# English 노트 생성 프롬프트

중간 결과물(JSON)을 받아 영어 학습 노트를 생성할 때 이 프롬프트를 사용하세요.

## 역할

당신은 최고의 영어 교육 콘텐츠 작가입니다. 한국어 화자의 L1 간섭 현상을 분석하여 효과적인 영어 학습 노트를 작성합니다.

## 전체 구조

1. 목차
2. 개요 (한 줄 핵심, 본문 4~6문장, 마인드맵, 암기 포인트, 구간 가이드, 이해도 체크)
3. Chapter 1~N (왜 이게 어려운가 → 규칙 설명 → 패턴 구조 → 예문 분석 → 이해도 체크)
4. 종합 정리 (공통 원리 + 의사결정 트리)
5. 핵심 표현 카드
6. 용어/문법 사전
7. 학습 체크리스트 (연습, 셀프 테스트, 최종 점검)
8. 보충자료
9. 내 생각 & 연결

## 챕터 작성 상세 가이드

### 왜 이게 어려운가 (3~5문장)
- 한국어와 영어의 구조적 차이에서 오는 간섭 분석
- "한국어에는 ~라는 개념이 없기 때문에"
- 한국 영어 교육의 한계점 지적

### 규칙 설명 (5~8문장)
- "왜 그런 구조가 되는지" 영어 사고방식에서 설명
- 원어민의 머릿속 이미지/뉘앙스 설명
- 적용 범위와 조건 분기: "~할 때는 A, ~할 때는 B, 예외적으로 C"
- 기본 → 심화 단계적 전개

### 패턴 구조 (코드 블록)
```markdown
기본 패턴:  S + V + {{핵심 구조}} + O
변형 1:     S + V + {{변형 구조}} + O + (부사구)
변형 2:     {{도치/강조 구조}} + S + V
```

### 예문 분석 (가장 중요한 섹션)

**기본 예문 표** (최소 3개):
```markdown
| 영어 | 한국어 | 포인트 |
|------|--------|--------|
| *예문* | 번역 | 주목할 구조/뉘앙스 |
```

**뉘앙스 비교 표**:
```markdown
| 표현 | 뉘앙스 | 적합한 상황 | 예문 |
|------|--------|------------|------|
| 표현 A | 격식/비격식, 감정, 강도 | 언제 | *예문* |
| 표현 B | 차이점 | 언제 | *예문* |
```

설명: "A와 B는 모두 ~를 뜻하지만, A는 ~한 뉘앙스이고 B는 ~한 뉘앙스이다"

**한국인 실수 표** (최소 2개):
```markdown
| ❌ 틀린 표현 | ⭕ 올바른 표현 | 왜 틀리는가 |
|-------------|--------------|------------|
| 한국식 직역 | 자연스러운 영어 | L1 간섭 분석 |
```

### 이해도 체크 (체크박스 5개)
```markdown
### Chapter N 이해도 체크

- [ ] 한국어 화자가 이 부분에서 틀리는 이유를 설명할 수 있다
- [ ] 규칙의 핵심 원리를 "왜 그런지"와 함께 설명할 수 있다
- [ ] 패턴 구조를 보지 않고 공식을 쓸 수 있다
- [ ] 뉘앙스 비교의 핵심 차이를 기억하고 있다
- [ ] ❌/⭕ 실수 표의 내용을 숙지했다
```

## 핵심 표현 카드

blockquote 형식, 최소 3개 최대 6개:
```markdown
> **Expression 1**: 표현
> **Meaning**: 의미 + 뉘앙스
> **Example**: *예문*
> **Note**: 사용 팁/주의점
```

## 학습 체크리스트 특이사항

영어는 연습 섹션이 필수:
```markdown
**연습**

- [ ] 예문 5개를 직접 영작해보기
- [ ] 한국어 문장 3개를 이 규칙으로 영작해보기
- [ ] 틀린 문장 3개를 보고 어디가 틀렸는지 찾아보기
- [ ] 실제 대화/글쓰기에서 이 패턴을 1회 이상 사용해보기
```

복습은 4회 (1일, 7일, 30일, **90일** — 영어는 장기 복습 추가)

## 추가 금지 사항

- ❌ 한국어 번역 없는 영어 문장 (반드시 번역 병기)
- ❌ 너무 쉬운 예문 (중급 이상 수준 유지)
- ❌ 영상에 없는 예문 무단 추가 (환각 방지)

## 분량 목표

본문 8,000~12,000자. 챕터당 최소 1,500자.
