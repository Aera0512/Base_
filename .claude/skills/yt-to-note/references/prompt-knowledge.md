# Knowledge 노트 생성 프롬프트

중간 결과물(JSON)을 받아 지식/교양 학습 노트를 생성할 때 이 프롬프트를 사용하세요.

## 역할

당신은 최고의 논픽션 학습 콘텐츠 작가입니다. 비판적 사고와 깊은 이해를 돕는 구조화된 지식 노트를 작성합니다.

## 전체 구조

1. 목차
2. 개요 (한 줄 핵심, 본문 4~6문장, 마인드맵, 암기 포인트, 구간 가이드, 이해도 체크)
3. Chapter 1~N (배경 → 화자의 주장과 근거 → 비유 → 이해도 체크)
4. 종합 정리 (큰 그림 + 비판적 시각 + 플로우차트)
5. 용어 사전
6. 학습 체크리스트 (셀프 테스트, 최종 점검)
7. 보충자료
8. 내 생각 & 연결

## 챕터 작성 상세 가이드

### 배경 (3~5문장)
- "많은 사람들이 ~라고 알고 있지만, 실제로는 ~이다"
- 통계, 시대적 배경, 사회적 맥락 포함
- 이걸 모르면 생기는 오해를 설명

### 화자의 주장과 근거 (가장 긴 섹션, 8~15문장)
- 핵심 주장을 한 문장으로 먼저 제시
- 논리 구조: "전제 → 근거 → 결론" 재구성
- **연구 결과 구체성 보존**: "하버드 심리학과 ~연구팀이 2023년 ~명을 대상으로 실험한 결과, ~한 그룹이 ~% 더 높은 성과를 보였다"
- 근거는 강력한 것부터 순서대로 배치
- 연결 문장: "이것을 뒷받침하는 또 다른 증거가 있다"
- 구체적 사례: 배경, 경과, 결과, 교훈 빠짐없이

### 비유로 이해하기 (1~2문장)
- "이것은 마치 ~와 같다. 왜냐하면 ~이기 때문이다."

### 이해도 체크 (체크박스 4개)
```markdown
### Chapter N 이해도 체크

- [ ] 이 챕터의 배경과 문제를 한 문장으로 설명할 수 있다
- [ ] 화자의 핵심 주장과 근거를 구분하여 설명할 수 있다
- [ ] 구체적 사례/연구 결과를 기억하고 있다
- [ ] 비유를 활용하여 타인에게 설명할 수 있다
```

### 챕터 간 연결
"앞서 ~를 살펴보았다면, 자연스럽게 떠오르는 질문은 '그렇다면 ~는 어떻게 되는가?'이다"

## 종합 정리 특이사항

knowledge 장르는 종합 정리에 **비판적 시각**을 반드시 포함:
- 화자가 당연시하는 전제 검토
- 근거의 한계: 일화 vs 통제 실험 vs 메타분석
- 적용 범위의 경계
- 반대 입장의 주요 논거

## 분량 목표

본문 8,000~15,000자. 챕터당 최소 2,000자.
