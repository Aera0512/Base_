# 서브에이전트 중간 결과물 JSON 스키마

서브에이전트는 자막을 분석하여 다음 JSON 구조를 반환해야 합니다.

## 추론 지시 (Ultra Think)

이 작업은 깊은 사고가 필요합니다. 충분히 시간을 들여 생각하세요.

1. **출처 신뢰도 평가**: 영상 내용의 각 주장을 평가하세요.
   - [A] 화자가 직접 수행한 연구/경험/공식 자료 인용
   - [B] 제3자 연구/논문/사례를 인용한 주장
   - [C] 개인 의견/추측/출처 불명 주장
   → 높은 등급 주장을 우선 반영

2. **모순 식별**: 영상 내에서 상충하는 주장이 있으면:
   - 양쪽 주장을 모두 기록
   - 어떤 주장이 더 근거가 있는지 판단
   - 해당 내용을 분석 결과에 명시

3. **미확인 마킹**: 화자가 출처를 밝히지 않은 주장은 `[미확인]` 표시

4. **깊은 추론**: 각 핵심 주장에 대해:
   - "이것이 왜 중요한가?" 한 단계 더 추론
   - "이 주장의 전제 조건은?" 식별
   - "반론은 무엇인가?" 검토

```
## 추론 지시 (Ultra Think)

이 작업은 깊은 사고가 필요합니다. 충분히 시간을 들여 생각하세요.

## 입력
- 영상 제목: {{title}}
- 채널: {{channel}}
- 장르: {{genre}}
- 자막 전문: (아래 첨부)

## 임무

1. **챕터 분절**: 자막을 주제 전환 기준으로 2~5개 챕터로 나누세요.
   - 각 챕터에 제목을 붙이세요 (핵심 키워드 중심, 한국어)
   - 각 챕터의 시작/종료 타임스탬프를 초 단위로 기록
   - 난이도 라벨 부여: 🟢 기초 / 🟡 중급 / 🔴 심화

2. **챕터별 핵심 분석**: 각 챕터에 대해:
   - 핵심 주장/개념을 1~2문장으로 요약
   - 뒷받침 근거/사례를 가능한 구체적으로 (수치, 연구자명 보존)
   - 핵심 용어 목록 (용어 → 한 줄 정의)
   - [tech] 코드/명령어가 있다면 원문 그대로 보존
   - [english] 문법 규칙/패턴/예문이 있다면 원문 그대로 보존
   - 화자가 사용한 비유가 있다면 기록
   - 흔한 실수/주의사항이 있다면 기록

3. **전체 분석**:
   - 한 줄 핵심 (20자 내외)
   - 4~6문장 개요
   - 마인드맵 구조: root → branch → leaf
   - 암기 포인트: ★★★(3점), ★★☆(2점), ★☆☆(1점) 중요도
   - 전체 용어 사전
   - 종합 정리 (모든 챕터를 관통하는 서사)
   - 셀프 테스트 질문 5~7개

모든 정보를 영상 자막에서만 추출하세요. 영상에 없는 내용을 추가하지 마세요.
```
