# 환경 설계 명령서: 딥워크 집중력 향상

> **환경**: 도서관 + 맥북
> **핵심**: 의지력은 유한한 자원. 환경이 행동을 결정하도록 설계하면, 의지력은 보조 수단이 된다.

---

## 적용된 뇌과학 원칙

| 원칙 | 설명 | 출처 |
|------|------|------|
| **주의 분산** | 2분 미만 태스크 전환만으로 전두엽 연결성 저하 | Frontiers in Human Neuroscience, 2025 |
| **신경가소성** | 깊은 집중 시 복잡한 추론/학습 신경 경로 강화 | Al-Mithaq Institute |
| **도파민/노르에피네프린** | 집중 시 증가 → 동기부여, 학습, 만족감 | Brain.fm |
| **환경이 뇌를 바꾼다** | 작업 공간 설계가 실시간 뇌 활동에 영향 | MeSpace-Neurable 연구 |

## 물리적 환경 (도서관에서 할 것)

- [ ] **자리 선택: 창가 or 벽면**
  → 자연광 노출 시 인지 성능 15% 향상. 뒤에 사람 지나가면 주의 분산.

- [ ] **시야 정리: 맥북 + 필기구 1개만**
  → Princeton 연구: 시야 내 물체 ↑ = 인지 자원 소모 ↑. 가방은 의자 아래.

- [ ] **에어팟/헤드폰 + 백색소음**
  → 도서관 잡음 차단. Brain.fm 또는 mynoise.net 사용. 60-65dB.

- [ ] **물병 책상 위**
  → 탈수 2%만으로 집중력 10% 저하. 물 마시러 일어나는 것 = 맥락 전환.

## 디지털 환경 (맥북 설정)

### 즉시 설정 (5분)

- [ ] **Focus 모드 생성: "딥워크"**
  ```
  설정 > 집중 모드 > + > 사용자 설정
  이름: 딥워크
  허용 앱: 없음 (또는 작업 앱만)
  허용 알림: 없음
  일정: 수동 또는 캘린더 연동
  ```

- [ ] **메뉴바에 Focus 표시**
  ```
  설정 > 제어 센터 > 집중 모드 > 메뉴 막대에 표시
  ```

- [ ] **방해 사이트 차단 (Cold Turkey Blocker)**
  - 다운로드: https://getcoldturkey.com
  - 차단 목록: youtube.com, twitter.com, instagram.com, reddit.com, news.naver.com
  - 설정: 딥워크 시간대 완전 차단 (끌 수 없음)

- [ ] **Dock 정리**
  ```
  현재 작업 앱만 Dock에 유지
  나머지 앱: 우클릭 > 옵션 > Dock에서 제거
  ```

### 추가 설정 (10분)

- [ ] **One Thing 앱 설치** (무료)
  → 메뉴바에 현재 작업 1개만 표시. "지금 뭐 하고 있지?" 상기.

- [ ] **전체화면 강제 습관**
  → 작업 앱 실행 후 `Ctrl + Cmd + F`. 다른 앱 시각적 유혹 완전 제거.

- [ ] **알림 센터 비활성화**
  ```
  설정 > 알림 > 각 앱별 > 알림 허용 끄기
  또는 DND 스케줄: 9AM-9PM 자동
  ```

## 시간 규칙 (지킬 것)

- [ ] **작업 시작 전 2분 의식**
  → 맥북 열기 전 "오늘 이 블록에서 할 것 1개" 적기. 뇌에 목표 프라이밍.

- [ ] **45분 딥워크 + 15분 휴식**
  → 휴식 시 맥북에서 손 떼기. 물 마시기, 스트레칭, 창밖 보기 (SNS ✗)

- [ ] **작업 전환 시 3초 멈춤**
  → 새 탭/앱 열기 전 "이게 지금 필요한가?" 자문. 충동적 전환 22% 감소.

## 자동화 (Shortcuts 설정)

### 딥워크 시작 자동화
```
단축어 앱 > + > 자동화 > 앱 열릴 때
트리거: Obsidian/작업앱 열릴 때
동작: Focus "딥워크" 켜기
```

### 도서관 도착 시 자동화
```
자동화 > 위치 도착 시
위치: 도서관 주소
동작: Focus "딥워크" 켜기 + 음량 0
```
