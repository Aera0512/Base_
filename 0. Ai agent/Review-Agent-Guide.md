# Review Agent 사용 가이드

> Obsidian · Anki · Notion · Google Calendar를 하나로 묶어, "오늘 뭘 복습해야 하는지" 알아서 알려주는 통합 복습 관제탑.

---

## 한 줄 요약

클로드에게 **"오늘 뭐 복습해?"** 라고 말하면, 알아서 스캔하고 정렬해서 원클릭 링크와 함께 브리핑을 만들어준다.

---

## 3가지 모드

### Mode A — 오늘의 복습 브리핑

**이렇게 말하면 됨:**
- "오늘 뭐 복습해?"
- "밀린 복습 있어?"
- "복습 브리핑"
- "뭐 공부해야 돼?"

**하는 일:**
1. Obsidian 볼트에서 yt-note, book-note, concept 노트를 스캔
2. `review` 배열과 `date_created`를 분석해 오늘 복습해야 할 노트 필터링
3. 밀린 복습은 🔴 긴급, 오늘 예정은 🟡 으로 우선순위 정렬
4. Anki due 카드 수 조회 (Anki 꺼져있으면 자동 스킵)
5. Notion 해야할일 DB에서 학습 태스크 가져오기
6. 모든 노트에 `obsidian://open` 원클릭 링크 포함

### Mode B — 복습 완료 & 기록

**이렇게 말하면 됨:**
- "방금 Global Warming Essay Writing Guide 복습했어. confidence 4점"
- "복습 완료"
- "[노트이름] 다 봤어"

**하는 일:**
1. Obsidian에서 해당 노트 검색
2. confidence 점수 기반으로 다음 복습일 자동 계산 (FSRS 알고리즘)
3. 프론트매터 업데이트: `review` 배열에 날짜 기록, `confidence`, `next_review`, `review_phase`
4. 복습 로그 테이블에 행 추가
5. Google Calendar "루틴" 캘린더에 다음 복습 리마인더 자동 생성

### Mode C — 주간 복습 리포트

**이렇게 말하면 됨:**
- "이번 주 복습 리포트"
- "복습 현황 보여줘"
- "주간 학습 정리"

**하는 일:**
1. 이번 주(월~일) 복습 완료 노트 수집
2. 과목별(genre별) 분석 + 미복습 누적 카운트
3. 다음 주 복습 예정 미리보기
4. `0. Ai agent/Review-Reports/` 폴더에 Obsidian 노트로 자동 저장

---

## Confidence 점수 가이드

복습 완료 시 기억 정도를 1~5로 알려주면 다음 복습 간격이 자동 조정된다.

| 점수 | 의미 | 간격 배율 |
|:----:|------|:---------:|
| 1 | 전혀 기억 안남 | ×0.5 (빨리 다시) |
| 2 | 거의 기억 안남 | ×0.75 |
| 3 | 보통 | ×1.0 (기본) |
| 4 | 잘 기억남 | ×1.25 |
| 5 | 완벽 | ×1.5 (느긋하게) |

예: 2차 복습 기본 간격 7일 × confidence 4 (×1.25) = **9일 후** 다음 복습

---

## 복습 주기

| 단계 | 기본 간격 | 예시 (confidence 3) |
|:----:|:---------:|:-------------------:|
| 1차 | +1일 | 학습 다음날 |
| 2차 | +7일 | 1차 복습 후 1주일 |
| 3차 | +30일 | 2차 복습 후 1개월 |
| 4차+ | FSRS 계산 | 점점 길어짐 (최대 365일) |

---

## 자동 스케줄

| 시간 | 이벤트 |
|------|--------|
| 매일 오전 8시 | 오늘의 복습 브리핑 자동 생성 |
| 매일 오후 9시 | 미완료 복습 리마인더 |
| 매주 일요일 오후 8시 | 주간 복습 리포트 생성 & Obsidian 저장 |

---

## 밀린 복습 처리 규칙

| 밀린 기간 | 처리 |
|-----------|------|
| 7일 이내 | 원래 단계에서 이어서 |
| 7일~30일 | 한 단계 되돌리기 |
| 30일 이상 | 처음부터 리셋 |

---

## 연동 앱

| 앱 | 역할 | 필수 여부 |
|----|------|:---------:|
| Obsidian | 학습 노트 저장소, 프론트매터 기반 추적 | 필수 |
| Anki | 플래시카드 due 현황 조회 | 선택 (꺼져있으면 스킵) |
| Notion | 학습 태스크 목록 | 선택 (연결 안되면 스킵) |
| Google Calendar | 복습 리마인더 이벤트 | 선택 |

---

## 프론트매터 필드

복습 시스템이 사용하는 필드 (기존 필드는 절대 건드리지 않음):

```yaml
review: [null, null, null]   # [1차 완료일, 2차 완료일, 3차 완료일]
confidence: null              # 마지막 복습 시 기억도 (1-5)
next_review: null             # 다음 복습 예정일 (ISO)
review_phase: 0               # 현재 복습 단계
difficulty: 3                 # 난이도 (1-5, 자동 조정)
```

신규 필드(`next_review`, `review_phase`, `difficulty`)는 첫 복습 완료 시 자동 추가된다. 기존 노트의 `review: [null, null, null]`만으로도 브리핑은 바로 작동한다.

---

## 팁

- confidence를 안 말하면 자동으로 물어봄 → 그냥 숫자만 답하면 됨
- 브리핑에서 노트 링크 클릭하면 Obsidian에서 바로 열림
- 주간 리포트는 `0. Ai agent/Review-Reports/`에 자동 누적됨
- 복습 대상이 너무 많으면 상위 5개만 먼저 보여주고 나머지는 요청 시 표시
