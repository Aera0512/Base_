# B2 Climate Essay - Quick Reference

> 시험 직전 3시간 암기용 핵심 치트시트

---

## 📐 에세이 4단락 구조

| 단락 | 기능 | 시작 프레임 |
|------|------|-------------|
| **서론** | 배경 + 논지 제시 | "This essay will critically examine both the advantages and drawbacks of..." |
| **본론1 (Pros)** | 핵심 장점 + 인과관계 | "One of the most compelling advantages is that..." |
| **본론2 (Cons)** | 대조 전환 + 단점 | "Despite these apparent benefits, there are significant limitations..." |
| **결론** | 요약 + 균형잡힌 의견 | "Taking everything into consideration..." |

---

## 🔤 핵심 연어 (Collocations)

### 동사-명사 (반드시 암기)
| 연어 | 의미 | 예문 |
|------|------|------|
| **mitigate** climate change | 기후변화 완화 | We must mitigate the effects of global warming. |
| **implement** policies | 정책 시행 | Governments must implement strict policies. |
| **phase out** fossil fuels | 단계적 폐지 | Fossil fuels must be phased out within a decade. |
| **reduce/cut down on** emissions | 배출량 감소 | Citizens must cut down on energy consumption. |

### 핵심 명사구
- **greenhouse gas emissions** (온실가스 배출)
- **carbon footprint** (탄소 발자국)
- **renewable energy** (재생 에너지)
- **fossil fuels** (화석 연료)

### 형용사-명사
- **devastating consequences** (파괴적 결과)
- **drastic measures** (과감한 조치)
- **regressive nature** (역진적 성격)
- **intermittency** (간헐성)

## 📝 문법 공식

### 1. 가정법 현재 (1st Conditional) → 실현 가능한 예측
```
If + 현재시제, will/can/may + 동사원형
```
> If global temperatures continue to rise, coastal cities **will face** devastating floods.

### 2. 가정법 과거 (2nd Conditional) → 가상/이상적 상황
```
If + 과거시제, would/could/might + 동사원형
```
> If every nation prioritized the environment, climate change **would slow** drastically.

### 3. 조동사 수동태 → 정책 제안
```
must/should/can + be + p.p
```
> Strict regulations **must be implemented** to limit pollution.

### 4. 비인칭 수동태 → 객관적 의견 (I think 대체)
- **It is widely believed that...** (널리 믿어진다)
- **It has been argued that...** (주장되어 왔다)
- **It must be acknowledged that...** (인정되어야 한다)

## 🔗 연결어 & 결속 기법

### 확장 (추가 논거)
- Furthermore, / Moreover, / In addition,

### 대조 전환 (본론1→본론2)
- **Despite these apparent benefits,** there are notable drawbacks.
- On the other hand, / Nevertheless,

### 결론
- **Taking everything into consideration,** ...
- All things considered, / On balance,

### 요약 명사 결속
❌ This causes problems.
✅ **This reliance on fossil fuels** causes problems.

## 💡 테마별 핵심 논거

### 탄소세 (Carbon Tax)

| Pros | Cons |
|------|------|
| 경제적 인센티브 → 기업이 친환경 기술 전환 | **역진적**: 저소득층에 더 큰 부담 |
| 세수 → 재생에너지 재투자 가능 | **탄소 누출**: 기업이 규제 느슨한 국가로 이전 |

### 재생 에너지 (Renewable Energy)

| Pros | Cons |
|------|------|
| **무한한 자원** (태양, 바람) | **간헐성**: 밤/흐린날/무풍시 발전 불가 |
| 탈탄소화 → 배출 제로 | 배터리 저장 기술 한계 |
| 에너지 안보 확립 | **지리적 제약**: 모든 국가에 적합하지 않음 |

## ⚠️ 감점 피하기

### Hedging (단정 회피)
❌ Carbon taxes **cause** poverty.
✅ Carbon taxes **tend to** disproportionately affect lower-income households.

**헤징 표현**: tend to / are likely to / appear to / to a certain extent

### 피해야 할 것
- "Every coin has two sides" (진부한 템플릿)
- 지나치게 긴 복문 (오류 확률↑)
- 맥락 안 맞는 고급 어휘 남발

## ⏱️ 3시간 액션 플랜

| 시간 | 활동 |
|------|------|
| 0-45분 | 연어 암기 (문장 단위로 소리내어) |
| 45-90분 | 수동태/가정법 문장 영작 연습 |
| 90-120분 | 4단락 구조 + 연결어 확정 |
| 120-180분 | 실전 모의 에세이 작성 |
