
## 목열기 

**기본 원리**
1. 높은 피치 유지하기
2. '으ㅓ' 모음값 유지하기
3. 복식호흡 깊게 (무릎에 팔)
4. 최대한 어두운 음색
5. 최대한 작은 소리

+ 연구개에 호흡 가져다 대기
+ 입 공간을 깊게 쓰기, 들숨 때 후두가 충분히 내려가지게 하기
+ 혀뿌리가 누르지 않고 적당히 올라가주기
+ 코에서 바람이 나오는 느낌으로 시작하기

피드백 1 : 첫 숨을 쉴 때 높게 목을 제대로 열어주고 날숨을 뱉을 때 혀가 적정한 위치로 옮겨가기. + 코쪽으로 바람이 나가주기 + 하행 때 소리 먹지 말고 균일하게 나가기

고음 부분은 '흐ㅓ' 모음 값 써주기


## 쿅쿅쿅

**기본 원리**

1. 귓속말처럼 아주 작은 소리
2. 어둡지 않은 약간 밝은 소리
3. 공기를 섞지 않은 가성

+ 들숨 짧게 목 열어주며 후두 중립
+ 날숨 적극적으로 발음함으로써 적합하게 뱉어주기 + 작은 턱 움직임
+ 스타카토인 만큼 짧고 툭툭 제대로 쳐주기
+ 숨을 마시고 가볍게 멈추고 있는 느낌

## 꼭꼭꼭

**기본 원리** / 두꺼운 성대 접촉에서 얇은 성대 접촉으로 자연스러운 전환 연습, 나도 모르는 새에 전환

1. 너무 어둡지 밝지도 않은 적당한 음색, 말하듯이 자연스러운
2. 높은 피치 처음부터 끝까지 계속 유지
