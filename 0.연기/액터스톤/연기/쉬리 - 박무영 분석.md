## 장면 분석
이 대사에서 인물은 말 그대로 무엇을 하고 있는가 : 

+ 상대방의 말을 존중한다.
+ 정치인을 기다려왔던 과거와 그들의 무관심함에 대해 말한다.
+ 이 모든 게 거짓임을 말한다.
+ 남한의 노래를 흉내낸다
+ 남한과 북한의 현실을 말한다.
+ 북한이 어떤 환경에서 살고 있는지 말한다.
+ 남한의 태평한 삶을 무시한다.
+ 정치인들의 음모를 따진다.
+ 자신이 역사를 다시 열 것 임을 선포한다.

평화와 통일이라는 안일한 생각에 빠진 상대방을 조롱하며 북한의 비참한 현실을 폭로함으로써 자신이 벌이려는 극단적이고 파괴적인 행동의 정당성을 선언한다.

상대방의 헛된 환상을 깨부수고, 나의 선택이 절대적으로 정당함을 상대에게 각인시킨다.
