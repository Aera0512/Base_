수단 : 
빨대 음 이동

피드백 : 공기의 양을 맞추는 데에 집중하라. 그러면 소리도 자연스레 균등해진다.

수단 2 : 
멈으로 소리내기

피드백 : 성대를 닫고 시작하기. 아니면 탄성을 잘 받기 (어깨 뜨지 않도록), 소리 균일하게 한 건 좋았다, 시작 위치를 더 바보처럼

피드백 : 소리가 플랫되는 경우가 있음. 코 공간을 더 잘 쓰면 좋을 듯 지금은 너무 구강 공명. 그리고 성대를 늘리는 시도를 더 했으면 (김건모 소리처럼)

ㅎ.. 멈 느낌으로 호흡을 보내주고 부드럽게 풀어주기. 성대에 경직있는 소리 안 났으면. (ta 근육 최소화, ==부드러운 콧 노래 부르듯이==)

피드백 : 시작할 때 자음을 코에 꽂고 시작하기, 전체 방향성은 앞으로 가되 바보소리로 시작해보자
