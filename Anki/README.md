# Anki 카드 생성 폴더

이 폴더에 노트를 넣으면 Cowork가 자동으로 Anki 플래시카드를 생성합니다.

## 폴더 구조

```
Anki/
├── English/                     ← 영어 카드
│   └── {노트 제목}/             ← 노트별 하위 폴더
│       └── {노트 제목}.md       ← 소스 노트
└── Knowledge/                   ← 지식 카드
    └── {노트 제목}/
        └── {노트 제목}.md
```

**규칙**: 노트 제목으로 폴더를 만들고, 그 안에 같은 이름의 .md 파일을 넣는다.

## Anki 덱 구조 (자동 매핑)

| Obsidian 경로 | Anki 덱 |
|---------------|---------|
| `Anki/English/TOEFL 필수 단어 5개/` | `Obsidian::English::TOEFL 필수 단어 5개` |
| `Anki/Knowledge/간격 반복 학습법/` | `Obsidian::Knowledge::간격 반복 학습법` |

## 사용법

### 새 노트 추가하기

1. `Anki/English/` 또는 `Anki/Knowledge/` 아래에 **노트 제목 폴더** 생성
2. 폴더 안에 같은 이름의 .md 파일 작성
3. 자동 스캔(매일 9시) 또는 수동 실행으로 카드 생성

### 자동 스캔 (스케줄)
- 매일 오전 9시, Cowork가 이 폴더를 스캔하여 새 노트에서 카드를 자동 생성
- Cowork 앱 + Anki 데스크톱이 모두 실행 중이어야 함

### 수동 생성 (Cowork 스킬)
- Cowork에서 "이 노트 Anki 카드로 만들어줘" 또는 검색 주제/사진 제공
