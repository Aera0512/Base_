# Anki 카드 생성 폴더

이 폴더에 노트를 넣으면 Cowork가 자동으로 Anki 플래시카드를 생성합니다.

## 사용법

### 자동 스캔 (스케줄)
- 이 폴더에 노트를 작성하면, 스케줄된 태스크가 주기적으로 스캔하여 카드를 만듭니다.

### 수동 생성 (Cowork 스킬)
- Cowork에서 스킬을 실행하여 특정 노트, 검색 주제, 사진으로 카드를 만들 수 있습니다.

## 하위 폴더
- `English/` — 영어 단어/표현 노트
- `Knowledge/` — 일반 지식 노트
- `Photos/` — 영어 단어장 사진 (자동 OCR)
