# Second Conditional (가정법 과거) - 복습 워크북

---

## ⚡ 핵심 공식

### 기본 구조
```
If + 주어 + 과거동사, 주어 + would + 동사원형
```

### 형태 정리
| 구성 요소 | 형태 | 예시 |
|-----------|------|------|
| If절 | If + S + 과거동사 | If I **had** money |
| If절 (be동사) | If + S + **were** | If I **were** rich |
| 주절 | S + would + 동사원형 | I **would buy** a car |
| 주절 (부정) | S + wouldn't + 동사원형 | I **wouldn't waste** it |
| 의문문 | Would + S + 동사원형? | **Would** you help me? |

### 도치 구문 (격식체)
```
Were + 주어 + ..., 주어 + would + 동사원형
```
- If I were rich → **Were I** rich
- If it were possible → **Were it** possible

### 신호 단어/표현
- **If I were you**: 조언할 때
- **If it weren't for**: ~이 없다면
- **What if**: 가상적 질문
- **Suppose/Imagine**: 가정 상황

## ⚠️ 한국인 오류 TOP 5

### 1. If절에 would 사용
❌ If I **would have** time, I would help you.
✅ If I **had** time, I would help you.

> 💡 **규칙**: If절에는 would 절대 금지! 과거동사만!

### 2. be동사에서 was 사용 (격식체 오류)
❌ If I **was** you, I would apologize. (비격식)
✅ If I **were** you, I would apologize. (격식/표준)

> 💡 **규칙**: 가정법에서 be동사는 **were**가 표준

### 3. First와 Second 혼동
❌ If I **win** (현재), I **would** buy...
✅ If I **won** (과거), I **would** buy...

> 💡 **규칙**: 낮은 가능성 = 과거동사 + would

### 4. 주절에 조동사 현재형 사용
❌ If I had time, I **can** help.
✅ If I had time, I **could** help.

> 💡 **규칙**: 주절도 조동사 과거형 (can→could, may→might)

### 5. 의문문 어순 오류
❌ What you would do if...?
✅ What **would you** do if...?

> 💡 **규칙**: Would + S + V 어순

## 🔑 핵심 예문 12선

### 초급 (4개)
1. **If I had more time, I would learn a new language.**
   - 기본 구조: If + 과거 + would + 원형

2. **If I were you, I would apologize.**
   - 조언 표현: If I were you

3. **What would you do if you won the lottery?**
   - 가상적 질문: What would + S + do

4. **If she knew the answer, she would tell us.**
   - 현재 사실의 반대 가정

### 중급 (4개)
5. **If the company offered remote work, employee satisfaction would improve.**
   - 복잡한 주어 + 결과

6. **If I weren't so busy, I would travel more often.**
   - 부정 가정: weren't

7. **If it weren't for your support, I wouldn't succeed.**
   - "If it weren't for" 관용 표현

8. **I could help you if I had the necessary skills.**
   - 주절 먼저 + could 사용

### 고급 (4개)
9. **Were I in your position, I wouldn't accept that offer without negotiating.**
   - 도치 구문: Were I

10. **Were the policy to be implemented, employees would benefit greatly.**
    - 도치 + to be 구문

11. **If meritocracy were truly practiced, promotions would be based on performance.**
    - 수동태 가정

12. **Were education universally accessible, opportunities would be distributed more equitably.**
    - 도치 + 복잡한 결과절

## ⚡ 빠른 자가 테스트 (10문제)

### 빈칸 채우기 (3문제)

1. If I _______ (have) a car, I would drive to work.
> [!success]- 정답
> **had**
> Second Conditional: If + 과거동사

2. If she _______ (be) here, she could help us.
> [!success]- 정답
> **were**
> be동사 가정법: were

3. What _______ you do if you lost your job?
> [!success]- 정답
> **would**
> 의문문: What would + S + V?

### 오류 교정 (2문제)

4. ❌ If I would know the answer, I would tell you.
> [!success]- 정답
> ✅ If I **knew** the answer, I would tell you.
> (If절에 would 사용 불가)

5. ❌ If she was rich, she will travel the world.
> [!success]- 정답
> ✅ If she **were** rich, she **would** travel the world.
> (were 사용 + will → would)

### Fill the Gap (3문제)

6. **내가 너라면, 그 제안을 받아들일 거야.**
> [!success]- 정답
> If I **were** you, I **would accept** that offer.

7. **시간이 더 있다면, 새로운 취미를 시작할 텐데.**
> [!success]- 정답
> If I **had** more time, I **would start** a new hobby.

8. **네 도움이 없다면, 나는 성공하지 못할 거야.**
> [!success]- 정답
> If it **weren't** for your help, I **wouldn't succeed**.

### 어순 배열 (2문제)

9. [ if / were / I / you / , / would / I / accept / that offer ]
> [!success]- 정답
> **If I were you, I would accept that offer.**

10. [ would / what / you / do / if / won / you / the lottery / ? ]
> [!success]- 정답
> **What would you do if you won the lottery?**

## ✅ 마스터 체크리스트

### 기본 개념
- [ ] Second Conditional의 용도 2가지를 설명할 수 있다 (현재 반대, 낮은 가능성)
- [ ] First vs Second Conditional의 차이를 알고 있다
- [ ] If절에 would를 사용하면 안 되는 이유를 안다

### 형태
- [ ] If + 과거동사 + would + 동사원형 구조를 만들 수 있다
- [ ] be동사 가정법에서 were를 사용한다
- [ ] 부정문을 만들 수 있다 (wouldn't, weren't)
- [ ] 의문문 어순을 안다 (Would + S + V?)

### 고급 구조
- [ ] 도치 구문을 이해한다 (Were I, Were it)
- [ ] "If it weren't for" 구문을 사용할 수 있다
- [ ] would 대신 could/might를 사용할 수 있다
- [ ] 주절이 먼저 오는 구조를 만들 수 있다

### 관용 표현
- [ ] "If I were you" 조언 표현을 사용할 수 있다
- [ ] "What if" 가상 질문을 할 수 있다
- [ ] "Suppose/Imagine" 구문을 이해한다

### 오류 회피
- [ ] If절에 would를 쓰지 않는다
- [ ] be동사는 were를 사용한다 (격식)
- [ ] First와 Second를 혼동하지 않는다
- [ ] 주절 조동사도 과거형을 쓴다 (can→could)

## 📚 빠른 참조

### 기본 vs 도치
| 기본 | 도치 (격식) |
|------|-------------|
| If I were rich | Were I rich |
| If he were here | Were he here |
| If it were possible | Were it possible |

### would vs could vs might
| 조동사 | 의미 | 확실성 |
|--------|------|--------|
| would | ~할 것이다 | 높음 |
| could | ~할 수 있다 | 중간 |
| might | ~할 수도 있다 | 낮음 |

### 관용 표현
```
If I were you... (조언)
If it weren't for... (~이 없다면)
What if...? (만약 ~한다면?)
Suppose/Imagine... (가정하면)
```

### First vs Second 비교
| | First | Second |
|---|-------|--------|
| 가능성 | 높음 | 낮음/불가능 |
| If절 | 현재 | 과거 |
| 주절 | will | would |
| 예시 | If it rains, I'll stay. | If it rained gold, I'd be rich. |
