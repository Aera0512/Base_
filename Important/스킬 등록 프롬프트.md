# 스킬 등록 프롬프트

아래 프롬프트를 Claude Code에 붙여넣으면 자동으로 해결됩니다.

---

## 프롬프트

```
내 Obsidian 볼트(.claude/skills/)에 만든 스킬들이 Claude Code에서 인식되지 않아.
다음 작업을 순서대로 수행해줘:

1. 볼트 루트의 .claude/skills/ 디렉토리를 탐색해서 모든 스킬 폴더 목록을 확인해
2. 각 스킬의 SKILL.md를 읽어
3. .claude/commands/{스킬명}.md 파일로 변환해서 볼트 루트에 저장해
   - 참조 파일 경로는 .claude/skills/{스킬명}/references/ 형태의 절대경로로 수정
   - 내용은 SKILL.md와 동일하되, references/ 경로만 보정
4. 유저 레벨에도 등록해: mkdir -p ~/.claude/commands && cp .claude/commands/*.md ~/.claude/commands/
5. 등록된 커맨드 목록을 ls ~/.claude/commands/ 로 확인해서 보여줘
```
