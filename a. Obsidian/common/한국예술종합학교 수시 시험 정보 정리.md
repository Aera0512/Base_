## 내가 원하는 타임 들어가는 법
### 한국예술종합학교는 기본적으로 고사장 5개 그리고 8타임
한 고사장마다 여자는 한 타임에 8명씩 남자는 6명씩 들어간다. 
따라서 하루에 
여자는 대략 8(인원)x8(타임 수)x 5고사장 수 = 320
남자는 대략 6(인원)x8(타임 수)x 5고사장 수 = 240

**유의할 점 : 사진 보면 알듯이 한 타임 당 인원이 일정하지않음. 5명씩 들어갈 때도 있고 무작위로 14명 7명씩 들어가기도 함.

### 구체적 방법

#### 날짜 계산 /
1#### 날짜 계산 /

1. 내가 시험보고 싶은 날짜를 고른다.
    
2. 하루 수용 인원을 확인한다.
    

- 여자 : 하루 320명
    
- 남자 : 하루 240명
    

3. 원하는 날짜의 번호 범위를 계산한다.
    

여자 기준

- 1일차 : 1~320
    
- 2일차 : 321~640
    
- 3일차 : 641~960
    
- 4일차 : 961~1280
    
- 5일차 : 1281~1600
    
- ...
    

남자 기준

- 1일차 : 1~240
    
- 2일차 : 241~480
    
- 3일차 : 481~720
    
- 4일차 : 721~960
    
- 5일차 : 961~1200
    
- ...
    

4. 원하는 날짜의 번호 범위를 확인한다.
    

예)  
여자 3일차 희망  
→ 641~960 사이 접수

남자 3일차 희망  
→ 481~720 사이 접수

5. 오픈채팅에서 현재 접수번호를 확인한다.  
    (남녀 접수번호는 별도로 확인)
    
6. 원하는 번호 범위에 진입했을 때 접수한다.
    

※ 실제 지원자 수에 따라 마지막 날짜의 번호 범위는 달라질 수 있으므로 접수 현황을 함께 확인
#### 타임 계산 /
1. 내가 원하는 시험 시간대를 고른다.  

2. 원하는 날짜의 시작 번호를 구한다.  
예)  
여자 3일차 → 641~960번  
남자 3일차 → 481~720번  
  
3. 같은 시간대는 시험장마다 반복된다.  
- 여자: 64명 간격 (8명 × 8타임)  
- 남자: 48명 간격 (6명 × 8타임)  
  
4. 원하는 시간대 번호를 계산한다.

- 1타임 : 시작번호 + 0~7

- 8타임 : 시작번호 + 56~63
