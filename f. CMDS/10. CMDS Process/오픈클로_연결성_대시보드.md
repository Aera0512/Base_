# 오픈클로 연결성 대시보드

상위: [[CMDS Home]]

## 고립 노트(인링크 0)
```dataview
TABLE file.folder AS Folder
FROM "f. CMDS"
WHERE length(file.inlinks) = 0
SORT file.mtime DESC
```

## 링크 많은 핵심 노트
```dataview
TABLE length(file.inlinks) AS Inlinks, length(file.outlinks) AS Outlinks
FROM "f. CMDS"
SORT length(file.inlinks) DESC
LIMIT 30
```

## 최근 생성 노트(연결 필요 후보)
```dataview
TABLE file.folder AS Folder, length(file.outlinks) AS Outlinks
FROM "f. CMDS"
SORT file.ctime DESC
LIMIT 30
```
