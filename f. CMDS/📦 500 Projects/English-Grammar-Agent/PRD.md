# English Grammar Learning Agent — PRD

> **프로젝트 유형**: 중형 (Cowork 스킬)
> **목적**: 영어 문법 토픽을 입력하면 심화 개념 설명 → 난이도별 예문 150개 → 오디오 → 퀴즈 → 스피킹 연습 → 유튜브 추천까지 자동 생성하는 학습 에이전트
> **실행 환경**: Cowork Skill → Obsidian MCP 직접 출력
> **버전**: 1.0 (draft)
> **작성일**: 2026-03-05

---

## 1. 프로젝트 개요

### 해결하는 문제
영어 문법을 공부할 때 개념 이해 → 반복 노출 → 능동적 사용까지의 전체 학습 사이클을 매번 수동으로 구성해야 한다. 양질의 예문을 충분히 확보하기 어렵고, 듣기 자료를 별도로 찾아야 하며, 스피킹 연습 구조도 없다.

### 핵심 가치
문법 토픽 하나만 입력하면 **"이해 → 듣기 → 읽기 → 문제풀기 → 말하기"** 전체 학습 자료가 Obsidian에 자동 생성된다. 한 번 만들어두면 반복 학습만 하면 되는 **완결형 학습 패키지**.

### 사용자 시나리오
1. 사용자가 스킬을 호출하고 "Present Perfect" 같은 문법 토픽을 입력
2. 에이전트가 웹 리서치로 해당 문법을 심층 조사
3. 개념서 수준의 설명을 한국어로 작성
4. 초/중/고급 예문 각 50개 생성
5. edge-tts로 난이도별 오디오 3개 생성
6. 빈칸 채우기 퀴즈 생성
7. 한→영 스피킹 연습 자료 생성
8. 관련 한국인 유튜브 영상 추천
9. 모든 결과물을 Obsidian 노트 하나 + 오디오 파일로 출력

## 2. 기능 정의

### 기능 1: 문법 딥 리서치 & 개념 설명

> ⚠️ **이 단계가 전체 학습 자료의 기초이므로 가장 심화적으로 수행**

#### 입력
- 사용자가 입력한 문법 토픽 (예: "Present Perfect", "관계대명사", "가정법")

#### 처리 — 리서치 단계
1. **웹 검색 3회 이상 수행**: 해당 문법에 대해 최소 3개 이상의 소스를 조사
   - 영문 문법 레퍼런스 (Cambridge Grammar, Grammarly 등)
   - 한국인 학습자 관점의 설명 (한국어 블로그, 강의 자료)
   - 원어민이 실제로 쓰는 뉘앙스/예외 사항
2. **교차 검증**: 여러 소스에서 일관된 정보를 확인하고, 소스 간 차이가 있으면 명시
3. **한국인 학습자 특화 포인트 조사**: 한국어와의 구조적 차이, 한국인이 흔히 틀리는 패턴

#### 처리 — 작성 단계
아래 구조로 **개념서 수준의 설명**을 한국어로 작성:

```
1. 핵심 개념 (한 문장 정의)
2. 왜 이 문법이 존재하는가 (영어의 사고방식)
3. 기본 형태 & 구조
   - 긍정문 / 부정문 / 의문문
   - 축약형 (실제 회화에서의 사용)
4. 핵심 용법 (각각 예시 포함)
   - 용법 1: [설명]
   - 용법 2: [설명]
   - ...
5. 시간 표현 / 신호 단어 (signal words)
6. 비슷한 문법과의 비교
   - 예: Present Perfect vs Simple Past
   - 차이점을 상황 예시로 설명
7. 한국인이 자주 틀리는 포인트
   - 한국어 사고방식과의 충돌 지점
   - 대표적인 오류 패턴 + 교정
8. 고급 뉘앙스 & 원어민 사용 패턴
   - 원어민이 실제로 이 문법을 어떤 맥락에서 쓰는지
   - 격식 vs 비격식 차이
```

#### 출력
- Obsidian 노트의 `## 📖 문법 설명` 섹션

#### 완료 기준
- 최소 3개 소스에서 교차 검증된 정보
- 한국인 학습자 관점의 설명이 포함
- 비슷한 문법과의 비교가 있음
- 형태(form), 의미(meaning), 사용(use) 세 차원을 모두 커버

### 기능 2: 난이도별 예문 생성 (각 50개, 총 150개)

#### 입력
- 기능 1에서 정리된 문법 개념 + 용법

#### 처리

**예문 설계 원칙**:

| 원칙 | 설명 |
|------|------|
| 점진적 복잡도 | 같은 난이도 내에서도 1→50으로 갈수록 조금씩 어려워짐 |
| 상황 분산 | 10가지 일상 상황(집, 카페, 직장, 쇼핑, 전화, 친구, 식당, 학교, 여행, 병원)에 고르게 분배 |
| 자연스러움 | 교과서식이 아닌 실제 회화체. 축약형 적극 사용 |
| 용법 커버리지 | 해당 문법의 모든 주요 용법이 예문에 골고루 반영 |
| 중복 방지 | 같은 동사/주어 패턴이 3번 이상 반복되지 않도록 |

**난이도 기준**:

| 난이도 | 단어 수 | 특징 | 예시 (Present Perfect) |
|--------|---------|------|----------------------|
| **초급** | 3~8 | 기본 형태, 고빈도 동사, 단순 구조 | "I've eaten lunch." |
| **중급** | 8~15 | 부사/시간표현 추가, 자연스러운 회화체 | "I've been waiting here for almost thirty minutes." |
| **고급** | 12~25 | 다른 문법과 결합, 복합 구조, 미묘한 뉘앙스 | "Had I known you were coming, I would've prepared something special." |

**상황 분배 (난이도별 50개 = 10상황 × 5문장)**:

| # | 상황 | 예시 맥락 |
|---|------|----------|
| 1 | 집/가족 | 아침 루틴, 가족과의 대화, 집안일 |
| 2 | 카페/식당 | 주문, 친구와 수다, 음식 이야기 |
| 3 | 직장/학교 | 동료와 대화, 업무 보고, 수업 |
| 4 | 쇼핑 | 물건 고르기, 점원과 대화, 온라인 쇼핑 |
| 5 | 전화/메시지 | 전화 통화, 문자 상황 설명 |
| 6 | 친구/사교 | 약속 잡기, 근황 토크, 파티 |
| 7 | 여행/외출 | 길 묻기, 관광, 교통수단 |
| 8 | 건강/병원 | 증상 설명, 약국, 운동 |
| 9 | 취미/여가 | 영화, 음악, 스포츠, 독서 |
| 10 | 감정/의견 | 기분 표현, 의견 교환, 조언 |

#### 출력
- Obsidian 노트의 `## 🎧 예문` 섹션
- 각 예문은 번호 + 영어 문장 + Obsidian callout으로 접힌 한국어 해석

#### 출력 형태 예시
```markdown
## 🎧 예문 — 초급

![[present-perfect-beginner.mp3]]

1. I've eaten lunch.
> [!note]- 해석
> 나는 점심을 먹었어.

2. She's left already.
> [!note]- 해석
> 그녀는 이미 떠났어.
```

#### 완료 기준
- 각 난이도별 정확히 50개
- 10가지 상황이 균등하게 분배 (각 5개)
- 같은 난이도 내 점진적 복잡도 상승
- 해당 문법의 주요 용법이 모두 커버됨
- 모든 문장이 문법적으로 정확하고 자연스러움

### 기능 3: 오디오 생성 (TTS)

#### 입력
- 기능 2에서 생성된 150개 영어 문장

#### 처리
1. **edge-tts** Python 라이브러리 사용 (무료, Microsoft Neural TTS)
2. **음성**: `en-US-AriaNeural` (여성) — 자연스럽고 명확한 발음
3. **속도**: 
   - 초급: rate `-10%` (약간 느리게)
   - 중급: rate `+0%` (기본 속도)
   - 고급: rate `+5%` (약간 빠르게, 실제 회화 속도에 가깝게)
4. **문장 간 간격**: 3초 무음 삽입
5. **파일 구성**: 난이도별 1개씩, 총 3개 MP3 파일

#### 기술 구현
```python
# 핵심 로직 (의사 코드)
import edge_tts
import pydub

for level in ["beginner", "intermediate", "advanced"]:
    audio_segments = []
    for sentence in sentences[level]:
        # TTS로 문장 생성
        tts = edge_tts.Communicate(sentence, voice, rate=rate)
        tts.save(temp_file)
        # 문장 오디오 + 3초 무음 추가
        audio_segments.append(AudioSegment.from_file(temp_file))
        audio_segments.append(AudioSegment.silent(duration=3000))
    # 합치기
    combined.export(f"{topic}-{level}.mp3")
```

#### 출력
- `English Grammar/audio/{topic}-beginner.mp3`
- `English Grammar/audio/{topic}-intermediate.mp3`
- `English Grammar/audio/{topic}-advanced.mp3`

#### Obsidian 임베드
```markdown
![[present-perfect-beginner.mp3]]
```
→ Obsidian에서 인라인 오디오 플레이어로 바로 재생

#### 완료 기준
- 3개 MP3 파일이 Obsidian 볼트 내에 생성됨
- 각 파일에 50개 문장이 3초 간격으로 포함
- 음성이 명확하고 자연스러움
- Obsidian에서 `![[파일명]]`으로 재생 가능

### 기능 4: 빈칸 채우기 퀴즈

#### 입력
- 해당 문법의 핵심 용법 + 한국인 오류 패턴

#### 처리
- **문제 수**: 20문제
- **출제 원칙**:
  - 예문 섹션의 문장을 그대로 재활용하지 않음 (새 문장)
  - 해당 문법의 핵심 포인트를 테스트하는 빈칸 설계
  - 한국인이 자주 틀리는 패턴을 집중 출제
  - 빈칸 위치: 문법의 핵심 부분 (동사 형태, 조동사, 전치사 등)
  - 난이도: 초급 7개 / 중급 7개 / 고급 6개로 혼합

#### 출력 형태
```markdown
## ✏️ 빈칸 채우기 퀴즈

**1.** I _______ (live) in Seoul for five years.
> [!success]- 정답
> have lived / have been living
> **해설**: 과거부터 현재까지 계속되는 상황이므로 현재완료 사용

**2.** She _______ (never / try) sushi before.
> [!success]- 정답
> has never tried
> **해설**: 경험을 나타내는 현재완료. never는 have/has와 과거분사 사이에 위치
```

#### 완료 기준
- 20문제 (초7/중7/고6)
- 정답 + 한국어 해설이 callout으로 숨겨져 있음
- 해당 문법의 다양한 용법을 커버
- 문제가 학습에 실질적으로 도움이 됨 (단순 암기가 아닌 이해 테스트)

### 기능 5: 스피킹 연습 — 한→영 변환

#### 입력
- 해당 문법의 용법 + 난이도 정보

#### 처리

**Stage 1: 한→영 유도 (40문장)**

A. **영어 어순 한국어 (20개)**: 한국어를 영어 어순으로 재배열해서 제공. 번역을 쉽게 유도.
```
나는 / 먹었다 / 점심을 / 이미
→ I have already eaten lunch.
```

B. **자연 한국어 어순 (20개)**: 일반적인 한국어 어순 그대로. 더 높은 사고 전환 요구.
```
나는 이미 점심을 먹었다.
→ I have already eaten lunch.
```

- 정답은 callout으로 숨김
- 예문 섹션과 다른 새 문장 사용

**Stage 2: 프리토킹 상황 (5개)**

해당 문법이 자연스럽게 나올 수 있는 대화 상황을 설정.

```markdown
### 상황 1: 친구와 여행 계획
당신은 친구와 다음 휴가 계획을 이야기하고 있습니다.
친구가 "Have you ever been to Japan?"이라고 물었습니다.
이 대화를 이어가 보세요. (현재완료를 사용하여 경험, 완료, 계속을 표현해보세요)
```

#### 출력 형태
```markdown
## 🗣️ 스피킹 연습

### Part A: 영어 어순 한국어 → 영어 (20개)

**1.** 나는 / 살아왔다 / 서울에 / 5년 동안
> [!success]- 정답
> I have lived in Seoul for five years.

### Part B: 자연 한국어 → 영어 (20개)

**1.** 나는 5년 동안 서울에 살아왔다.
> [!success]- 정답
> I have lived in Seoul for five years.

### Part C: 프리토킹 상황 (5개)
(상황 설명만 제공, 정답 없음)
```

#### 완료 기준
- Part A: 20개 (영어 어순 한국어 + 정답 callout)
- Part B: 20개 (자연 한국어 + 정답 callout)
- Part C: 5개 상황 (다양한 맥락)
- 모든 문장이 해당 문법 사용을 자연스럽게 유도

### 기능 6: 유튜브 추천

#### 입력
- 문법 토픽명

#### 처리
1. 웹 검색으로 해당 문법 관련 한국인 영어 교육 유튜브 영상 탐색
2. **선별 기준**:
   - 한국인 유튜버의 콘텐츠 (한국어로 설명)
   - 해당 문법에 대한 직접적인 강의 영상
   - 조회수/채널 구독자 등 품질 지표 고려
   - 설명이 정확하고 실용적인 콘텐츠
3. 3~5개 영상 추천

#### 출력 형태
```markdown
## 🎬 추천 유튜브 영상

1. **[채널명] — [영상 제목]**
   - 링크: [URL]
   - 왜 추천: [한 줄 설명]

2. ...
```

#### 완료 기준
- 최소 3개 영상 추천
- 모든 영상이 해당 문법에 직접 관련
- 한국인 유튜버 (한국어 설명)

## 3. 기술 제약 & 의존성

| 항목 | 선택 | 비고 |
|------|------|------|
| **실행 환경** | Cowork Skill | Claude가 직접 콘텐츠 생성 + 도구 호출 |
| **TTS** | edge-tts (Python) | 무료, Microsoft Neural TTS |
| **음성** | en-US-AriaNeural | 여성, 명확한 발음 |
| **오디오 처리** | pydub + ffmpeg | 무음 삽입, MP3 결합 |
| **출력** | Obsidian MCP | 노트 직접 생성 + 파일 저장 |
| **검색** | WebSearch tool | 문법 리서치 + 유튜브 탐색 |

### 필요 패키지
```
edge-tts
pydub
ffmpeg (시스템)
```

### 비용
- **edge-tts**: 무료 (제한 없음)
- **Claude API**: 스킬 실행 시 소비되는 토큰 (Cowork 구독 내)
- **총 예상 비용**: $0 (추가 비용 없음)

## 4. 안 하는 것 (스코프 제한)

- ❌ 발음 교정 / STT (음성 인식) — 별도 프로젝트로 분리
- ❌ 학습 진행 추적 / 통계 — 이번 버전에서는 자료 생성에만 집중
- ❌ 자동 복습 스케줄 (Anki 연동 등) — 향후 확장 고려
- ❌ 영어 외 다른 언어 지원
- ❌ 사용자 답변 채점 — 퀴즈 정답은 제공하지만 자동 채점은 하지 않음

## 5. 파일 구조

## 6. 전체 파이프라인 흐름

```
사용자 입력: "Present Perfect"
        │
        ▼
[Step 1] 문법 딥 리서치 (웹 검색 3회+)
        │
        ▼
[Step 2] 개념서 작성 (한국어)
        │
        ▼
[Step 3] 예문 150개 생성 (초50/중50/고50)
        │
        ▼
[Step 4] edge-tts → 오디오 3개 생성
        │
        ▼
[Step 5] 빈칸 채우기 퀴즈 20문제
        │
        ▼
[Step 6] 스피킹 연습 (한→영 40개 + 상황 5개)
        │
        ▼
[Step 7] 유튜브 추천 (3~5개)
        │
        ▼
[Step 8] Obsidian에 전체 출력
```

## 7. 리스크 & 대응

| 리스크 | 영향 | 대응 |
|--------|------|------|
| edge-tts 서비스 중단 | 오디오 생성 불가 | gTTS로 대체, 또는 Kokoro TTS |
| 예문 품질 불균일 | 학습 효과 저하 | 생성 후 자체 검증 단계 추가 |
| Obsidian 볼트 경로 오류 | 파일 저장 실패 | 볼트 구조 사전 확인 로직 |
| 한 세션 내 토큰 한계 | 150개 예문 생성 중 컨텍스트 부족 | 단계별로 나눠 생성 + 중간 저장 |
| 유튜브 검색 결과 부정확 | 부적절한 영상 추천 | 검색 키워드 최적화 + 결과 필터링 |

## 8. 검증 계획

### 파이프라인 검증
- [ ] 테스트 토픽 "Present Perfect"으로 전체 파이프라인 1회 실행
- [ ] 생성된 노트 구조가 설계대로인지 확인
- [ ] 오디오 파일이 Obsidian에서 정상 재생되는지 확인
- [ ] callout 접기/펴기가 정상 동작하는지 확인

### 콘텐츠 품질 검증
- [ ] 문법 설명이 정확하고 포괄적인지 확인
- [ ] 예문 150개 중 비문(ungrammatical)이 없는지 검토
- [ ] 난이도 구분이 적절한지 확인
- [ ] 퀴즈가 학습에 실질적으로 도움이 되는지 확인
- [ ] 스피킹 연습의 한국어가 자연스러운지 확인
