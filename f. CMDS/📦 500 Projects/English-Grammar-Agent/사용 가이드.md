# English Grammar Learning Agent — 사용 가이드

## 빠른 시작

### 1. 프로젝트 폴더에서 Claude Code 실행
```bash
cd Grammer_generater
claude
```
Claude Code가 `CLAUDE.md`를 자동으로 읽고 프로젝트 맥락을 파악한다.

### 2. TTS 테스트 (최초 1회)
```
/tts-test
```
Kokoro-82M이 설치/작동되는지 확인. 실패하면 edge-tts로 자동 폴백.

### 3. 문법 토픽으로 전체 파이프라인 실행
```
/generate Present Perfect
/generate Relative Clauses
/generate Conditionals
```
토픽 이름을 영어로 입력하면 전체 파이프라인이 자동 실행된다.

---

## 파이프라인 흐름 (자동)

```
입력: "Present Perfect"
  │
  ├─ [1] 🧠 웹 리서치 (3회+, ultrathink 교차검증)
  ├─ [2] 개념서 작성 (한국어, 8개 섹션)
  ├─ [3] 💡🧠 예문 150개 (brainstorm 설계 → ultrathink 생성)
  ├─ [4] TTS 오디오 3개 (Kokoro / edge-tts 폴백)
  ├─ [5] 🧠 빈칸 퀴즈 20문제 (ultrathink 출제)
  ├─ [6] 스피킹 연습 (영어어순 20 + 자연 한국어 20 + 상황 5)
  ├─ [7] 유튜브 추천 (한국인 유튜버 3~5개)
  └─ [8] Obsidian 출력
```

예상 소요 시간: **25~40분**

## 학습 순서 (추천)

1. **📖 문법 설명** 먼저 읽기 — 개념 이해
2. **🎧 초급 예문** 오디오 틀어놓고 반복 듣기 — 패턴 익히기
3. **🎧 중급 → 고급** 순서대로 올라가기
4. **✏️ 퀴즈** 풀어보기 — 이해도 확인
5. **🗣️ Part A** (영어 어순 한국어) — 쉬운 영작부터
6. **🗣️ Part B** (자연 한국어) — 실전 영작
7. **💬 프리토킹** — 혼자 말해보기 or 파트너와 연습

## 품질 강화 포인트

파이프라인에서 3개 핵심 단계에 extended thinking이 적용된다:

| 단계 | 기법 | 효과 |
|------|------|------|
| Step 1 리서치 | ultrathink | 소스 간 모순 식별, 누락 용법 방지 |
| Step 3 예문 | brainstorm → ultrathink | 사전 설계 후 생성. 패턴 반복/교과서식 방지 |
| Step 5 퀴즈 | ultrathink | 한국인 오류 패턴 기반 출제 |

## 팁

- **첫 실행은 "Present Perfect"로** — 가장 보편적인 문법이라 품질 확인하기 좋음
- **결과물 마음에 안 들면** — Claude Code에서 바로 수정 요청 가능
- **TTS 품질이 별로면** — `tts-config.md`에서 음성 프리셋 변경 (af_bella 등)
- **예문이 부자연스러우면** — `example-sentences.md` 규칙에 구체적 금지 패턴 추가
- **새 문법 추가할 때마다** `/generate [토픽]` 만 입력하면 됨
