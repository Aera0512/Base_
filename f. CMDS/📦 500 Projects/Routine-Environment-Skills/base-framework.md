# 환경 설계 기본 토대 — 뇌과학 기반 프레임워크

> **관련 스킬**: [[environment-architect-SKILL]]
> **프로젝트 홈**: [[PRD]]

이 문서는 environment-architect 스킬이 **매번** 참조하는 기본 원칙 모음이다.
어떤 습관/목적이 입력되든, 이 원칙들은 항상 적용된다.

---

## 1. 마찰 조절 원칙

### 원하는 행동: 마찰을 최소화한다
- 습관 트리거를 팔 닿는 곳에 배치한다 (명상 쿠션→소파 옆, 물병→책상 위)
- 환경 구성 요소를 미리 준비한다 (운동복→전날 밤에 꺼놓기, 책→읽는 의자 위에 펼쳐놓기)
- 근접성 원칙: 원하는 행동 큐는 가까이, 원치 않는 큐는 멀리
- "결정 단계"를 제거한다 — 최소 저항 경로가 올바른 경로가 되게 설계

### 원치 않는 행동: 마찰을 최대화한다
- 10초 이상의 지연을 추가한다 (SNS 로그아웃, 앱 차단기 사용)
- 물리적으로 거리를 둔다 (간식→높은 선반, 핸드폰→다른 방 서랍)
- 자동성을 깨는 작은 장애물을 설치한다 (의식적 결정을 강제)
- 기술적 차단을 사용한다 (쿠키 삭제, 자동완성 비활성화)

### 핵심 수치
- 같은 장소에서 반복되는 일상 행동: 45%
- 10초 지연만으로 원치 않는 행동 감소: ~22%
- 건강한 음식 가시성 증가 시 소비 증가: 48%
- 정크푸드 숨겼을 때 소비 감소: 23%

## 2. 시각적 큐 설계

### 원칙
일상 행동의 45-65%가 환경 큐에 의해 촉발된다. 시각적 큐는 바실 갱글리아를 통해 ~0.3초 내에 습관 패턴을 활성화한다.

### 배치 규칙
- **전략적 배치**: 해당 맥락에 접근할 때 가장 먼저 보이는 곳에 습관 트리거를 놓는다
- **경쟁 큐 제한**: 한 습관 공간에 최대 1-3개 큐만 유지한다
- **시각적 돌출**: 트리거는 공간에서 가장 먼저 눈에 띄어야 한다
- **다중감각 큐**: 시각 + 촉각 (질감 있는 물체) + 위치를 결합한다
- 4개 이상의 큐는 시각적 혼잡을 만들어 효과를 감소시킨다

### 습관별 큐 예시
- 독서: 의자 위에 책을 쌓아놓는다 (선반에 꽂지 않는다)
- 운동: 완전한 운동복 세트를 신발과 함께 펼쳐놓는다
- 명상: 쿠션 + 타이머를 함께 보이게 놓는다
- 수분 섭취: 물병은 책상 중앙에, 컵은 커피메이커 옆에

## 3. 디폴트 설정 심리학

### 원칙
기본값은 현상 유지 편향과 정신적 노력 감소를 활용해 행동을 형성한다. 대부분의 사람은 변경에 최소한의 노력만 필요해도 기본 설정을 유지한다.

### 적용 영역
- **핸드폰**: 업무 시간에 방해금지/Focus 모드를 기본값으로 설정
- **이메일**: 보관을 기본 동작으로 (삭제가 아닌)
- **앱**: 최소 알림을 기본으로, 활성화하려면 행동 필요
- **기기**: 저녁에 다크 모드, 그레이스케일, 블루라이트 필터 기본 활성화
- **일정**: 기본 작업 블록을 50분 집중 + 10분 휴식으로 설정

## 4. 주의력 경쟁 원칙 (Princeton Neuroscience)

### 원칙
시야 내 물체가 많을수록 뇌가 필터링에 더 많은 인지 자원을 소모한다. 지속적인 억제는 전체 인지 용량을 감소시킨다.

### 물리적 공간 기본값
- **즉각 시야 내 물체**: 최대 3-5개 (이상적: 1-2개)
- **1차 작업 공간 (책상)**: 현재 프로젝트 자료 + 컴퓨터만
- **2차 공간 (선반)**: 눈높이 이하, 컨테이너로 시각적 복잡성 감소
- **배경/벽**: 벽당 최소 포스터 (1-2개 최대), 무늬 > 단색
- **케이블**: 전부 숨기거나 케이블 트레이로 정리
- **바닥**: 책상 아래 의자 다리 외에 아무것도 없게

### ADHD 연관성
어수선함 감소가 일부 사람에게 환경적 약물치료만큼 효과적이라는 연구 결과가 있다.

## 5. 유혹 묶기 (Temptation Bundling)

### 원칙
피할 수 없는 즐거운 활동("원하는 것")을 의지력이 필요한 행동("해야 하는 것")과 짝짓는다.

### 핵심 수치
- 주간 운동 10-14% 증가 (매력적인 오디오북과 결합 시)

### 구현 패턴
1. 높은 의지력이 필요한 작업 식별 ("해야 하는 것")
2. 즉각적 만족을 주는 활동 식별 ("원하는 것")
3. "원하는 것"에 대한 접근을 "해야 하는 것" 수행에 의존하게 만든다
4. 일관성 유지 — 항상 이 활동들을 짝짓는다

### 예시
- 운동 + 좋아하는 팟캐스트 (운동할 때만 청취 허용)
- 독서 + 특정 편안한 의자 + 음료
- 집중 블록 완료 + SNS 허용 시간
- 학습 + 좋아하는 매체 (유튜브 교육 콘텐츠 등)

## 6. 물리적 환경 기본값

이 값들은 어떤 목적이든 기본으로 권장된다. 목적별 최적화에서 조정될 수 있다.

### 조명
| 맥락 | 색온도 | 조도 | 비고 |
|------|--------|------|------|
| 집중 작업 | 5000-6500K | 300-500 lux | LED, CRI ≥90 |
| 일반 사무 | 4000-5000K | 300-400 lux | 오버헤드 |
| 이완/저녁 | 3000K | ~100 lux | 취침 2-3시간 전 전환 |
| 수면 전 | 1500-2000K | <50 lux | 촛불/캔들과 유사 |

### 온도
| 맥락 | 목표 온도 | 비고 |
|------|-----------|------|
| 집중 작업 | 22-23°C | 약간 시원하게 |
| 주의력 중요 작업 | 21-22°C | 더 시원 = 더 각성 |
| 수면 | 18-19°C | 체온 하강 촉진 |

### 소음
| 맥락 | 권장 | 데시벨 |
|------|------|--------|
| 딥워크 | 화이트노이즈 또는 악기 음악 | 60-65 dB |
| 루틴 작업 | 가사 있는 음악 OK | 50-60 dB |
| 학습/기억 | 화이트노이즈 | 60-70 dB |
| ADHD/주의력 이슈 | 화이트노이즈 강력 권장 | 60-65 dB |

### 공기질
- CO2 800 ppm 미만 유지 (최적 인지)
- 1-2시간마다 15-30분 창문 개방
- 1200 ppm 초과 시 90분마다 10분 실외 휴식

### 인체공학 (작업 시)
- 20/8/2 규칙: 20분 앉기, 8분 서기, 2분 움직이기
- 모니터: 상단이 눈높이, 50-70cm 거리
- 팔꿈치: 몸에 가까이, 90-110도 각도

### 색상 심리학
| 공간 기능 | 주요 색상 | 이유 |
|-----------|-----------|------|
| 집중 작업 | 파랑/초록 | 심박수↓, 코르티솔↓, 집중↑ |
| 창의 작업 | 노랑/주황 | 창의적 사고 자극 |
| 균형 인지 | 초록 | 눈의 피로↓, 문제해결↑ |

## 7. 디지털 환경 기본값

### 알림 관리
- **딥워크 중**: 모든 알림 비활성화 (비행기 모드 또는 DND)
- **이메일**: 하루 3회 수동 확인 (예: 9시, 12시, 15시)
- **메시지**: 90분마다 또는 매시간 확인
- **SNS**: 하루 1-2회 고정 시간

핵심 수치:
- 인터럽션 후 재집중까지: 평균 23분 15초
- 멀티태스커 오류율: 50% 증가
- 5초 인터럽션만으로 오류율: 3배 증가

### 앱/웹사이트 차단
- **업무 시간**: 완전 차단 (비활성화 불가)
- **저녁**: 15-30분 윈도우만 허용
- **밤**: 설정 시간 이후 완전 차단
- **모든 플랫폼 커버**: 폰 + 컴퓨터 + 브라우저 (간격 있으면 전체 전략 무력화)

권장 도구:
- iOS: Screen Time + Focus Modes
- macOS/Windows: Cold Turkey (가장 제한적), Freedom
- 브라우저: LeechBlock NG, News Feed Eradicator

### 그레이스케일 모드
- 스크린 타임 22-50분 감소 (연구 기반)
- **일과 중**: 컬러 (정상)
- **저녁 6PM**: 그레이스케일 + DND
- **밤 10PM**: 그레이스케일 + 수면 Focus Mode

### 핸드폰 프리 존 & 타임
**시간:**
- 식사 시: 핸드폰 없음
- 기상 후 1시간: 핸드폰 프리
- 취침 전 1시간: 완전 핸드폰 프리

**장소:**
- 침실: 핸드폰 아예 없음 (외부 충전 스테이션)
- 식탁: 가방/서랍에
- 화장실: 밖에 두기
- 운동 공간: 다른 방이나 가방

### Focus Mode 스케줄 (iOS/Android)
| 모드 | 시간 | 허용 | 설정 |
|------|------|------|------|
| 업무 집중 | 8AM-6PM | 가족 전화만 | 알림 전체 음소거 |
| 수면 | 10PM-7AM | 긴급 연락처 1명 | 그레이스케일 + 자동 |
| 운동 | 운동 시간 | 없음 | 완전 무음 |
| 딥워크 | 설정 시간 | 없음 | 모든 알림 비활성화 |

## 8. 시간 환경 기본값

### 역산 스케줄링 (취침 23:00 기준 예시)
| 시간 | 행동 제한 |
|------|-----------|
| 14:00 전 | 마지막 카페인 (9시간 전) |
| 20:00 전 | 마지막 식사 (3시간 전) |
| 20:00 전 | 마지막 격한 운동 (3시간 전) |
| 21:00 | 스크린 줄이기 시작 (2시간 전) |
| 22:00 | 침실 환경 전환 (1시간 전) |
| 22:00-22:30 | 모든 스크린 종료 |

### 습관 형성 타임라인
- 1-3일: 높은 유혹, 의식적 노력 필요
- 4-7일: 유혹 감소, 습관 형성 시작
- 2-4주: 습관 고착, 자연스러워짐
- 1개월+: 새로운 정상 상태

## 9. 사회적 환경 기본값

### 책임 파트너
- 습관 규칙을 누군가에게 알리고 리마인드를 요청한다
- 규칙을 공유하면 준수율이 유의미하게 상승한다

### 디지털 디톡스 공유 규칙
- 식사 시 핸드폰 규칙을 가족/동거인과 합의한다
- 업무 시간 "집중 중" 표시를 주변에 알린다

### 30일 디지털 디클러터 (Cal Newport)
- 비필수 기술을 30일간 제거한다
- 필수 업무 도구 + 1-2개 의도적 앱만 유지한다
- 이 기간에 무엇이 진짜 가치를 주는지 재평가한다
- 30일 후 가치가 확인된 것만 조건부로 재도입한다
