## 핵심 철학

> 의지력은 유한한 자원이다. 환경이 행동을 결정하도록 설계하면, 의지력은 보조 수단이 된다.

---

## 3층 구조

### 1층: 기본 토대 (매번 자동 적용)

`references/base-framework.md` 참조. 어떤 목적이든 항상 적용:

- **마찰 조절**: 원하는 행동↓마찰 / 원치 않는 행동↑마찰
- **시각적 큐 설계**: 바실 갱글리아 0.3초 자동 반응, 1-3개 큐 제한
- **디폴트 설정 심리학**: 기본값이 행동을 지배
- **주의력 경쟁 원칙**: 시야 내 자극 3-5개 이하
- **유혹 묶기**: 즐거운 활동 + 의지력 필요 활동 페어링

---

### 2층: 환경 영역별 구체 설정 (목적에 따라 선택 적용)

| 영역 | 항목 |
|------|------|
| **물리적 공간** | 조명(색온도/조도), 온도, 소음, 공기질, 정리 상태, 색상, 인체공학 |
| **디지털 환경** | 알림(DND/Focus Mode), 앱/웹 차단, 그레이스케일, 핸드폰 프리 존, 스크린 타임 |
| **시간 환경** | 시간대 행동 제한, 역산 스케줄링, 타이머/미션 알람, 루틴 시퀀스(큐 체이닝) |
| **사회적 환경** | 책임 파트너, 공유 규칙(동거인/가족), 공개 약속 |

---

### 3층: 목적 특화 최적화 (동적 리서치)

사용법: `/environment-architect [만들고 싶은 습관이나 목적]`

1. **목적 분석** — 목표 정확히 파악
2. **현재 환경 질문** — 실제 생활 공간, 기기, 제약 조건 파악
3. **특화 리서치** (ultra think) — WebSearch로 해당 목적에 최적화된 환경 설정 방법 검색 (최소 3개 소스)
4. **1층 + 2층 + 3층 결합** — 종합 설계
5. **환경 변경 명령서 출력**

## 핵심 원칙

1. **구체성이 생명** — 앱 이름, 설정 경로, 정확한 시간, 정확한 위치를 명시
2. **강제성을 두려워하지 마라** — Cold Turkey(끌 수 없음), 핸드폰 물리적 격리, 라우터 시간제 차단 등 강력한 수단 권장
3. **모든 권장에 뇌과학 근거 포함** — "좋아 보여서"는 금지
4. **실제 생활 공간 고려** — 원룸/아파트, 동거인 유무, 스마트 기기 유무 반드시 파악
5. **점진적 구현 고려** — 우선순위를 매기고 단계별 구현 계획 제시 (사용자 원하면 한꺼번에도 가능)
6. **ultra think 필수** — 특화 리서치 결합 + 상황 맞춤 최적화에 깊은 추론 필요
