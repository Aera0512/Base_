## 1. 크로노타입 & 시간대 배치

인지 성능은 하루 중 예측 가능하게 변동한다. 작업 유형을 피크 인지 윈도우에 맞추면 산출물 품질이 극적으로 향상된다.

### 시간대별 권장 작업

| 시간대 | 작업 유형 | 이유 |
|--------|----------|------|
| **09:00-11:30** (오전 피크) | 분석·논리·코딩·글쓰기·중요 의사결정 | 전두엽 활동 피크, 코르티솔이 각성 지원 |
| **11:30-13:00** (점심 전) | 행정·이메일·미팅 | 약간의 하락, 루틴 업무에 적합 |
| **13:00-15:00** (식후 저하) | 가벼운 행정, 짧은 낮잠(20-30분) | 서카디안 저점 + 식후 졸림 |
| **15:00-17:00** (오후 회복) | 협업·브레인스토밍·리뷰 | 중간 각성, 사회적 상호작용이 에너지 부스트 |
| **19:00-21:00** (저녁 창의) | 창의적 아이디어, 자유 사고, 개인 프로젝트 | 전두엽 억제 감소 → 넓은 연합적 사고 |

> 올빼미형: 전체 2-3시간 후방 이동 / 종달새형: 1-2시간 전방 이동

## 2. 울트라디안 90분 주기 (BRAC)

뇌는 ~90분 주기로 높은 각성과 낮은 각성을 반복한다 (Basic Rest-Activity Cycle).

### 구현 규칙

- **90분 집중** → **15-20분 능동적 휴식**
- 하루 최대 **4-5 집중 블록** (이후 수확체감)
- 블록 중간에 미팅 예약 금지
- 블록 1개 = 주제/맥락 1개 (맥락 전환 최소화)
- 30분 미만 작업은 유사 작업끼리 묶어서 한 블록에

### 휴식 품질 기준

| 순위 | 휴식 유형 | 회복 효과 |
|------|----------|----------|
| 1 | 자연 노출 (15-20분 녹지 산책) | ⭐⭐⭐⭐⭐ |
| 2 | 신체 활동 (스트레칭, 요가) | ⭐⭐⭐⭐ |
| 3 | 사회적 연결 (업무 외 대화) | ⭐⭐⭐⭐ |
| 4 | 감각 휴식 (눈 감기, 조용한 환경) | ⭐⭐⭐ |
| 5 | 낮잠 (20-30분, 13:00-15:00) | ⭐⭐⭐ |
| 6 | 엔터테인먼트 (소설, 가벼운 미디어) | ⭐⭐ |
| 7 | SNS 스크롤 | ❌ 음(-)의 회복 |

## 3. 의지력 고갈 곡선

자기 통제, 의사결정, 집중 주의는 유한한 일일 풀에서 인출된다. 주로 수면·식사·휴식으로 보충.

### 스케줄링 원칙

**높은 의지력 작업 → 오전에 배치:**
어려운 결정, 유혹 저항, 복잡한 인지 작업, 새로운 학습

**낮은 의지력 작업 → 오후에 배치:**
루틴 행정, 습관화된 작업, 즐거운 작업, 운동(오히려 에너지를 줌)

### 의지력 보존 전략

- 가능한 한 사전 결정 (일일 결정 수 감소)
- 아침 루틴/의식으로 자동화
- 규칙적 식사 (포도당이 실행기능 지원)
- 전략적 카페인: 기상 후 90분에 (코르티솔 경쟁 회피), 마지막 컵 14시 전

## 4. 주의 잔여 & 맥락 전환

Task A → Task B 전환 시 주의의 일부가 Task A에 "고착". 이 잔여가 Task B 성능을 최대 23분간 저하시킴.

### 스케줄링 규칙

- **유사 작업 묶기**: 이메일 한 블록, 창의 작업 한 블록
- **하루 주요 작업 유형 2-3개로 제한**
- **맥락 간 버퍼 5-10분** (책상 정리, 다음 작업 목표 확인, 짧은 산책)
- **미팅 → 딥워크 전환 시 15분+ 버퍼 필수**
- **미완료 작업 "닫기 의식"**: 멈춘 지점 + 다음 단계를 적어놓으면 잔여 감소

### 맥락 카테고리 (같은 블록 내 유지)

| 카테고리 | 예시 |
|----------|------|
| 분석 | 코딩, 데이터 분석, 재무 작업 |
| 창의 | 글쓰기, 디자인, 브레인스토밍 |
| 행정 | 이메일, 스케줄링, 정리 |
| 사회 | 미팅, 전화, 협업 |
| 학습 | 독서, 강의, 노트 정리 |

## 5. 전략적 휴식 설계

휴식은 작업의 부재가 아니라 인지 자원을 복원하는 능동적 과정이다.

### 전략적 낮잠 프로토콜

- **타이밍**: 13:00-14:30 (서카디안 저점에 맞춤)
- **길이**: 20-26분 (30분+ → 수면 관성 발생)
- **커피 낮잠**: 낮잠 직전 커피 → 카페인이 ~20분 후 작동
- **금기**: 불면증이 있거나 수면 부채가 있으면 낮잠 회피

### 저녁 회복 (다음 날 준비)

- 일정한 시간에 업무 종료 (이상적: 18-19시)
- **셧다운 의식**: 내일 리뷰, 3가지 우선순위 기록, 모든 업무 탭 닫기
- 셧다운 후 업무 관련 콘텐츠 금지
- 저녁은 운동 또는 사회적 시간

## 6. 수면 압력 관리

수면 품질이 다음 날 인지 용량을 직접 결정한다.

### 목표 취침 시간에서 역산 (예: 23:00 취침)

| 역산 시간 | 행동 |
|-----------|------|
| -9시간 (14:00) | 마지막 카페인 |
| -3시간 (20:00) | 마지막 식사, 마지막 격한 운동 |
| -2시간 (21:00) | 스크린 줄이기 시작 |
| -1시간 (22:00) | 침실 환경 전환, 모든 스크린 종료 |

### 수면 건축 보호

- 일정한 기상 시간 (주말 포함, ±30분)
- 기상 30분 내 빛 노출 (10,000 lux 또는 실외)
- 침실 18-19°C, 암막 커튼/수면 마스크
- 취침 3시간 내 알코올 금지 (REM 수면 파괴)

## 7. Rize 리포트 분석 가이드

### 일간 리포트에서 추출할 것

| 지표 | 의미 |
|------|------|
| 총 집중 시간 | 실제 딥워크 시간 |
| 집중/방해 비율 | 생산성 효율 |
| 최장 집중 구간 | 피크 퍼포먼스 실제 타이밍 |
| 주요 방해 앱/사이트 | 디지털 환경 개선 포인트 |
| 카테고리별 시간 | 우선순위 정렬 상태 |
| 미팅 시간 비율 | 딥워크 가용 시간 압박 정도 |

### 주간 리포트에서 추출할 것

- 주간 트렌드 (상승/하락)
- 요일별 패턴 (어떤 요일이 최고/최저?)
- 시간대별 실제 집중 패턴 (계획 vs 실제)
- 방해 트렌드 (같은 방해 요소 반복?)
- 카테고리 균형 (시간 배분이 우선순위와 정렬?)

### 분석 프레임워크 (매 리포트 적용)

1. **갭 분석**: 의도한 스케줄 vs 실제 행동 괴리
2. **패턴 감지**: 반복되는 실패 지점 (같은 시간, 같은 앱, 같은 맥락)
3. **밝은 점 식별**: 잘 되고 있는 것 → 보호/강화
4. **근본 원인**: 왜 방해가 발생했나? (환경? 알림? 에너지 저하?)
5. **구체적 조정**: 다음 기간을 위한 1-3개 실행 가능한 변경
6. **진척 추적**: 이전 권장사항이 실행되었는가?
