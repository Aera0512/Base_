# Writing Coach PRD

> **프로젝트명**: Writing Coach — 영어 에세이 글쓰기 코치 에이전트
>
> **목적**: 주제별 어휘 학습 → 에세이 작성 → 3라운드 점진적 교정 → 오류 추적의 완전 자동화 파이프라인으로 영어 글쓰기 실력을 체계적으로 향상시킨다
>
> **아키텍처**: Claude Cowork 스킬 (obsidian-to-anki 스킬 연동)
>
> **파이프라인**: pipeline-full (중형)
>
> **최종 수정**: 2026-03-18 | 버전: 0.1 (초안)

---

## Phase 1 요약

| 항목 | 확정 내용 |
|------|----------|
| **What** | 주제별 어휘 → 에세이 작성 → 3라운드 교정 → 오류 추적 통합 에이전트 |
| **Why** | 어휘 학습과 글쓰기 교정을 분리하지 않고, 하나의 파이프라인으로 통합하여 실전 글쓰기 실력 향상 극대화 |
| **Who** | 1인 사용 (중상급/Upper-intermediate, 한국어 L1) |
| **Where** | Claude Cowork 스킬 → Obsidian 볼트 저장 + Anki 연동 |
| **When** | 주 2~3회 에세이 연습 세션 |
| **How** | 주제 선정 → 어휘 생성 & Anki 카드 → 사용자 에세이 작성 → 3라운드 교정 (Grammar → Clarity → Style) → 오류 프로필 업데이트 |

## Phase 2 요약 (리서치 결과)

### 기존 도구 분석

| 도구 | 강점 | 약점 (우리가 해결할 것) |
|------|------|----------------------|
| LanguageTool / Harper | 문법 교정 정확도 높음 | 다단계 피드백 없음, 학습 추적 없음 |
| WriteHERE | 재귀적 글쓰기 계획 | 학습자 피드백 없음, 어휘 통합 없음 |
| Grammarly | 스타일 제안 우수 | 한국어 L1 간섭 미지원, SRS 연동 없음 |
| Anki + 수동 카드 | SRS 효과 검증됨 | 글쓰기 오류 → 카드 변환 수동 |

### 교육학적 근거

- **인지 부하 이론**: 모든 피드백을 한꺼번에 주면 학습 효과 저하 → 3라운드 점진적 교정이 최적
- **간격 반복 + 글쓰기 통합**: 실제 오류에서 추출한 SRS 카드가 일반 단어장보다 2-3배 높은 retention rate
- **L1 간섭 특화**: 한국어 화자의 체계적 오류 패턴 (관사, 주어-동사 일치, 시제, 전치사, 직역)을 우선 교정하면 효율적
- **CEFR 기반 평가**: 레벨별 비교를 통해 학습자가 목표를 시각적으로 파악 가능

### 핵심 차별점 (기존 도구에 없는 것)

1. **어휘 → 글쓰기 → 교정 → SRS 완전 자동화 파이프라인**
2. **3라운드 점진적 교정 + 직접 수정 사이클** (읽기만 하는 것보다 2-3배 효과적)
3. **한국어 L1 간섭 특화 교정**
4. **세션 간 오류 추적 + 개인화**

## 기능 요구사항

### REQ-1: 주제 선정 & 어휘 생성

- **입력**: 사용자 지정 주제 또는 "추천해줘" 요청
- **처리**:
  1. 주제 추천 시: 시사/사회 이슈와 개인 관심사를 번갈아 추천 (난이도 표시 포함)
  2. 주제 확정 후 3가지 카테고리의 어휘 생성:
     - **주제별 핵심 어휘** (8-10개): 해당 주제에 필수적인 단어 + 콜로케이션
     - **에세이 연결어/표현** (5-7개): 논리 전개에 필요한 담화 표지
     - **B2-C1 고급 어휘** (3-5개): 현재 수준에서 한 단계 높은 어휘
  3. 각 어휘에 예문, 콜로케이션, 한국어 의미, IPA 발음 포함
  4. 에세이 구조 제안 (서론-본론-결론 가이드)
- **출력**: 어휘 리스트 + 에세이 가이드라인
- **수락 기준**: 어휘가 주제와 직접 관련되고, B2-C1 수준에 적합하며, 실제 에세이에서 자연스럽게 활용 가능

### REQ-2: Anki 플래시카드 자동 생성

- **입력**: REQ-1에서 생성된 어휘 리스트
- **처리**:
  1. obsidian-to-anki 스킬을 호출하여 CTP-English 카드 생성
  2. 덱 이름: `Obsidian::English::Writing-Coach::{주제명}`
  3. 각 카드에 Word, Phonetic, POS, Meaning_KR, Meaning_EN, Example_EN, Example_KR, Synonyms, Frequency 필드 완성
- **출력**: Anki에 추가된 플래시카드
- **수락 기준**: 모든 어휘가 카드로 생성되고, 예문이 자연스럽고 문맥적으로 정확

### REQ-3: 에세이 작성 안내

- **입력**: 사용자의 글쓰기 준비 완료 신호
- **처리**:
  1. 제공된 어휘 중 최소 5개 이상 활용하도록 안내
  2. 목표 단어 수 제안 (200-300 단어, 사용자 조절 가능)
  3. 시간 제한 제안 (선택적, 시험 대비 모드 시 25분)
  4. 사용자가 에세이를 완성하여 제출할 때까지 대기
- **출력**: 작성 가이드라인 메시지
- **수락 기준**: 명확한 작성 지침 제공, 압박감 없이 동기 부여

### REQ-4: Round 1 교정 — Grammar & Mechanics

- **입력**: 사용자가 작성한 에세이 원문
- **처리**:
  1. **한국어 L1 간섭 오류 우선 검출**:
     - 관사 (a/the) 누락 또는 오용
     - 주어-동사 수 일치 오류
     - 단복수형 혼동
     - 시제 일관성 위반
     - 전치사 오용 (한국어 직역)
     - 직역 표현 (Konglish → Natural English)
  2. 일반 문법 오류 검출: 철자, 구두점, 문장 구조
  3. 각 오류에 대해:
     - 원문에서 오류 위치 표시
     - 왜 틀렸는지 간결한 설명 (한국어)
     - 교정 제안 (대안 2-3개 가능)
     - L1 간섭 오류인 경우 "🇰🇷 한국어 간섭" 태그 표시
- **출력**: 인라인 교정 피드백 (원문 대비 수정 사항 명확히 표시)
- **수락 기준**: 문법 오류 90% 이상 검출, L1 간섭 오류 명시적 표시, 설명이 학습자 수준에 맞게 간결

### REQ-5: Round 2 교정 — Clarity & Coherence

- **입력**: 사용자가 Round 1 피드백 반영하여 수정한 에세이
- **처리**:
  1. **문장 수준**: 모호한 표현, 불필요한 반복, 어색한 문장 구조
  2. **단락 수준**: 주제문(topic sentence) 존재 여부, 뒷받침 문장의 관련성
  3. **글 전체 수준**: 서론-본론-결론 구조, 논리 흐름, 전환(transition) 자연스러움
  4. 각 피드백에:
     - 구체적 위치와 이유
     - 개선 방향 제안 (직접 고쳐주는 것이 아니라 방향 제시)
     - 해당 부분에서 활용 가능한 연결어/표현 제안
- **출력**: 구조/명확성 중심 피드백
- **수락 기준**: 논리적 일관성 평가 포함, 구체적이고 실행 가능한 제안, 단순 "이 부분이 약합니다"가 아닌 방향 제시

### REQ-6: Round 3 교정 — Style & Sophistication

- **입력**: 사용자가 Round 2 피드백 반영하여 수정한 에세이
- **처리**:
  1. **어휘 다양성**: 반복 사용된 단어 지적, 대체어 제안
  2. **레지스터 적절성**: 에세이에 맞는 격식 수준 확인
  3. **세련된 표현**: 단순한 표현 → 고급 표현 업그레이드 제안
  4. **수사적 기법**: 적절한 곳에 강조, 대비, 예시 등 기법 제안
  5. **레벨별 비교 리라이트**:
     - 🟢 **초급 (A2-B1)**: 같은 내용을 초급 수준으로 쓴 버전
     - 🟡 **중급 (B1-B2)**: 중급 수준 버전
     - 🟠 **중상급 (B2-C1)**: 현재 목표 수준 (사용자의 최종 수정본과 비교)
     - 🔴 **상급 (C1-C2)**: 원어민 수준의 세련된 버전
  6. 각 레벨 간 차이점 설명 (무엇이 레벨을 나누는지)
- **출력**: 스타일 피드백 + 4레벨 비교 리라이트
- **수락 기준**: 레벨별 차이가 명확하고, 사용자가 "여기서 여기로 가려면 이것을 바꿔야 한다"를 이해할 수 있어야 함

### REQ-7: 오류 프로필 관리

- **입력**: 각 라운드에서 검출된 오류 데이터
- **처리**:
  1. Obsidian `writing-coach/error-profile.md`에 누적 오류 기록 관리
  2. 오류 유형별 분류 & 빈도 추적:
     - L1 간섭 (관사, 시제, 전치사, 직역 등)
     - 문법 (주어-동사 일치, 복수형, 구두점 등)
     - 구조 (논리 흐름, 전환, 주제문 등)
     - 스타일 (어휘 다양성, 레지스터 등)
  3. 다음 세션 시작 시 프로필을 읽어서 맞춤 가이드 제공:
     - "지난 3회 세션에서 관사 오류가 12회 발생했습니다. 이번에 특히 주의해보세요."
     - 개선 추세 표시 ("시제 일관성은 지난달 대비 40% 감소했습니다 👍")
  4. 세션별 기록 저장: `writing-coach/sessions/YYMMDD-{주제}.md`
- **출력**: 업데이트된 오류 프로필 + 세션 기록 노트
- **수락 기준**: 오류 분류가 정확하고, 추세 추적이 가능하며, 다음 세션에서 실제로 참고됨

### REQ-8: 오류 기반 Anki 카드 생성

- **입력**: 교정 과정에서 발견된 오류 문장들
- **처리**:
  1. 반복적인 오류 패턴에서 학습 카드 생성
  2. **CTP-Cloze 카드**: 오류 문장의 교정 버전을 Cloze로 변환
     - 예: "The government {{c1::has}} implemented new policies." (수 일치)
  3. **CTP-Knowledge 카드**: 문법 규칙 Q&A
     - 예: Q: "한국어에는 없는 영어 관사 규칙 중, 처음 언급할 때는?" A: "'a/an'을 사용..."
  4. 덱: `Obsidian::English::Writing-Coach::Error-Cards`
- **출력**: 오류 기반 Anki 카드
- **수락 기준**: 카드가 실제 오류에서 추출되고, 같은 실수를 반복하지 않도록 설계됨
