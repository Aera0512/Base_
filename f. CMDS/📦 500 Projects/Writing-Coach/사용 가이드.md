# Writing Coach 사용 가이드

> 영어 에세이 글쓰기 실력을 체계적으로 향상시키는 AI 코치

---

## 시작하기

### 사전 준비

1. **Anki 데스크탑 앱** 실행 + **AnkiConnect** 플러그인 설치 (Add-on 코드: `2055492159`)
2. **Obsidian MCP** 연결 확인
3. Claude Code 또는 Cowork에서 사용 가능

### 실행 방법

아래 중 아무 말이나 하면 스킬이 자동으로 활성화됩니다:

- \"글쓰기 연습하자\"
- \"에세이 써볼까\"
- \"writing practice\"
- \"영작 도와줘\"

---

## 워크플로우

세션 시작 시 두 가지 모드 중 선택합니다:

### Mode A: 자유 글쓰기 (출력 능력 훈련)

```
A. 오류 프로필 로드 → 모드 선택
   ↓
B. 주제 선정 (직접 지정 or AI 추천)
   ↓
C. 어휘 제공 (16-22개) + Anki 카드 자동 생성
   ↓
D. 에세이 작성 (200-500 단어, 어휘 5개+ 활용)
   ↓
E. Round 1: 문법 교정 (한국어 L1 간섭 우선) → 수정 후 재제출
   ↓
F. Round 2: 구조/명확성 교정 → 수정 후 재제출
   ↓
G. Round 3: 스타일 + 4레벨 비교 리라이트
   ↓
H. 세션 마무리 (오류 프로필 업데이트 + 오류 Anki 카드)
```

### Mode B: 역번역 연습 (입력+모방 능력 훈련)

```
A. 오류 프로필 로드 → 모드 선택
   ↓
B2. 주제 선정
   ↓
C2. 모범문 확보 + 한국어 번역만 제공 (원문은 숨김)
   ↓
D2. 한국어 보고 영어로 직접 작성
   ↓
E2. 원문 공개 + 가이디드 비교 (구문/어휘/연결 3카테고리)
   → 수정 후 재제출
   ↓
F2. 수정본 재비교 + 개선점 강조
   ↓
H2. 세션 마무리 (배운 표현 TOP 3 + 오류 프로필 + Anki 카드)
```

두 모드는 **같은 오류 프로필을 공유**합니다. 자유 글쓰기에서 발견된 약점이 역번역에서도 추적되고, 반대도 마찬가지입니다.

## 핵심 기능

### 1. 3라운드 점진적 교정

각 라운드는 하나의 관점에만 집중합니다. 한꺼번에 모든 피드백을 받는 것보다 단계별로 받는 것이 학습 효과가 2-3배 높습니다.

| Round | 초점 | 직접 수정 |
|-------|------|----------|
| Round 1 | 문법 & 기계적 오류 (관사, 시제, 전치사 등) | O |
| Round 2 | 구조 & 명확성 (논리 흐름, 주제문, 전환) | O |
| Round 3 | 스타일 & 세련됨 (어휘 다양성, 레지스터) + 4레벨 비교 | - |

### 2. 한국어 L1 간섭 특화

한국어 화자가 영어에서 체계적으로 하는 6가지 실수를 우선 잡아줍니다:

| ID | 유형 | 예시 |
|----|------|------|
| L1-1 | 관사 누락/오용 | \"I like ~~Ø~~ music\" → \"I like **the** music\" |
| L1-2 | 주어-동사 수 일치 | \"He ~~go~~\" → \"He **goes**\" |
| L1-3 | 단복수형 혼동 | \"many ~~student~~\" → \"many **students**\" |
| L1-4 | 시제 일관성 | 과거 서술 중 갑자기 현재형 |
| L1-5 | 전치사 오용 | \"go ~~to~~ home\" → \"go home\" |
| L1-6 | 직역 표현 | \"I'm very ~~interest~~\" → \"I'm very **interested**\" |

### 3. 4레벨 비교 리라이트

Round 3에서 에세이의 핵심 단락을 4개 수준으로 다시 써서 보여줍니다:

- **초급 (A2-B1)**: 단문, 기본 어휘
- **중급 (B1-B2)**: 복문, 주제 어휘
- **중상급 (B2-C1)**: 콜로케이션, 논리적 전환 ← 목표 수준
- **상급 (C1-C2)**: 수사적 기법, 원어민 수준

### 4. 오류 프로필 누적 추적

매 세션 후 `writing-coach/error-profile.md`에 오류 패턴이 자동 저장됩니다. 다음 세션 시작 시 \"지난 3회 관사 오류 8회. 오늘 포커스: 관사\" 같은 맞춤 가이드를 받습니다.

### 5. 어휘 Anki 카드 자동 생성

주제별 어휘가 Anki에 자동으로 카드로 만들어집니다. 덱: `Obsidian::English::Writing-Coach::{주제}`

### Mode B의 핵심: 가이디드 비교

역번역 연습의 학습 효과는 **원문과 비교하는 과정**에서 나옵니다. 에이전트가 3가지 카테고리로 체계적으로 비교해줍니다:

| 카테고리 | 무엇을 비교하나 | 예시 |
|---------|---------------|------|
| 구문 (Syntax) | 문장 구조의 차이 | 내가 쓴 "I think it is good" vs 원문 "It has proven beneficial" |
| 어휘 (Vocabulary) | 단어 선택의 차이 | "important" vs "indispensable" |
| 연결 (Cohesion) | 문장 간 연결 방식 | "And also..." vs 분사구문 "enabling..." |

각 차이점에 대해 **왜 원문이 더 효과적인지** 설명해주므로, 단순히 "틀렸다/맞다"가 아닌 표현의 수준 차이를 이해할 수 있습니다.

## 팁

- **라운드 건너뛰기**: \"Round 2 건너뛸래\" 하면 가능 (비추천)
- **시간 제한 모드**: 시험 대비 시 \"25분 제한으로 해줘\" 요청
- **주제 추천**: \"추천해줘\" 하면 시사 이슈와 개인 관심사를 번갈아 추천
- **중간 종료**: 언제든 그만둘 수 있음. 그때까지의 오류 데이터는 자동 저장
- **Anki 없이도 사용 가능**: Anki가 꺼져 있으면 카드 생성만 건너뛰고 교정은 정상 진행
