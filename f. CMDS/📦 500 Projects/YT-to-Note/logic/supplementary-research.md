## 5-1. 핵심 개념/용어 추출

노트 생성 후, 보충자료가 필요한 항목을 자동 추출한다.

### 추출 대상

| 대상 | 소스 | 검색 방법 |
|------|------|----------|
| 핵심 용어 | 중간 결과물의 `glossary[]` | 용어별 웹 검색 |
| 핵심 기술/도구 | `chapters[].content.terms[]` | 공식문서 검색 |
| 인용된 연구 | `chapters[].content.evidence[]` | 논문/연구 검색 |
| 비교 대상 기술 | 비교표의 항목들 | 각 기술 공식문서 |

### 추출 프롬프트

```
다음 노트 데이터에서 보충자료 검색이 필요한 항목을 추출하세요.

규칙:
1. 전문 용어 중 추가 설명이 도움될 것들
2. 영상에서 언급된 도구/라이브러리/프레임워크의 공식문서
3. 인용된 연구/논문의 원본 출처
4. 비교 대상의 상세 정보

출력 (JSON):
{
  "search_queries": [
    {"type": "official_doc", "term": "용어", "query": "검색어"},
    {"type": "research", "term": "연구", "query": "검색어"},
    {"type": "tutorial", "term": "용어", "query": "검색어"},
    {"type": "deep_dive", "term": "용어", "query": "검색어"}
  ]
}

최대 8개로 제한하세요.
```

## 5-2. 웹 검색 보충자료 수집

### 검색 전략 (장르별)

**tech**:
```
검색 우선순위:
1. 공식 문서 (site:docs.* OR site:github.com)
2. 튜토리얼 (site:medium.com OR site:dev.to)
3. 심화 아티클 (기술 블로그, 컨퍼런스 토크)
```

**knowledge**:
```
검색 우선순위:
1. 원본 연구/논문 (scholar OR research paper)
2. 신뢰할 수 있는 도서 추천
3. 관련 TED/강연 영상
```

**english**:
```
검색 우선순위:
1. 문법서/사전 (site:dictionary.cambridge.org OR site:grammarly.com)
2. 연습 사이트 (interactive exercises)
3. 유사 학습 콘텐츠
```

### 검색 도구

Claude 내장 웹 검색 사용:
```
도구: WebSearch
파라미터:
  query: "{{검색어}}"
```

### 검색 결과 필터링 프롬프트

```
다음 검색 결과에서 학습에 가장 유용한 자료를 선별하세요.

선별 기준:
1. 신뢰성: 공식 문서 > 저명한 블로그 > 개인 블로그
2. 관련성: 노트의 핵심 주제와 직접 관련
3. 접근성: 무료 접근 가능, 한국어 또는 영어
4. 실용성: 읽으면 이 노트의 이해가 깊어지는 자료

출력 형식:
| 자료 | 유형 | 왜 읽어야 하는지 |
```

## 5-3. 용어 사전 보강

중간 결과물의 `glossary`를 웹 검색으로 보강한다.

### 보강 프롬프트

```
다음 용어 사전을 보강하세요.

현재 용어 목록:
{{glossary from JSON}}

규칙:
1. 각 용어의 정의가 정확한지 웹 검색으로 크로스체크
2. 한 줄 정의가 너무 추상적이면 구체화
3. "이 영상에서의 맥락" 열에 영상 내 사용 맥락 기록
4. 볼트 내 관련 노트가 있으면 [[링크]] 추가 (Task 6에서 처리)

출력:
| 용어 | 정의 | 맥락 |
```

## 5-4. 보충자료 통합 포맷

### 최종 보충자료 섹션 형태

```markdown
## 보충자료

| 자료 | 유형 | 왜 읽어야 하는지 |
|------|------|-----------------|
| [React Server Components 공식 문서](URL) | 공식문서 | Chapter 1의 RSC 개념을 더 깊이 이해할 수 있음 |
| [Dan Abramov의 RSC 설명 블로그](URL) | 아티클 | 비교표에서 다룬 SSR vs RSC 차이를 실제 코드로 보여줌 |
| [Next.js App Router 튜토리얼](URL) | 튜토리얼 | Chapter 3의 실전 적용을 직접 따라할 수 있는 가이드 |
```

### 품질 기준

- 최소 2개, 최대 5개 자료
- 각 자료마다 "이 노트의 어떤 부분"과 연결되는지 명시
- 깨진 링크 방지: 검색 시점에 접근 가능한 URL만 포함
- 유료 콘텐츠는 명시: "(유료)" 표시

## 5-5. 전체 보충자료 수집 플로우

```
[노트 생성 완료]
    │
    ├─ 1. 핵심 용어/개념 추출 (최대 8개)
    │
    ├─ 2. 장르별 검색 전략으로 웹 검색
    │     ├─ tech: 공식문서 → 튜토리얼 → 심화
    │     ├─ knowledge: 연구 → 도서 → 강연
    │     └─ english: 문법서 → 연습 → 유사 콘텐츠
    │
    ├─ 3. 검색 결과 필터링 (신뢰성/관련성/접근성)
    │
    ├─ 4. 용어 사전 보강
    │
    ├─ 5. 보충자료 섹션 조립
    │     └─ | 자료 | 유형 | 왜 읽어야 하는지 |
    │
    └─ 6. 노트에 삽입 (용어 사전 + 보충자료 섹션)
```

## 검증 기준

- [ ] 핵심 용어당 최소 1개 이상 신뢰할 수 있는 보충 출처
- [ ] 보충자료 2~5개가 노트에 포함됨
- [ ] 각 자료에 "왜 읽어야 하는지"가 노트 내용과 연결됨
- [ ] 용어 사전의 정의가 정확함 (웹 검색 크로스체크)
- [ ] URL이 유효함 (접근 가능)
