# Second Conditional (가정법 과거)

---

## 📖 문법 설명

### 1. 핵심 개념

**Second Conditional은 현재 사실과 반대이거나 미래에 일어날 가능성이 낮은 상상/가정을 표현하는 문법 구조다.**

### 2. 왜 이 문법이 존재하는가

Second Conditional이 존재하는 이유:

- **현실과 다른 상상을 표현**: "If I were rich, I would travel the world." (나는 부자가 아니지만 상상)
- **가능성이 낮은 미래를 표현**: "If I won the lottery, I would quit my job." (복권 당첨 가능성 낮음)
- **조언/제안을 부드럽게 전달**: "If I were you, I would apologize." (직접적 명령 회피)
- **희망사항/꿈을 표현**: "If I could fly, I would visit every country."
- **가설적 상황에서 결과 예측**: "What would you do if you lost your job?"

### 3. 기본 형태 & 구조

#### 기본 공식
```
If + 주어 + 과거동사, 주어 + would + 동사원형
```

#### 구조 상세
| If절 (조건) | 주절 (결과) |
|-------------|-------------|
| If + S + **과거동사** | S + **would** + 동사원형 |
| If + S + **were** | S + **would** + 동사원형 |

#### 긍정문 / 부정문 / 의문문
| 형태 | 예문 |
|------|------|
| 긍정문 | If I had money, I **would buy** a car. |
| 부정문 | If I had money, I **wouldn't waste** it. |
| 의문문 | **Would** you help me if I asked? |
| What if | **What would** you do if you won? |

#### 축약형
- would → 'd (I'd, you'd, he'd, she'd, we'd, they'd)
- would not → wouldn't
- If I were → 구어체에서 If I was도 사용

### 4. 핵심 용법

#### 용법 1: 현재 사실의 반대 (Unreal Present)
> *If I **had** more time, I **would learn** Japanese.*
> (사실: 나는 시간이 없다)

> *If she **knew** the answer, she **would tell** us.*
> (사실: 그녀는 답을 모른다)

#### 용법 2: 미래의 낮은 가능성 (Unlikely Future)
> *If I **won** the lottery, I **would quit** my job.*
> (복권 당첨 가능성이 매우 낮음)

> *If aliens **landed** tomorrow, what **would** you do?*
> (일어날 가능성이 거의 없음)

#### 용법 3: 조언/제안 (Advice)
> *If I **were** you, I **would apologize** to her.*
> (부드러운 조언)

> *If I **were** in your position, I **wouldn't accept** that offer.*
> (상대방 입장에서의 제안)

#### 용법 4: 상상/꿈 (Dreams/Imagination)
> *If I **could** fly, I **would visit** every country.*
> (불가능한 상상)

> *If I **were** invisible, I **would sneak** into concerts.*
> (비현실적 가정)

#### 용법 5: 가설적 질문 (Hypothetical Questions)
> *What **would** you do if you **found** a wallet on the street?*
> *How **would** you react if your boss **fired** you?*

### 5. 시간 표현 / 신호 단어

Second Conditional과 자주 쓰이는 표현:

| 표현 | 예문 |
|------|------|
| If I were you | If I were you, I'd take the job. |
| If I were in your shoes | If I were in your shoes, I'd be careful. |
| What if | What if we missed the train? |
| Suppose/Supposing | Suppose you had a million dollars, what would you do? |
| Imagine | Imagine you could live anywhere. Where would you go? |

### 6. 비슷한 문법과의 비교

#### First Conditional vs Second Conditional

| First Conditional | Second Conditional |
|-------------------|-------------------|
| **가능성 높음** | **가능성 낮음/불가능** |
| If + 현재, will + 동사원형 | If + 과거, would + 동사원형 |
| If it rains, I **will** stay home. | If it rained diamonds, I **would** be rich. |
| 실제 일어날 수 있는 상황 | 상상/비현실적 상황 |

#### 예시 비교
| 상황 | First (가능) | Second (가능성 낮음) |
|------|-------------|---------------------|
| 돈 | If I **have** enough money, I**'ll** buy new shoes. | If I **had** a million dollars, I **would** buy a yacht. |
| 날씨 | If it **rains**, we**'ll** cancel the picnic. | If it **rained** fire, we **would** all panic. |
| 시험 | If I **study** hard, I**'ll** pass. | If I **studied** 24/7, I **would** get a perfect score. |

#### Zero vs First vs Second Conditional

| 유형 | 용도 | 구조 |
|------|------|------|
| Zero | 항상 참인 사실 | If + 현재, 현재 |
| First | 실현 가능한 조건 | If + 현재, will + 동사원형 |
| Second | 비현실/낮은 가능성 | If + 과거, would + 동사원형 |

### 7. 한국인이 자주 틀리는 포인트

#### ❌ 오류 1: If절에 would 사용
| ❌ 틀린 표현 | ✅ 올바른 표현 |
|-------------|---------------|
| If I **would have** money... | If I **had** money... |
| If she **would know**... | If she **knew**... |

> 💡 **규칙**: If절에는 would 사용 금지! 과거 동사만 사용.

#### ❌ 오류 2: was 대신 were 사용 안 함 (격식체)
| ❌ 덜 격식적 | ✅ 격식적/표준 |
|-------------|---------------|
| If I **was** you... | If I **were** you... |
| If he **was** here... | If he **were** here... |

> 💡 **가정법에서는 were가 문법적으로 표준**이지만, 구어체에서 was도 많이 쓰임.

#### ❌ 오류 3: 시제 혼동 (First와 Second 혼동)
| ❌ 혼동 | ✅ 올바른 표현 |
|---------|---------------|
| If I win (현재), I would buy... | If I **won** (과거), I would buy... |
| If I had money, I will buy... | If I had money, I **would** buy... |

#### ❌ 오류 4: 조동사 과거형 누락
| ❌ 틀린 표현 | ✅ 올바른 표현 |
|-------------|---------------|
| If I had time, I **can** help. | If I had time, I **could** help. |
| If she were free, she **may** come. | If she were free, she **might** come. |

> 💡 **주절에서는 would 외에 could, might도 사용 가능**

#### ❌ 오류 5: 직역으로 인한 어순 오류
| ❌ 한국어 직역 | ✅ 올바른 영어 |
|---------------|---------------|
| If time I had... | If I had time... |
| I would if rich buy a car. | If I were rich, I would buy a car. |

### 8. 고급 뉘앙스 & 원어민 패턴

#### would 대신 could/might 사용

| 조동사 | 뉘앙스 | 예문 |
|--------|--------|------|
| would | 확실한 결과 | If I had time, I **would** help you. |
| could | 능력/가능성 | If I had time, I **could** help you. |
| might | 낮은 가능성 | If I had time, I **might** help you. |

#### 도치 구문 (Inversion) - 격식체
```
Were + S + ..., S + would + V
```

| 일반 | 도치 (격식) |
|------|-------------|
| If I were rich... | **Were I** rich... |
| If he were here... | **Were he** here... |
| If it were possible... | **Were it** possible... |

#### 혼합 가정법 (Mixed Conditional)
과거 조건 → 현재 결과

> *If I **had studied** medicine, I **would be** a doctor now.*
> (과거에 의학을 공부했다면 → 지금 의사일 텐데)

#### 원어민 구어체 패턴

**1. "I wish" + 과거동사 (Second Conditional과 같은 구조)**
> *I wish I **had** more money.* = If only I had more money.
> *I wish I **were** taller.* = If only I were taller.

**2. "If only" 강조 표현**
> *If only I **could** speak French!*
> *If only it **weren't** so expensive!*

**3. "What if" 대화체**
> *What if we **just** stayed home?*
> *What if I **told** you I loved you?*

**4. 주절 생략 (문맥상 명확할 때)**
> A: Would you take the job?
> B: If they paid me enough. (= I would take it if they paid me enough.)

> [!note]- 해석

> [!note]- 해석
> 신호가 더 좋다면, 네 말을 들을 수 있을 텐데.

### 친구 (Friends)

### 학교 (School)

### 여행 (Travel)
33. If I had a passport, I'd travel abroad.
> [!note]- 해석
> 여권이 있다면, 해외여행을 할 텐데.

> [!note]- 해석

> 휴가가 더 있다면, 유럽에 갈 텐데.

### 병원 (Hospital)
37. If I felt better, I'd go to work.
> [!note]- 해석
> 몸이 나아진다면, 출근할 텐데.

38. If the doctor came sooner, I'd be relieved.
> [!note]- 해석
> 의사가 더 빨리 온다면, 안심할 텐데.

> 대기 시간이 더 짧다면, 기다릴 텐데.

## 🎧 예문 — 중급 (Intermediate)

### 집 (Home)
1. If we could afford a renovation, we'd completely redesign the kitchen.
> [!note]- 해석
> 리모델링할 여유가 된다면, 주방을 완전히 새로 디자인할 텐데.

2. If I didn't have to commute, I'd consider moving to the countryside.
> [!note]- 해석
> 통근할 필요가 없다면, 시골로 이사하는 것을 고려할 텐데.

3. If our neighbors weren't so noisy, we'd be able to sleep better at night.
> [!note]- 해석
> 이웃이 그렇게 시끄럽지 않다면, 밤에 더 잘 잘 수 있을 텐데.

4. If I had the skills, I'd build all the furniture myself instead of buying it.
> [!note]- 해석
> 기술이 있다면, 가구를 사는 대신 직접 다 만들 텐데.

### 카페 (Cafe)
5. If they offered plant-based milk options, I'd come here more regularly.
> [!note]- 해석
> 식물성 우유 옵션을 제공한다면, 더 정기적으로 올 텐데.

6. If the barista remembered my usual order, it would save so much time.
> [!note]- 해석
> 바리스타가 내 단골 주문을 기억한다면, 시간이 많이 절약될 텐데.

7. If this place had outdoor seating, we could enjoy the nice weather.
> [!note]- 해석
> 이곳에 야외 좌석이 있다면, 좋은 날씨를 즐길 수 있을 텐데.

8. If I weren't trying to cut down on caffeine, I'd order a triple espresso.
> [!note]- 해석
> 카페인을 줄이려는 중이 아니라면, 트리플 에스프레소를 주문할 텐데.

### 직장 (Work)
9. If the company offered remote work options, employee satisfaction would improve significantly.
> [!note]- 해석
> 회사가 재택근무 옵션을 제공한다면, 직원 만족도가 크게 향상될 텐데.

10. If I had more authority in my position, I'd implement several changes immediately.
> [!note]- 해석
> 내 직책에 더 많은 권한이 있다면, 몇 가지 변화를 즉시 시행할 텐데.

11. If our team had a bigger budget, we could hire two more developers.
> [!note]- 해석
> 우리 팀에 더 큰 예산이 있다면, 개발자 두 명을 더 고용할 수 있을 텐데.

12. If the deadline weren't so tight, we'd be able to deliver higher quality work.
> [!note]- 해석
> 마감이 그렇게 촉박하지 않다면, 더 높은 품질의 작업을 제공할 수 있을 텐데.

### 쇼핑 (Shopping)
13. If I won a shopping spree, I'd buy everything on my wish list.
> [!note]- 해석
> 쇼핑 스프리에 당첨된다면, 위시리스트에 있는 모든 것을 살 텐데.

14. If this brand weren't tested on animals, I'd consider purchasing their products.
> [!note]- 해석
> 이 브랜드가 동물 실험을 하지 않는다면, 제품 구매를 고려할 텐데.

15. If online shopping didn't exist, I'd probably spend less money overall.
> [!note]- 해석
> 온라인 쇼핑이 존재하지 않는다면, 전반적으로 돈을 덜 쓸 것 같아.

16. If the return policy were more flexible, more customers would shop with confidence.
> [!note]- 해석
> 반품 정책이 더 유연하다면, 더 많은 고객들이 자신 있게 쇼핑할 텐데.

### 전화 (Phone)
17. If I weren't so dependent on my smartphone, I'd probably be more productive.
> [!note]- 해석
> 스마트폰에 그렇게 의존하지 않는다면, 아마 더 생산적일 텐데.

18. If the battery lasted longer, I wouldn't have to carry a charger everywhere.
> [!note]- 해석
> 배터리가 더 오래 간다면, 어디든 충전기를 들고 다닐 필요가 없을 텐데.

19. If my provider had better coverage, I could make calls from the countryside.
> [!note]- 해석
> 내 통신사 커버리지가 더 좋다면, 시골에서도 전화할 수 있을 텐데.

## ✏️ 빈칸 채우기 (Fill in the Blanks)

### 초급 (Beginner)
1. If I _______ (have) more money, I would buy a new phone.
> [!success]- 정답
> **had**
> Second Conditional: If + 과거동사

2. If she _______ (be) here, she would help us.
> [!success]- 정답
> **were** (격식) 또는 **was** (구어)
> 가정법에서는 were가 표준

3. I would travel more if I _______ (not have) to work.
> [!success]- 정답
> **didn't have**
> 부정: didn't + 동사원형

4. If it _______ (rain), we would stay home.
> [!success]- 정답
> **rained**
> Second Conditional: If + 과거동사

5. What _______ you do if you won the lottery?
> [!success]- 정답
> **would**
> 의문문: Would + S + 동사원형?

6. If I _______ (know) the answer, I would tell you.
> [!success]- 정답
> **knew**
> know의 과거형

### 중급 (Intermediate)
7. If I _______ (be) in your position, I wouldn't accept that offer without negotiating first.
> [!success]- 정답
> **were**
> "If I were you/in your position" 관용 표현

8. If the company _______ (offer) better benefits, more qualified candidates would apply.
> [!success]- 정답
> **offered**
> Second Conditional 조건절

9. She _______ (might/help) us if we explained the situation properly.
> [!success]- 정답
> **might help**
> 주절에 might 사용 가능 (낮은 가능성)

10. If he _______ (not be) so stubborn, we _______ (can/reach) a compromise.
> [!success]- 정답
> **weren't** (또는 wasn't) / **could reach**
> 부정 + 조동사 과거형

11. _______ I to win the competition, I would donate half the prize money to charity.

## 🔍 오류 교정 (Error Correction)

### 초급 (Beginner)
1. ❌ If I would have time, I would help you.
> [!success]- 정답 및 해설
> ✅ If I **had** time, I would help you.
> **해설**: If절에는 would 사용 불가. 과거동사(had)만 사용.

2. ❌ If she was you, she would apologize.
> [!success]- 정답 및 해설
> ✅ If she **were** you, she would apologize.
> **해설**: 가정법에서 be동사는 were가 표준 (특히 격식체).

3. ❌ If I win the lottery, I would buy a house.
> [!success]- 정답 및 해설
> ✅ If I **won** the lottery, I would buy a house.
> **해설**: Second Conditional은 If + 과거동사. win → won

4. ❌ If I had money, I will buy a car.
> [!success]- 정답 및 해설
> ✅ If I had money, I **would** buy a car.
> **해설**: 주절에는 will이 아닌 would 사용.

### 중급 (Intermediate)
5. ❌ If I would be rich, I would travel the world.
> [!success]- 정답 및 해설
> ✅ If I **were** rich, I would travel the world.
> **해설**: If절에 would 사용 불가. be동사의 가정법은 were.

6. ❌ If she knew the truth, she can understand our decision.
> [!success]- 정답 및 해설
> ✅ If she knew the truth, she **could** understand our decision.
> **해설**: 주절에서 조동사도 과거형 사용 (can → could).

7. ❌ If I have more experience, I would apply for that position.
> [!success]- 정답 및 해설
> ✅ If I **had** more experience, I would apply for that position.
> **해설**: If절은 과거 시제 (have → had).

8. ❌ What you would do if you lost your job?
> [!success]- 정답 및 해설
> ✅ What **would you** do if you lost your job?
> **해설**: 의문문 어순: What would + S + V?

### 고급 (Advanced)
9. ❌ Was I to know the consequences, I wouldn't have agreed.
> [!success]- 정답 및 해설
> ✅ **Were** I to know the consequences, I wouldn't **agree**.
> **해설**: 도치에서 Were 사용. 또한 Second Conditional이므로 wouldn't agree (would + 원형).

10. ❌ If it wasn't for your help, I will fail the exam.
> [!success]- 정답 및 해설
> ✅ If it **weren't** for your help, I **would** fail the exam.
> **해설**: 가정법에서 were 사용, 주절에 would 사용.

11. ❌ If the policy would be implemented, employees would benefit greatly.
> [!success]- 정답 및 해설
> ✅ If the policy **were** implemented, employees would benefit greatly.
> **해설**: If절에 would 불가. 수동태 가정법: were + PP

12. ❌ Were I knew about the problem, I would have fixed it earlier.
> [!success]- 정답 및 해설
> ✅ **Had** I **known** about the problem, I would have fixed it earlier.
> (Third Conditional로 수정)
> 또는 Second Conditional: **Were** I **to know** / If I **knew**
> **해설**: "Would have fixed"는 Third Conditional. 도치 구조도 맞춰야 함.

> [!success]- 모범 답안
> **Were** I not so introverted by nature, I **would probably have** a much larger social circle and **attend** more events.
>
> **격차 체크포인트:**
> - Were I not (도치 부정)
> - by nature (관용 표현)
> - would probably have and attend (병렬)
>
> **대안 표현:**
> - "Were I not so introverted" → "If I weren't so shy"

22. **교육이 사회경제적 지위에 관계없이 보편적으로 접근 가능하다면, 기회의 더 공평한 분배를 볼 수 있을 텐데.**
> [!success]- 모범 답안
> **Were** education universally accessible regardless of socioeconomic status, we **would see** a more equitable distribution of opportunities.
>
> **격차 체크포인트:**
> - Were + 주어 + 형용사 (도치)
> - regardless of (관계없이)
> - equitable distribution (콜로케이션)
>
> **대안 표현:**
> - "equitable distribution" → "fair allocation"

23. **제약 회사들이 주주 이익보다 환자 복지를 우선시한다면, 생명을 구하는 약이 보편적으로 저렴할 텐데.**
> [!success]- 모범 답안
> If pharmaceutical companies **prioritized** patient welfare over shareholder profits, life-saving medications **would be** universally affordable.
>
> **격차 체크포인트:**
> - prioritized A over B (A를 B보다 우선시)
> - would be universally affordable (보편적 접근)
>
> **대안 표현:**
> - "life-saving medications" → "essential medicines"

24. **탄소 상쇄 제도가 더 효과적이라면, 양심적인 여행자들이 환경 발자국에 대해 덜 죄책감을 느낄 수도 있을 텐데.**
> [!success]- 모범 답안
> **Were** carbon offsetting schemes more effective, conscientious travelers **might feel** less guilty about their environmental footprint.
>
> **격차 체크포인트:**
> - Were + 주어 + 형용사 (도치)
> - might feel (낮은 가능성)
> - environmental footprint (환경 용어)
>
> **대안 표현:**
> - "carbon offsetting schemes" → "carbon offset programs"
> - "conscientious travelers" → "environmentally aware tourists"

25. **정신 건강이 우리 사회에서 그렇게 오명화되지 않는다면, 더 많은 사람들이 판단에 대한 두려움 없이 전문적인 도움을 구할 텐데.**
> [!success]- 모범 답안
> If mental health **weren't** so stigmatized in our society, more people **would seek** professional help without fear of judgment.
>
> **격차 체크포인트:**
> - weren't so stigmatized (오명화 표현)
> - would seek (결과)
> - without fear of judgment (두려움 없이)
>
> **대안 표현:**
> - "stigmatized" → "looked down upon"
> - "professional help" → "therapy" / "counseling"

## 💬 프리토킹 상황 (Free Talking Situations)

### 상황 1: 인생에서 바꾸고 싶은 것
> 친구와 "만약 ~하다면"으로 시작하는 대화를 나누고 있습니다. 다음 주제에 대해 Second Conditional을 사용하여 이야기하세요:
> - 직업을 바꿀 수 있다면 무엇을 하고 싶은지
> - 어디든 살 수 있다면 어디에 살고 싶은지
> - 하루가 30시간이라면 무엇을 할 것인지

**연습 포인트**: If I could..., I would... / If I had..., I would...

### 상황 2: 사회 문제 토론
> 토론 수업에서 사회 문제에 대해 가상의 해결책을 제시해야 합니다. Second Conditional을 사용하여 다음 주제에 대해 의견을 말하세요:
> - 만약 교육이 완전히 무료라면
> - 만약 모든 사람이 기본 소득을 받는다면
> - 만약 플라스틱 사용이 금지된다면

**연습 포인트**: If education were..., students would... / Were the government to...

### 상황 3: 조언 구하기와 주기
> 친구가 어려운 결정을 앞두고 조언을 구합니다. "If I were you" 구문을 사용하여 조언을 주세요:
> - 직장을 그만둘지 고민하는 친구에게
> - 해외 유학을 갈지 고민하는 친구에게
> - 이사를 할지 고민하는 친구에게

**연습 포인트**: If I were you, I would... / If I were in your shoes, I'd...

## 📝 학습 정리

### 핵심 공식
```
If + 주어 + 과거동사, 주어 + would + 동사원형
```

### 도치 구문 (격식체)
```
Were + 주어 + ..., 주어 + would + 동사원형
Were I rich, I would travel. (= If I were rich)
```

### would 외 조동사
| 조동사 | 뉘앙스 | 예문 |
|--------|--------|------|
| could | 능력/가능성 | I could help if I had time. |
| might | 낮은 가능성 | I might go if I felt better. |

### 관용 표현
- **If I were you**: 조언할 때
- **If it weren't for**: ~이 없다면
- **What if**: 가정적 질문

### 꼭 기억할 것
1. **If절에 would 사용 금지**: If I would have ❌ → If I had ✅
2. **be동사는 were 권장**: If I was ❌ → If I were ✅ (격식)
3. **주절에 조동사 과거형**: can → could, may → might
4. **현재 상황의 반대** 또는 **가능성 낮은 미래**를 표현
