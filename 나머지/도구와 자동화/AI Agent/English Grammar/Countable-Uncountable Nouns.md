# 가산/불가산 명사 (Countable/Uncountable Nouns)

---

## 📖 문법 설명

### 1. 핵심 개념

### 가산/불가산 판단 기준
> **"하나, 둘 셀 수 있으면 가산 / 덩어리·추상개념·물질이면 불가산"**

### Quantifier 매칭표

| 가산명사 전용 | 불가산명사 전용 | 둘 다 가능 |
|:---:|:---:|:---:|
| many | much | some |
| few | little | any |
| several | — | a lot of |
| a number of | an amount of | plenty of |

> [!tip] 핵심 공식
> - **가산**: a/an 사용 가능, 복수형 존재, many/few 사용
> - **불가산**: a/an 사용 불가, 복수형 없음, much/little 사용

---

### 2. 왜 이 구분이 존재하는가

영어는 **개별 단위 vs 덩어리/물질** 이라는 개념적 차이를 명사 형태로 표현합니다.

### 개념적 차이

**가산명사의 사고방식**
- 책 1권, 책 2권, 책 3권... → 개별 단위로 세기
- "**개수**"를 세는 것이 자연스러움

**불가산명사의 사고방식**
- 물을 한 컵, 물을 두 컵... → "물"이라는 **물질 자체**는 불가산
- 물의 "양"을 측정해야 함

### 의미 변화 사례
```
furniture (불가산) = "가구 일반"
  → We need furniture for the living room.

a piece of furniture (가산화) = "가구 하나"
  → This is a beautiful piece of furniture.
```

---

### 3. 기본 형태 & 구조

### 가산명사 (Countable Nouns)
**개별적인 단위로 셀 수 있는 명사**
- 단수/복수 형태가 구분됨
- a/an 사용 가능
- 숫자와 직접 결합 가능

| 단수 | 복수 | 예문 |
|------|------|------|
| a book | two books | I have **three books** on my desk. |
| an apple | five apples | She bought **six apples** at the market. |
| a person | people/persons | There are **ten people** in the room. |

### 불가산명사 (Uncountable Nouns)
**덩어리, 물질, 추상적 개념으로 취급하는 명사**
- 복수형이 없음
- a/an 사용 불가
- 직접 숫자 사용 불가 (단위 표현 필요)

| 명사 | 특징 | 예문 |
|------|------|------|
| water | 액체 | **Water** is essential for life. |
| information | 추상명사 | I need **information** about the event. |
| furniture | 집합명사 | The **furniture** in this room is expensive. |

### 가산명사의 형태 변화

**규칙 변화**
- book → books
- cat → cats
- apple → apples

**불규칙 변화**
- child → children
- person → people
- mouse → mice
- man → men
- woman → women

### 이중 사용 명사 (문맥에 따라 가산/불가산)

| 명사 | 불가산 (일반적) | 가산 (특정 의미) |
|------|-----------------|-----------------|
| chicken | 고기 | 닭 (동물) |
| paper | 종이 | 신문, 논문 |
| glass | 유리 (물질) | 잔 (용기) |
| time | 시간 (추상) | 횟수 |
| coffee | 커피 (음료) | 커피 한잔 |
| experience | 경험 (일반) | 특정한 경험 |

**문맥별 사용**
```
불가산 (일반): I like chicken. (고기로서)
가산 (동물): There are three chickens in the farm. (동물로서)

불가산 (물질): Glass breaks easily.
가산 (용기): Can you pass me two glasses? (물을 담은 잔)

불가산 (추상): Experience is the best teacher.
가산 (구체): That was an interesting experience.
```

### 4. 핵심 용법

### 가산명사 사용법

**a/an + 단수형**
```
✅ I have a cat.
✅ She is an engineer.
✅ There is a problem.
```

**복수형 (관사 없음 또는 some, many 등)**
```
✅ I have cats. (일반적 단수형)
✅ I have some cats.
✅ I have many cats.
✅ There are three cats in the house.
```

### 불가산명사 사용법

**관사 없이 사용 (또는 the + 명사)**
```
✅ Information is important. (관사 없음)
✅ The information you gave me is helpful. (the 사용)
❌ An information is important. (a/an 불가)
❌ Informations are important. (복수형 불가)
```

**some, any, much 등의 quantifier 사용**
```
✅ I need some water.
✅ Do you have any luggage?
✅ There isn't much furniture in the room.
```

### 불가산명사를 셀 때: 단위 표현 필요

| 표현 | 예문 |
|------|------|
| a piece of + 불가산 | I need **a piece of furniture**. |
| a cup of + 음료 | Would you like **a cup of coffee**? |
| a glass of + 액체 | Can I have **a glass of water**? |
| a bottle of + 액체 | She drank **two bottles of water**. |
| a sheet of + 종이 | Give me **a sheet of paper**. |
| an item of + 일반 | That's **an item of clothing**. |

**예시**
```
❌ I have two luggages.
✅ I have two pieces of luggage. / I have two bags.

❌ Can you give me three furnitures?
✅ Can you give me three pieces of furniture? / Can you bring three chairs?
```

### 5. Quantifiers 완전 정복

### 가산명사 전용 Quantifiers

| Quantifier | 형태 | 예문 |
|------------|------|------|
| **many** | 많은 | **Many students** attended the lecture. |
| **few** | 거의 없는 (부정적) | **Few people** understood the concept. |
| **a few** | 몇 개의 (긍정적) | I have **a few** suggestions. |
| **several** | 여러 개의 | There are **several ways** to solve this. |
| **a number of** | ~개의 | **A number of** changes were made. |
| **each** | 각각 | **Each student** got a certificate. |
| **every** | 모든 (반복성) | **Every day**, I exercise. |

### 불가산명사 전용 Quantifiers

| Quantifier | 형태 | 예문 |
|------------|------|------|
| **much** | 많은 양 | There isn't **much time** left. |
| **little** | 거의 없는 양 (부정적) | We have **little** information. |
| **a little** | 약간의 양 (긍정적) | Add **a little** sugar to your tea. |
| **a great deal of** | 많은 양 | We spent **a great deal of** money. |
| **a bit of** | 조금의 | Can I have **a bit of** advice? |

### 양쪽 모두 사용 가능한 Quantifiers

| Quantifier | 가산 예시 | 불가산 예시 |
|------------|---------|-----------|
| **some** | I have **some books**. | I have **some water**. |
| **any** | Do you have **any questions**? | Is there **any sugar**? |
| **a lot of** | There are **a lot of** cars. | There is **a lot of** traffic. |
| **lots of** | **Lots of** people came. | **Lots of** snow fell. |
| **plenty of** | We have **plenty of** time. | We have **plenty of** food. |
| **enough** | Are there **enough** chairs? | Is there **enough** space? |
| **no** | There are **no mistakes**. | There is **no time**. |
| **all** | **All students** passed. | **All** information is correct. |

### few vs a few / little vs a little

| 표현 | 의미 | 뉘앙스 | 예문 |
|------|------|--------|------|
| **few** | 거의 없는 | 부정적 | Few people came. (거의 안 왔다) |
| **a few** | 몇 개의 | 긍정적 | A few people came. (몇 명 왔다) |
| **little** | 거의 없는 | 부정적 | There's little hope. (희망이 거의 없다) |
| **a little** | 약간의 | 긍정적 | There's a little hope. (희망이 조금 있다) |

### 6. 관사와의 조합

### a/an의 사용 규칙

**가산명사 단수형에만 사용**
```
✅ a book, an apple, a university, an hour
❌ a information, an advice, a furniture
```

**발음 규칙 (자음/모음 발음)**
```
✅ a university (유니버시티 = 자음 발음)
✅ an hour (아워 = 모음 발음)
✅ a one-year-old (원 = 자음 발음)
✅ an 8-year-old (에이트 = 모음 발음)
```

### the의 사용 규칙

**가산/불가산 모두 가능**
```
✅ The books on the shelf are interesting. (가산 복수)
✅ The furniture in the house is beautiful. (불가산)
✅ I like the coffee you made. (불가산)
```

### 무관사 사용

**불가산명사의 일반적 의미**
```
✅ Water is essential. (물 일반)
✅ Information changes constantly. (정보 일반)
✅ Children need education. (어린이들 일반)
```

```

```

```

```

### 4. people (이미 복수형)
```

✅ There are many people here.
```

```
❌ How many luggages do you have?

```

```

```

### 8. 고급 뉘앙스 & 원어민 패턴

### 의미 변화: 같은 단어, 다른 의미

**chicken**
```
불가산: Chicken tastes delicious. (고기)
가산: The chickens in the yard are noisy. (동물)
```

**experience**
```
불가산: Experience is the best teacher. (일반적 경험)
가산: That was an unforgettable experience. (특정 경험)
```

**coffee**
```
불가산: Do you like coffee? (음료 일반)
가산: Can I have two coffees, please? (두 잔의 커피, 구어체)
```

### 구어 vs 문어의 차이

**Less vs Fewer (구어에서 혼용)**
```
문법적 규칙:
- fewer + 가산명사
- less + 불가산명사

❌ There are less people now. (구어에서 자주 사용)
✅ There are fewer people now. (문어)

✅ Use less salt. (불가산, 맞음)
```

**Amount vs Number (자주 혼동)**
```
✅ a large number of students (가산, 정확)
❌ a large amount of students (불가산, 부정확)

✅ an amount of water (불가산, 정확)
❌ an amount of bottles (가산, 부정확)
```

### 고급 문법: 집합명사

**집합명사는 단수/복수 모두 가능**
```
영국 영어 (집단 = 여러 개체):
✅ The team are strong. (단수 집합, 복수 동사)

미국 영어 (집단 = 하나의 단위):
✅ The team is strong. (단수 집합, 단수 동사)
```

### 원어민도 혼동하는 경계선

**Data (기술적으로 복수형)**
```
학술적: Data shows that... (라틴어: datum의 복수)
실무적: The data are clear. (영국 영어)
현대적: The data is clear. (미국 영어, 점점 일반화)
```

#### 1. 냉장고 안 설명하기

**상황**: 당신의 냉장고 안에 있는 음식들을 친구에게 설명해보세요.

**사용해야 할 표현**: much, many, some, a little, a few, any, a lot of

> - much milk (불가산) / many vegetables (가산)
> - a few apples (가산, 긍정) / a little butter (불가산, 긍정)
> - some cheese / some oranges
> - aren't any eggs (부정문 + any)

#### 2. 새 집으로 이사하기

**상황**: 새 집으로 이사했습니다. 필요한 가구와 물건에 대해 이야기해보세요.

> [!success]- 모범 응답 예시

Unfortunately, I don't have much money left after paying the deposit, so I'll have to buy things gradually."
>
> **핵심 표현**:
> - much furniture / pieces of furniture (불가산 단위 표현)
> - a few chairs / many kitchen appliances (가산)
> - enough storage space / much money (불가산)
> - some equipment (불가산)

#### 3. 여행 준비하기

**상황**: 1주일간의 해외여행을 준비하고 있습니다. 짐 싸기에 대해 이야기해보세요.
