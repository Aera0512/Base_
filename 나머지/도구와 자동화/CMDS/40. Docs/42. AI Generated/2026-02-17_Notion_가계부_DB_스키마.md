# Notion 가계부 DB 스키마 (영상 구조 호환)

허브: [[나머지/도구와 자동화/CMDS/🏠 Vault Home]] · [[나머지/도구와 자동화/CMDS/40. Docs/42. AI Generated/Hub - 42. AI Generated]]


데이터베이스 이름: `가계부_자동입력`

속성(필드)
- `이름` (Title) → 예: `점심`, `교통비`
- `날짜` (Date)
- `금액` (Number)
- `분류` (Select)
  - 식비
  - 교통
  - 쇼핑
  - 구독
  - 생활
  - 의료
  - 여가
  - 기타
- `결제수단` (Select)
  - 카드
  - 현금
  - 계좌이체
  - 간편결제
- `메모` (Rich text)
- `월` (Formula)
  - `formatDate(prop("날짜"), "YYYY-MM")`
- `유형` (Select)
  - 지출
  - 수입

## 추천 뷰
1. `이번달` : 월 = 현재월, 날짜 내림차순
2. `카테고리별` : 분류 그룹
3. `결제수단별` : 결제수단 그룹
4. `수입/지출` : 유형 필터
