# 🧠 옵시디언을 위한 AI 리서치 에이전트 활용 가이드

인터넷의 방대한 정보를 수집하고 가공하여 옵시디언(Obsidian) 지식 베이스에 바로 통합할 수 있는 강력한 오픈소스 에이전트 3종과 효과적인 워크플로우 구축 방법입니다.

---

## 1. GPT-Researcher

- GitHub 링크: [https://github.com/assafelovic/gpt-researcher](https://github.com/assafelovic/gpt-researcher)
- 핵심 기능: 주제를 주면 스스로 하위 질문을 생성하고, 20개 이상의 웹사이트를 스크랩하여 서론-본론-결론이 갖춰진 종합 보고서를 작성합니다.

### 💡 효과적인 활용 방법

- **LLM 백엔드 연결**: 기본 모델 외에도 GPT나 Gemini Pro 등 강력한 모델을 API로 연결하여 보고서의 추론 및 요약 품질을 극대화할 수 있습니다.
- **연구 및 브리핑 자동화**: 깊이 있는 조사가 필요한 주제를 던져주고, 출력된 긴 형태의 마크다운(.md) 결과물을 옵시디언의 `Research`나 `Daily Notes` 폴더에 그대로 저장하여 인사이트 창고로 활용해 보세요.

---

## 2. STORM (Stanford OVAL)

- GitHub 링크: [https://github.com/stanford-oval/storm](https://github.com/stanford-oval/storm)
- 핵심 기능: 스탠포드 대학 연구진이 개발. 위키백과 편집자처럼 다각도로 질문을 던지며 탐색하고, 출처(Citation)가 명확히 달린 아티클을 생성합니다.

### 💡 효과적인 활용 방법

- **신뢰도 높은 팩트 검증**: 퍼플렉시티(Perplexity)처럼 정보의 출처를 중요하게 생각할 때 최적입니다. 생성된 문서 하단의 각주들을 옵시디언 레퍼런스 형식으로 유지하여 정보의 환각을 최소화할 수 있습니다.
- **위키형 지식망 구축**: 출력된 아티클 내의 소주제들을 옵시디언 고유의 위키 링크(`[[ ]]`)를 활용해 다른 노트들과 연결하면, 단단하고 체계적인 개인 백과사전을 구축하기 좋습니다.

---

## 3. Fabric

- GitHub 링크: [https://github.com/danielmiessler/fabric](https://github.com/danielmiessler/fabric)
- 핵심 기능: CLI(터미널) 기반의 워크플로우 프레임워크로, 유튜브 영상, 긴 기사, 팟캐스트 등을 입력받아 고품질 텍스트로 가공하는 수백 개의 검증된 프롬프트 패턴을 제공합니다.

### 💡 효과적인 활용 방법

- **CLI 도구 및 로컬 연계**: 터미널에서 구동되므로, Claude Code나 Claude MCP 서버를 함께 활용하여 로컬 파일 시스템 내의 옵시디언 볼트를 직접 다루며 문서 생성 및 편집을 지시하는 유연한 제어가 가능합니다.
- **자동화 파이프라인 통합**: n8n과 같은 자동화 툴과 연결하기 매우 좋습니다. RSS 피드나 북마크한 링크가 들어오면 n8n 파이프라인 내에서 Fabric의 특정 요약 패턴(예: `extract_wisdom`)을 거치게 한 후, 핵심만 깔끔하게 정리된 상태로 옵시디언에 자동 저장되도록 구성할 수 있습니다.
