# YT-to-Note 사용 가이드

> 유튜브 영상을 구조화된 학습 노트로 자동 변환하는 에이전트 스킬
> **버전**: 1.0 | **최종 수정**: 2026-03-04

---

## 한 줄 요약

유튜브 링크를 주면, 자막을 추출하고 AI가 분석하여 **책처럼 구조화된 학습 노트**를 옵시디언에 자동 저장한다.

---

## 사전 준비

### 필수 환경

| 항목 | 상태 | 설명 |
|------|:----:|------|
| YouTube Transcript MCP | ✅ 설치됨 | `@fabriqa.ai/youtube-transcript-mcp` — Claude Code에서 자막 추출 |
| Obsidian MCP | ✅ 연결됨 | 볼트 읽기/쓰기/검색 |
| Obsidian CLI | ✅ 설치됨 | 로컬에서 노트 조작 |
| Claude 웹 검색 | ✅ 내장 | 보충자료 수집용 |

### 설치 확인 (처음 한 번만)

YouTube Transcript MCP가 설치되어 있는지 확인:
```bash
claude mcp list
```

없으면 설치:
```bash
claude mcp add --scope user youtube-transcript npx @fabriqa.ai/youtube-transcript-mcp@latest
```

## 기본 사용법

### 1. 가장 간단한 방법

Claude Code 또는 Cowork에서 이렇게 말하면 된다:

```
이 영상 노트 만들어줘: https://www.youtube.com/watch?v=VIDEO_ID
```

이것만으로 전체 파이프라인이 실행된다:
1. 자막 추출
2. 장르 자동 판별 (tech / knowledge / english)
3. 구조화된 노트 생성
4. 보충자료 검색
5. 내부 링크 생성
6. `Yt-to-Note/`에 자동 저장

### 2. 장르를 직접 지정하고 싶을 때

```
이 영상 tech 노트로 만들어줘: https://youtube.com/watch?v=...
```

또는:
```
이 영어 학습 영상 노트 정리해줘: https://youtu.be/...
```

### 3. 시청일을 지정하고 싶을 때

```
이 영상 2026-02-28에 봤는데 노트 만들어줘: URL
```

기본값은 오늘 날짜.

## 지원하는 장르와 템플릿

### tech (기술/개발)

**적합한 영상**: 프로그래밍 튜토리얼, 기술 설명, 개발 도구 소개, 아키텍처 강의

**노트 구조**: 문제 상황 → 핵심 개념 → 비교표 → 비유 → 코드 & 실전 → 흔한 실수 → 이해도 체크

**특징**:
- 코드 블록 + 주석 해설
- 기술 비교표 (A 방식 vs B 방식)
- 실습 체크리스트 (Level 1~3)
- 공식문서 링크 자동 수집

### knowledge (지식/교양)

**적합한 영상**: 다큐, 강연, 심리학/경제/역사/과학, 자기계발, 건강

**노트 구조**: 배경 → 화자의 주장과 근거 → 비유 → 이해도 체크

**특징**:
- 연구/데이터 구체적 보존 (연구자명, N수, 수치)
- 종합 정리에 비판적 시각 포함
- 근거 강도 분석 (일화 vs 통제실험 vs 메타분석)

### english (영어 학습)

**적합한 영상**: 문법 강의, 영어 회화, 발음 교정, 시험 영어(TOEIC 등)

**노트 구조**: 왜 이게 어려운가 → 규칙 설명 → 패턴 구조 → 예문 분석 → 이해도 체크

**특징**:
- L1 간섭 분석 (한국어 → 영어 오류 원인)
- 뉘앙스 비교 표 (비슷한 표현의 미묘한 차이)
- ❌/⭕ 한국인 실수 표
- 핵심 표현 카드 (플래시카드 형식)
- 90일 복습 트래킹 (영어는 장기 반복 필요)

## 생성되는 노트 상세

### 파일 위치와 이름

```
Yt-to-Note/YT-{genre}-{YYMMDD}-{제목축약}.md
```

예시:
- `Yt-to-Note/YT-tech-260304-React-Server-Components.md`
- `Yt-to-Note/YT-knowledge-260228-도파민과-습관형성.md`
- `Yt-to-Note/YT-english-260301-가정법-과거완료.md`

### 공통 구성 요소

모든 장르의 노트에 포함되는 요소:

| 요소 | 설명 |
|------|------|
| **목차** | `[[#heading]]` 링크로 원클릭 이동 |
| **전체 영상 iframe** | 옵시디언 안에서 바로 영상 시청 |
| **마인드맵** | Mermaid 시각화로 전체 구조 한눈에 |
| **암기 포인트 표** | ★ 중요도별 핵심 정리 + 기억 고리 |
| **구간 가이드** | 챕터별 시간대 + 난이도 라벨 |
| **챕터별 구간 재생** | 해당 챕터만 반복 시청 가능 (`?start=&end=`) |
| **챕터별 이해도 체크** | 각 챕터 학습 후 자가 점검 체크박스 |
| **종합 정리 + 플로우차트** | 전체를 관통하는 큰 그림 |
| **용어 사전** | 핵심 용어 + 정의 + 맥락 + 내부 링크 |
| **셀프 테스트** | 노트 가리고 답해보기 |
| **최종 점검** | 이해도 + 간격 복습 트래킹 (1일/7일/30일) |
| **보충자료** | 웹 검색으로 수집한 참고 자료 |
| **내부 링크** | 볼트 내 관련 노트와 자동 연결 |

### 난이도 라벨

- `🟢 기초` — 배경지식 없이 이해 가능
- `🟡 중급` — 기본 개념 이해 전제
- `🔴 심화` — 깊은 이해 필요

### 프론트매터

```yaml
type: yt-note
genre: tech | knowledge | english
source: "[영상 제목](URL)"
channel: "채널명"
video_id: "VIDEO_ID"
date_watched: 2026-03-04
date_created: 2026-03-04
subtitle_lang: ko | en
tags: [yt-note, 장르, 주제태그들]
review: [null, null, null]     # 복습 기록
confidence: null               # 학습 후 자기 평가 (1~5)
status: processed
```

## 학습 워크플로

### 노트 생성 직후

1. **목차**로 전체 구조 파악
2. **마인드맵**으로 핵심 관계 시각화
3. **암기 포인트** ★★★ 항목 먼저 읽기

### 챕터별 학습

1. **구간 재생**으로 해당 챕터 영상 시청
2. 노트의 해당 챕터 정독
3. **이해도 체크** 체크박스 점검
4. 모르는 것 → 구간 재생으로 재시청

### 학습 마무리

1. **종합 정리** 읽고 큰 그림 확인
2. **셀프 테스트** — 노트 가리고 답해보기
3. **최종 점검** 체크박스 완료
4. **내 생각 & 연결** 직접 작성 (가장 중요!)

### 간격 복습

| 복습 | 시점 | 방법 |
|------|------|------|
| 1차 | +1일 | 암기 포인트 + 셀프테스트만 빠르게 |
| 2차 | +7일 | 전체 노트 훑고 이해도 체크 재점검 |
| 3차 | +30일 | 셀프테스트만, 틀린 부분 챕터 재학습 |
| 4차 | +90일 | 영어 장르만 (장기 기억 정착) |

복습 완료 시 프론트매터의 `review` 배열에 날짜 기록하고, 학습 체크리스트의 복습 체크박스 체크.

## 고급 사용법

### 노트 품질 높이는 팁

1. **장르를 직접 지정**하면 판별 오류 방지
2. **시청 후 바로 생성**하면 기억과 대조 가능
3. **"내 생각 & 연결"은 직접 작성**해야 학습 효과 극대화 (Generation Effect)
4. **기존 노트가 많을수록 내부 링크 품질 향상** — 지식 네트워크 효과

### 엣지 케이스

| 상황 | 동작 |
|------|------|
| 자막 없는 영상 | 알림 후 중단 |
| 영어 자막만 있는 영상 | 영어 자막으로 추출, 한국어 노트 생성 |
| 2시간+ 매우 긴 영상 | 타임스탬프 제거하여 토큰 절약, 필요 시 분할 |
| 동일 영상 재처리 | 덮어쓰기 여부 확인 |

### PDF 변환 (아이패드 학습)

이 노트는 PDF 변환에 최적화되어 설계되었다. 추후 PDF 변환 에이전트와 연결하면:
1. 옵시디언 노트 → PDF 자동 변환
2. 아이패드로 전송
3. Apple Pencil로 필기하며 학습

## 트러블슈팅

| 문제 | 해결 |
|------|------|
| "YouTube Transcript MCP를 찾을 수 없습니다" | `claude mcp add --scope user youtube-transcript npx @fabriqa.ai/youtube-transcript-mcp@latest` |
| "Obsidian MCP 연결 실패" | Obsidian 앱이 실행 중인지 확인 |
| 자막이 깨져서 나옴 | `lang` 파라미터를 `en`으로 변경하여 영어 자막으로 시도 |
| 노트가 너무 짧음 | 서브에이전트에 "본문 8,000자 이상" 제약 조건 강조 |
| Mermaid가 렌더링 안 됨 | 옵시디언 설정 → 에디터 → Mermaid 활성화 확인 |
| 내부 링크가 없음 | 볼트에 관련 노트가 충분히 있어야 함. 사용할수록 네트워크 효과 |
