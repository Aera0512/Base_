## 🚀 시너지 조합 TOP 5

### 1️⃣ 명사절 + to부정사 + 동명사 (Month 2-3)
- **천일문**: 20-24 → **Speaking**: 17, 22, 24, 27, 42, 44
- **이유**: 모두 준동사, 개념 → 실전 연결

### 2️⃣ 수동태 + 시제 (Month 1, 7-8)
- **천일문**: 6-10 → 15-19 → **Speaking**: 37, 39, 52, 54
- **이유**: 수동태는 시제 이해 필수

### 3️⃣ 분사 + 형용사절 (Month 1, 4-5)
- **천일문**: 25-32 → 37-43 → **Speaking**: 6, 64, 29, 32, 34
- **이유**: 형용사 역할 공통

### 4️⃣ 조동사 + 가정법 (Month 7-10)
- **천일문**: 11-14 → 51 → **Speaking**: 67
- **이유**: 가정법은 조동사 활용

### 5️⃣ it구문 + 강조 + 특수구문 (Month 11-12)
- **천일문**: 52-56 → **Speaking**: 72, 77
- **이유**: 고급 문장 전환 기술
