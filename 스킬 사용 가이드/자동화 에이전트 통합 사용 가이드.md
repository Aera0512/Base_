# 자동화 에이전트 통합 사용 가이드

> 현재 구축된 모든 에이전트 스킬과 커맨드를 한 곳에서 확인하고 사용하는 마스터 가이드
> **최종 수정**: 2026-03-05

---

## 현재 보유한 에이전트 전체 목록

| 에이전트 | 입력 | 출력 | 환경 |
|----------|------|------|------|
| **YT-to-Note** | YouTube URL | 구조화된 학습 노트 | Cowork + Claude Code |
| **Book-to-Note** | 책 제목 (+저자) | 구조화된 학습 노트 | Cowork + Claude Code |
| **Obsidian-to-Anki** | 옵시디언 노트 / 사진 / 주제 | Anki 플래시카드 | Cowork (스킬 + 스케줄) |
| **JSON Canvas** | 텍스트 요청 | .canvas 마인드맵/다이어그램 | Cowork + Claude Code |
| **Obsidian Markdown** | — (참조 가이드) | OFM 호환 노트 | Cowork + Claude Code |

## 1. Obsidian-to-Anki (플래시카드 자동 생성)

### 한 줄 요약

옵시디언 노트, 검색 주제, 단어장 사진을 입력하면 **Catppuccin Mocha 테마**의 예쁜 Anki 카드를 자동 생성한다.

### 사전 준비 (최초 1회)

#### 1) Anki + AnkiConnect 설치

```
Anki 실행 → 도구 → 애드온 → 새 애드온 받기 → 코드: 2055492159 → 재시작
```

AnkiConnect가 실행 중인지 확인:
```bash
curl http://localhost:8765 -X POST -d '{"action":"version","version":6}'
```
→ `{"result":6,"error":null}` 이 나오면 정상

#### 2) 노트 타입 + CSS 셋업

```bash
python setup-anki.py
```

이 스크립트가 자동으로 생성하는 것들:
- 덱: `Obsidian::English`, `Obsidian::Knowledge`
- 노트 타입: `CTP-English`, `CTP-Knowledge`, `CTP-Cloze`
- Catppuccin Mocha CSS 스타일링
- 샘플 카드 3장

> [!important] setup-anki.py 위치
> 파일은 선택한 폴더(Obsidian-photo-to-Anki/)에 있다.
> Anki가 실행된 상태에서 돌려야 한다.

### 사용법

#### 방법 A: 옵시디언 노트 → 카드

Cowork에서:
```
Anki/English/TOEFL 필수 단어 5개/ 노트를 Anki 카드로 만들어줘
```
→ `Obsidian::English::TOEFL 필수 단어 5개` 덱에 자동 저장

또는:
```
Anki/ 폴더 전체 스캔해서 카드 만들어줘
```
→ 각 하위 폴더별로 별도 덱에 저장

#### 방법 B: 주제 직접 제시

```
"cognitive load theory"에 대해 Anki 카드 5장 만들어줘
```

```
TOEFL 필수 단어 abandon, abstract, accomplish 카드 만들어줘
```

#### 방법 C: 단어장 사진

사진을 업로드하고:
```
이 사진에서 단어 추출해서 Anki 카드로 만들어줘
```

### 자동 스캔 (매일 9시)

스케줄 태스크 `anki-obsidian-scan`이 매일 오전 9시에 실행된다:
- `Anki/English/` 폴더의 새 노트 → English 카드
- `Anki/Knowledge/` 폴더의 새 노트 → Knowledge 카드
- Cowork 앱이 열려 있어야 동작

> [!tip] 노트 작성 규칙
> 1. `Anki/English/` 또는 `Anki/Knowledge/` 아래에 **노트 제목 폴더** 생성
> 2. 폴더 안에 같은 이름의 .md 파일 작성
> 3. 다음 날 자동 스캔으로 카드 생성 → Anki에서 노트 제목별로 정리된 덱 확인

### 카드 디자인 (Catppuccin Mocha)

| 요소 | 값 |
|------|-----|
| 배경 | `#1e1e2e` (Base) |
| 텍스트 | `#cdd6f4` (Text) |
| 강조 | `#cba6f7` (Mauve) |
| 명사 | `#89b4fa` (Blue) |
| 동사 | `#a6e3a1` (Green) |
| 형용사 | `#f9e2af` (Yellow) |
| 부사 | `#f5c2e7` (Pink) |
| 폰트 | Inter + Noto Sans KR + JetBrains Mono |

3가지 카드 타입:

**CTP-English**: 단어 → 발음 + 품사 + 뜻 + 예문 + 유의어 + 빈도  
**CTP-Knowledge**: 질문 → 답변 + 상세 + 카테고리 + 힌트  
**CTP-Cloze**: 빈칸 문장 → 정답 + 번역

### 옵시디언 폴더 구조

```
Anki/
├── README.md
├── English/                          ← 영어 카드
│   └── TOEFL 필수 단어 5개/          ← 노트별 폴더
│       └── TOEFL 필수 단어 5개.md    ← 소스 노트
└── Knowledge/                        ← 지식 카드
    └── 간격 반복 학습법/
        └── 간격 반복 학습법.md
```

**규칙**: 노트 제목으로 폴더를 만들고, 그 안에 같은 이름의 .md 파일을 넣는다.

### Anki 덱 구조 (자동 매핑)

Obsidian 폴더 구조가 Anki 덱 구조로 그대로 매핑된다:

| Obsidian 경로 | Anki 덱 |
|---------------|---------|
| `Anki/English/TOEFL 필수 단어 5개/` | `Obsidian::English::TOEFL 필수 단어 5개` |
| `Anki/English/GRE 핵심 단어/` | `Obsidian::English::GRE 핵심 단어` |
| `Anki/Knowledge/간격 반복 학습법/` | `Obsidian::Knowledge::간격 반복 학습법` |

새 하위 덱은 카드 추가 시 AnkiConnect가 자동으로 생성한다.

## 2. YT-to-Note (유튜브 학습 노트)

### 한 줄 요약

유튜브 링크를 주면 자막을 추출·분석하여 학습 노트를 `Yt-to-Note/`에 자동 저장한다.

### 사용법

```

```

장르 지정:
```
이 영상 tech 노트로: URL
```

### 필수 MCP

```bash
claude mcp add --scope user youtube-transcript npx @fabriqa.ai/youtube-transcript-mcp@latest
```

## 4. JSON Canvas (마인드맵/다이어그램)

### 한 줄 요약

텍스트 요청을 받아 옵시디언 Canvas 파일(.canvas)을 생성한다.

### 사용법

```
React 상태관리 라이브러리 비교 캔버스 만들어줘
```

```
이 노트 내용을 마인드맵 캔버스로 변환해줘
```

### 알아야 할 것

- 노드 타입: text, file, link, group
- 색상: `1`~`6` 프리셋 또는 hex
- 연결선(edge)에 라벨 가능

## 5. Obsidian Markdown (OFM 참조 가이드)

### 용도

에이전트가 옵시디언 호환 마크다운을 작성할 때 참조하는 문법 가이드.
직접 호출하기보다는 다른 스킬과 함께 자동으로 참조된다.

### 주요 문법

- `[[노트명]]` — 내부 링크
- `![[이미지.png]]` — 임베드
- `> [!tip]` — 콜아웃
- `%%숨김%%` — 주석
- 프론트매터, 태그, LaTeX, Mermaid 다이어그램

## 환경 설정 총정리

### Cowork (스킬)

스킬은 `.claude/skills/` 폴더에 자동으로 인식된다.

| 스킬 | 위치 | 트리거 |
|------|------|--------|
| obsidian-to-anki | Cowork 설치됨 | "anki", "플래시카드", "단어 카드" |
| yt-to-note | `.claude/skills/yt-to-note/` | 유튜브 URL, "영상 노트" |
| book-to-note | `.claude/skills/book-to-note/` | "책 노트", 책 제목 |
| json-canvas | `.claude/skills/json-canvas/` | "캔버스", "마인드맵" |
| obsidian-markdown | `.claude/skills/obsidian-markdown/` | (자동 참조) |

### Claude Code (커맨드)

커맨드는 `.claude/commands/` 또는 `~/.claude/commands/`에 위치한다.

| 커맨드 | Claude Code 사용법 |
|--------|-------------------|
| `/yt-to-note` | 유튜브 노트 생성 |
| `/book-to-note` | 도서 노트 생성 |
| `/json-canvas` | Canvas 파일 생성 |
| `/obsidian-markdown` | OFM 문법 참조 |

#### 유저 레벨 등록 (모든 프로젝트에서 사용)

```bash
mkdir -p ~/.claude/commands && cp ~/Desktop/Base_/.claude/commands/*.md ~/.claude/commands/
```

#### 등록 확인

```bash
ls ~/.claude/commands/
```

### 스케줄 태스크

| 태스크 | 스케줄 | 동작 |
|--------|--------|------|
| `anki-obsidian-scan` | 매일 09:00 | Anki/ 폴더 스캔 → 카드 생성 |

> [!warning] Cowork 앱이 열려 있어야 스케줄이 실행된다.
> Anki 데스크톱도 실행 중이어야 AnkiConnect가 동작한다.

## 일일 워크플로 예시

### 아침 (자동)

1. Cowork 앱 열기
2. Anki 실행
3. 09:00 — `anki-obsidian-scan` 자동 실행 → 어제 쓴 노트에서 카드 생성
4. Anki에서 복습

### 학습 중

| 상황 | 명령 |
|------|------|
| 유튜브 영상 시청 후 | "이 영상 노트 만들어줘: URL" |
| 책 읽은 후 | "아토믹 해빗 노트 만들어줘" |
| 영어 단어장 사진 | (사진 업로드) "Anki 카드로 만들어줘" |
| 특정 주제 카드 | "인지 부하 이론 Anki 카드 5장 만들어줘" |

### 정리

1. 새로 만든 노트 확인
2. "내 생각 & 연결" 직접 작성 (학습 효과 극대화)
3. 프론트매터 `confidence` 기록

## 수정 방법

### 카드 디자인 (CSS) 수정

Anki에서 직접 수정:
```
Anki → 도구 → 노트 타입 관리 → CTP-English 선택 → 카드 → 스타일링
```
CSS 변수를 수정하면 모든 카드에 일괄 적용된다. (`:root` 블록의 `--ctp-*` 변수)

또는 setup-anki.py를 수정 후 다시 실행하면 CSS가 업데이트된다:
```bash
python3 setup-anki.py
```
→ 기존 노트 타입이 있으면 CSS만 갱신 (카드 삭제 안 됨)

### 카드 내용 수정

Anki에서 직접 수정:
```
Anki → 찾아보기 → 덱 선택 → 카드 선택 → 편집
```

### 덱 구조 수정

Anki에서 덱 이름을 드래그하거나 이름 변경으로 계층 구조 조정 가능.
`::` 가 계층 구분자. 예: `Obsidian::English::TOEFL` → `Obsidian::시험::TOEFL`

### 새 노트 카테고리 추가하기

1. Obsidian에서 폴더 생성: `Anki/English/새 카테고리명/`
2. 안에 노트 작성: `Anki/English/새 카테고리명/새 카테고리명.md`
3. 카드 생성하면 Anki에 `Obsidian::English::새 카테고리명` 덱이 자동으로 만들어짐

### 스케줄 태스크 수정

Cowork에서:
```
anki-obsidian-scan 스케줄 9시에서 8시로 변경해줘
```

또는 Claude Code에서:
```bash
claude schedule list
claude schedule update anki-obsidian-scan --cron "0 8 * * *"
```

### 스킬 자체 수정

스킬 파일 위치:
- Cowork: `.claude/skills/obsidian-to-anki/SKILL.md` (볼트 안에서는 Cowork 설치 파일 사용)
- Helper: `.claude/skills/obsidian-to-anki/references/anki-helper.md`
- CSS: `.claude/skills/obsidian-to-anki/references/card-css.md`

## 트러블슈팅 공통

| 문제 | 원인 | 해결 |
|------|------|------|
| AnkiConnect 연결 실패 | Anki 미실행 | Anki 데스크톱 실행 |

| 노트 내부 링크 없음 | 볼트에 관련 노트 부족 | 사용할수록 개선됨 |
| Obsidian MCP 연결 실패 | Obsidian 미실행 | Obsidian 앱 열기 |
