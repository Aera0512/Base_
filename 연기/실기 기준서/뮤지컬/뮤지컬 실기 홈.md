# 뮤지컬 실기

> [!note] 정리 원칙
> 가창연기와 장면연기는 서로 겹치더라도 각 노트에 필요한 내용을 전부 적는다. 여러 유형에 공통으로 적용되는 내용은 각 유형에 그대로 둔 채 **뮤지컬 공통**에도 다시 정리한다. 연기 파트와 겹치더라도 뮤지컬 안에서 독립적으로 완성한다.
