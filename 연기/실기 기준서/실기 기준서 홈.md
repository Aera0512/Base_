# 실기 기준서

> [!important] 이 기준서의 원칙
> - 대학별 정보가 아니라 매일 연습할 때 반복해서 확인할 핵심 기준을 만든다.
> - 연기와 뮤지컬은 서로 독립된 체계로 정리한다.
> - 실제 내용은 **조사 → 질문 → 직접 작성 → 함께 비평 → 확정** 순서로 채운다.
> - 기존 일일 연습 기록은 이 기준서에 연결하지 않는다.

## 내용 상태

- **확정** — 조사와 대화를 거쳐 기준서에 남기기로 결정한 내용
- **검증 중** — 중요해 보이지만 연습과 추가 조사가 필요한 내용
- **보류** — 아직 판단하지 않거나 현재 기준서에는 넣지 않기로 한 내용
