## 첫인상 정리

올란도 : 용감하지만 막무가내 같기도함. 마음에 드네. 소신 있어보임. 힘이 세고 똑똑해보임. 정의로운 전형적인 주인공 스타일. 사람을 잘 믿고 순수하다. 

올리버 : 첫인상은 곱게 자란 개구쟁이 형 같은 느낌. 현명하다는 생각은 안 듬. 약았어. 동생에게 혼을 내고 싶어한다. 동생이 잘 났기 때문에 샘내서 자신만이 좋은 교육을 받게 하는 것 같음

로잘린드 : 이름만 들어도 뭔가 호감이 간다. 생각이 깊다.

찰슨 : 허세 많고 실제로 능력도 뛰어나나 결국 남주를 돋보이게 하기 위한 재미있는 수단 같아 보인다.

실리아 : 로잘린느에 비하면 조금 더 어리광이 느껴진다. 순수함

터취스턴 : 바보같지만 순수하고 매력있다. 인간적이고 솔직해. 바보 같은 모습이 매력적이야.

프레드릭 : 품위있다. 하지만 무언가 부족하다. 엄격하고 거칠고 꽉 막혔다.

노 : 현명하고 지혜로워 보인다. 왜 로잘린드가 그렇게 컸는지 알 것 같다. 선하고 베풀 줄 안다. 사리가 깊고 섣불리 판단하지 않는다.

어떤 장치가 보는 사람들로 하여금 재미를 불러일으키는 지 잘 알고 쓴 것 같다.
가문과 혈통의 관계 때문에 저항받는. 세상에 맞서는 개인?
전개가 깔끔하고 이해 안 되는 부분 없지만 직관적이지 않고 유려한 글. 무엇보다 재밌다!
부패한 결혼 문화 풍자 같은 것이 보이네. 사회적인 문제 또한 많이 담겨있는 듯

애덤  : 충성심 넘치고 스스로를 헌신할 줄 아는 매력적인 인물.
