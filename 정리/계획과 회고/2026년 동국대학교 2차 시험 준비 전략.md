# 동국대학교 2차 시험 준비 전략

> **확정:** 1차 합격 · 지정작품 《유령》 오스왈드. **미정:** 개인 응시일·장면 범위·특기 작품·하루 가용시간.
> **2026-10-06 기준 D-15~18.** 공식 2차 기간은 **10/21~24**. 개인 응시일 확정 전에는 **10/21에 준비 완료**하는 초안으로 운영한다. D-day는 기준일의 기록이며 자동 갱신되지 않는다.

### 의상·현장 준비

- **입고 갈 실기복 초안:** 검정 무지 라운드넥 반팔 또는 긴팔 연습복 + 검정 긴 연습바지. 실제 소지품 중 한 벌을 골라 맨발로 전체 리허설한다.
- **공식 규정:** 맨발, 양말·신발 불가. 화장 금지. 눈·코·입·이마·귀가 보여야 하며 단발 이상은 묶고, 묶이지 않으면 검정 핀으로 고정. 검정 머리끈·고정핀만 허용.
- 흰색·민소매·터틀넥·셔츠·무대의상·7부·치마·슬랙스 등은 피한다. 액세서리·미용렌즈·유색 네일 등도 금지. 세부 항목은 [[정리/입시/2027 연기과 이미지/학교별/동국대학교|최신 복장 규정]]에서 확인.
- 개인 소품 불가, 의자·큐빅 제공 없음. 반주 사용 시 **USB에 재생 가능한 음원** 준비(CD 불가). 실제 파일 재생 점검은 특기 노트에서 관리.
- **당일:** 고사 시작 1시간 전까지 입실 완료. 출력 수험표와 인정되는 실물 신분증 준비(모바일 신분증·촬영본 불인정).
- **아직 정할 것:** 실제 상·하의 / 머리 정리 방법 / 특기 반주 유무.

## 2. 남은 기간을 목적별로 나누기

**제안 초안.** 다른 대학 시험·수업과 현재 완성도를 확인한 뒤 조정한다. 한 구간의 목적에 집중하되 다른 평가 항목을 며칠씩 완전히 비우지는 않는다.

| 기간 | 소목적 | 이 구간을 마칠 때 남길 결과 |
|---|---|---|
| 10/6~8 · 3일 | 현재 수준 확인·선택 | 오스왈드 장면 범위, 특기 종목·작품 결정. 항목별 현재 상태를 촬영/말하기로 확인하고 우선 문제 1개씩 적기 |
| 10/9~13 · 5일 | 핵심 부분 보완 | 지정연기·특기의 어려운 구간을 보완해 처음부터 끝까지 연결. 작품 질문에 대본 근거로 답하고 즉흥 1분을 끝내보기 |
| 10/14~18 · 5일 | 실전 연결·재현 | 실기복·맨발·실제 반주 조건으로 모의실기. 다른 날에도 반복되는 문제만 수정; 개인 응시일 반영 |
| 10/19~20 · 2일 | 최종 안내 반영·정리 | 의상·USB·동선·시간 확인, 짧은 점검으로 감각 유지. 시험 직전 볼 핵심만 세부 노트 상단에 압축 |
| 개인 시험이 10/22~24이면 | 추가 1~3일 유지·미세 조정 | 새 작품을 벌리기보다 이미 정한 연기·특기의 일관성과 컨디션 확인 |

## 3. 훈련할 큰 대상 → 실제 연습

아래는 **연습 제안**이며 공식 채점 세부기준이 아니다. 구체적인 기록은 연결된 평가 항목 노트에 쓴다.

| 큰 대상 | 할 수 있는 연습 | 확인할 것 |
|---|---|---|
| 오스왈드의 목적과 상대 | 장면을 내 말로 해본 뒤 원대사로 돌아오기; 행동이 달라지는 지점 나누기 | 감정 설명 없이도 누구에게 무엇을 얻으려는지 보이는가 |
| 작품 이해를 말·연기로 연결 | 질문 하나에 말로 답하기 → 대본 근거 찾기 → 해당 장면 실연 | 답변한 해석과 실제 연기가 맞는가 |
| 즉흥의 상황·변화·끝 | 시작 대사 하나로 관계·목적을 잡고 1분 실연; 같은 대사로 다른 상황 재시도 | 제시 대사로 시작하고 사건이 변하며 시간 안에 끝나는가 |
| 특기의 완성도 | 불안한 구간을 나눠 연습 → 앞뒤 연결 → 전체 촬영 | 제한시간·시작·끝이 안정되고 의도한 강점이 보이는가 |
| 실전에서의 연결 | 입장부터 실기·질문·퇴장까지 모의실기; 중단·추가 지시도 연습 | 연기 밖 대기·전환 때도 집중을 이어가는가 |

**하루 운영 초안:** 시작할 때 가장 필요한 문제 하나를 고른다 → 부분 연습 → 전체에서 확인 → 끝에 ‘바뀐 점 / 남은 점 / 다음 행동’을 한 줄씩. 시간 배분은 가용시간을 확인한 뒤 정한다.

## 4. 생활 루틴: 도움이 되는 것과 방해하는 것

기존 [[정리/계획과 회고/나의 습관|나의 습관]]에 적은 관찰을 출발점으로 삼았다. **지금도 같은지는 확인 필요.**

| 기존 관찰 | 이번 준비에 적용할 초안 |
|---|---|
| 한 가지에 몰입할 때 집중이 잘 됨 | 한 연습 블록에는 한 문제만; 분석·촬영·수정을 계속 섞지 않기 |
| 누군가 지켜보면 집중·의욕이 높아짐 | 가능한 수업에서 짧은 실연과 피드백 받기; 평가받는 상황에서도 목적을 유지하는지 보기 |
| 계획에 변수가 생기면 실행률이 떨어짐 | 일정이 밀린 날은 ‘가장 급한 부분 하나 → 전체에서 확인 → 다음 행동 기록’만 남기는 축소안 사용 |
| 방법을 찾고 실천하는 데 즐거움을 느낌 | 새 연습법을 찾았다면 바로 한 번 시험하고 효과 확인; 탐색이 연습을 밀어내는지는 관찰 |

- **공간 활용 초안:** 집은 희곡·장면 분석과 답변 정리 / 연습실은 소리·움직임·전체 연결 / 수업은 내가 못 보는 문제 확인. 기존 [[앞으로 연습실과 학원 계획]]을 참고했으며 현재 이용 가능 여부는 미확인.
- **추가로 확인할 실제 생활:** 수면·기상, 이동, 다른 시험·수업, 휴대폰 사용 중 무엇이 시간을 빼앗거나 회복을 돕는지. 아직 원인으로 단정하지 않는다.
- **내가 유지할 것 1개:** 미정 / **줄일 것 1개:** 미정 / **바뀐 효과를 확인할 방법:** 미정.
