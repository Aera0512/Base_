## 3. 훈련할 큰 대상 → 실제 연습

아래는 **연습 제안**이며 공식 채점 세부기준이 아니다. 구체적인 기록은 연결된 평가 항목 노트에 쓴다.

| 큰 대상 | 할 수 있는 연습 | 확인할 것 |
|---|---|---|
| 오스왈드의 목적과 상대 | 장면을 내 말로 해본 뒤 원대사로 돌아오기; 행동이 달라지는 지점 나누기 | 감정 설명 없이도 누구에게 무엇을 얻으려는지 보이는가 |
| 작품 이해를 말·연기로 연결 | 질문 하나에 말로 답하기 → 대본 근거 찾기 → 해당 장면 실연 | 답변한 해석과 실제 연기가 맞는가 |
| 즉흥의 상황·변화·끝 | 시작 대사 하나로 관계·목적을 잡고 1분 실연; 같은 대사로 다른 상황 재시도 | 제시 대사로 시작하고 사건이 변하며 시간 안에 끝나는가 |
| 특기의 완성도 | 불안한 구간을 나눠 연습 → 앞뒤 연결 → 전체 촬영 | 제한시간·시작·끝이 안정되고 의도한 강점이 보이는가 |
| 실전에서의 연결 | 입장부터 실기·질문·퇴장까지 모의실기; 중단·추가 지시도 연습 | 연기 밖 대기·전환 때도 집중을 이어가는가 |

**하루 운영 초안:** 시작할 때 가장 필요한 문제 하나를 고른다 → 부분 연습 → 전체에서 확인 → 끝에 ‘바뀐 점 / 남은 점 / 다음 행동’을 한 줄씩. 시간 배분은 가용시간을 확인한 뒤 정한다.

## 4. 생활 루틴: 도움이 되는 것과 방해하는 것

기존 [[정리/계획과 회고/나의 습관|나의 습관]]에 적은 관찰을 출발점으로 삼았다. **지금도 같은지는 확인 필요.**

| 기존 관찰 | 이번 준비에 적용할 초안 |
|---|---|
| 한 가지에 몰입할 때 집중이 잘 됨 | 한 연습 블록에는 한 문제만; 분석·촬영·수정을 계속 섞지 않기 |
| 누군가 지켜보면 집중·의욕이 높아짐 | 가능한 수업에서 짧은 실연과 피드백 받기; 평가받는 상황에서도 목적을 유지하는지 보기 |
| 계획에 변수가 생기면 실행률이 떨어짐 | 일정이 밀린 날은 ‘가장 급한 부분 하나 → 전체에서 확인 → 다음 행동 기록’만 남기는 축소안 사용 |
| 방법을 찾고 실천하는 데 즐거움을 느낌 | 새 연습법을 찾았다면 바로 한 번 시험하고 효과 확인; 탐색이 연습을 밀어내는지는 관찰 |

- **공간 활용 초안:** 집은 희곡·장면 분석과 답변 정리 / 연습실은 소리·움직임·전체 연결 / 수업은 내가 못 보는 문제 확인. 기존 [[앞으로 연습실과 학원 계획]]을 참고했으며 현재 이용 가능 여부는 미확인.
- **추가로 확인할 실제 생활:** 수면·기상, 이동, 다른 시험·수업, 휴대폰 사용 중 무엇이 시간을 빼앗거나 회복을 돕는지. 아직 원인으로 단정하지 않는다.
- **내가 유지할 것 1개:** 미정 / **줄일 것 1개:** 미정 / **바뀐 효과를 확인할 방법:** 미정.
