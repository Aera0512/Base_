
## 수시 지원 대학교 

### 후보

- ==**한국예술종합학교**==
  1차 합격 경험, 추구하는 학생 스타일, 특기
  당일대사
  
- ==**성균관대학교**== 
  성적, 1차 합격 경험, 추구하는 학생스타일, 무용 특기
  당일대사
  
- **동국대학교** 
  1차 합격 경험, 이미지
  즉흥 연기
  
- **건국대학교** 
  1차 먹고 들어감, 연기 스타일
  정보 부족, 이미지
  
- **세종대학교** 
  연기 스타일, 세종액팅베스트원, 무용 특기
  즉흥 연기
  
- **중앙대학교**
  이미지, 상대적으로 부담 없는 일정, 많은 독백 하이라이트들로 임팩트.
  높은 경쟁률과 당일대사
  
- **인천대학교**
  1차 합격 경험, 추구하는 학생 스타일, 상대적으로 낮은 경쟁력과 시험 일정.
  당일대사

- 국민대학교
- 숭실대학교

특기를 보는 학교 )
1차 : 2개 (한국예술종합학교, 세종대학교) 동국대학교는 시켜볼 수 있음.
2차 : 3개 (한국예술종합학교, 성균관대학교, 동국대학교) 중앙대학교, 인천대학교, 세종대학교, 건국대학교도 모두 시켜볼 수 있음.

1차 : 0개 (성균관대학교는 질의응답으로, 동국대학교와 인천대학교는 독백 변형 즉흥 연기를 시킬 수 있음)
2차 : 2개 (세종대학교와 동국대학교) 성균관대학교와 한국예술종합학교도 시켜볼 수 있음.
