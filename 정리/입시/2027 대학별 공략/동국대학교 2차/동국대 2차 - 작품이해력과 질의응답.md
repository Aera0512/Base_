작품 전체 분석은 유령 노트에, **내 해석을 말하고 실연하는 연습**은 여기에 적는다. 아래 질문은 준비용 예시이며 실제 출제 예고가 아니다.

## 현재 목표

- 줄거리 암기에서 끝내지 않고 오스왈드의 행동을 작품 안의 사건으로 설명하기.
- 현재 막히는 질문 / 이번 구간의 목표: 미정

## 연습할 질문

| 질문 | 내 답의 핵심 | 대본 근거 |
|---|---|---|
| 작품의 핵심 갈등과 제목을 어떻게 이해했나? | | |
| 오스왈드는 이 장면에서 상대에게 무엇을 원하는가? | | |
| 앞선 사건이 이 대사와 행동에 어떻게 영향을 주는가? | | |
| 왜 이 장면을 골랐으며 어떤 선택을 했나? | | |
| 다른 해석도 가능한 지점은 어디인가? | | |

## 연습 후보

1. 한 질문에 내 말로 30~45초 답한다. **연습용 시간**이며 공식 답변 제한시간이 아니다.
2. 답변에 필요한 사건·대사를 읽고, 근거 없는 단정은 수정한다.
3. 답한 해석대로 해당 부분을 연기해 말과 실연이 일치하는지 확인한다.
4. 핵심 단어만 보고 재답변하고 ‘왜?’라는 추가 질문을 받아본다.

**확인 방법:** 답의 주장·대본 근거·내 연기 선택이 이어지는가? 모르는 부분을 말로 덮지 않고 다시 읽을 곳을 찾았는가?
