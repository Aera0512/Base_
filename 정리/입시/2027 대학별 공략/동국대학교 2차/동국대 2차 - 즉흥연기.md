# 동국대 2차 — 즉흥연기

[[정리/계획과 회고/2026년 동국대학교 2차 시험 준비 전략|← 동국대 2차 전략]]

**공식:** 제시 대사로 시작하는 이야기를 구성해 1분 이내 실연. 아래 준비 시간과 훈련 방식은 자체 연습안이며 실제 현장 준비 시간은 안내에 따른다.

## 현재 목표

- 현재 어려운 점 / 이번 구간의 목표: 미정
- 기본 점검: 누구와 어디에 있는가 → 무엇을 원하나 → 어떤 일이 바꾸나 → 어떻게 끝나나.

## 연습 후보

1. 시작 대사 하나를 뽑아 관계·장소·목적을 정하고 타이머로 1분 실연.
2. 영상에서 ‘관계가 드러난 순간 / 사건이 바뀐 순간 / 마지막 행동’을 찾아본다.
3. 같은 대사를 다른 관계·목적으로 다시 해본다. 첫 아이디어만 반복하지 않는지 확인.
4. 가장 약한 요소 하나만 바꿔 재시도한다. 준비에 실제 걸린 시간도 적는다.

**확인 방법:** 제시 대사로 시작했는가? 설명에 머무르지 않고 행동했는가? 상황이 변하고 1분 안에 끝났는가? 이는 연습용 점검 기준이다.
