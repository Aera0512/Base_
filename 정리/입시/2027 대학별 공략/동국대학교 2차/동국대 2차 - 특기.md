# 동국대 2차 — 특기

[[정리/계획과 회고/2026년 동국대학교 2차 시험 준비 전략|← 동국대 2차 전략]]

**현재:** 동국대용 종목·작품 미정. 이전 세종대 준비 노트에는 무용이 있지만 이번 선택으로 확정하지 않는다.

## 결정할 것

- 종목 / 작품명 / 보여줄 강점 한 가지:
- 현재 완성도 / 불안한 구간 / 이번 구간의 목표:
- 반주 유무 / 시작·끝 지점 / 실연 시간:

**선택 초안:** 이미 준비한 후보를 우선 촬영해 보고, 남은 기간 안에 안정적으로 보여줄 수 있는지와 강점이 드러나는지를 기준으로 정한다.

## 연습 후보

1. 먼저 전체를 촬영해 실연 시간과 불안한 구간을 확인.
2. 어려운 부분만 나누어 연습한 뒤 앞뒤 구간을 붙여 재확인.
3. 무용이면 시선·중심 이동·마지막 정지, 노래면 가사 전달·프레이즈 연결 등 선택한 종목에 맞게 문제 하나씩 확인.
4. 검정 실기복·맨발·실제 반주로 시작과 끝까지 연결. 다른 날에도 같은 부분이 무너지는지 확인.

## 현장 조건

- 공식 제한 2분 이내. 특기로 연기는 지양; 뮤지컬 지망자는 뮤지컬 한 곡. 모든 노래는 한국어.
- 반주가 있으면 USB 준비. 컴퓨터 재생 가능한 형식(mp3·wmv·mp4·wav 등), CD 불가. 파일을 실제로 열어 음량·시작·끝을 점검한다.
- 개인 소품·의자·큐빅 사용을 전제하지 않는다. 악기 연주 특기는 악기 반입 가능하지만 소품용 악기는 불가.
- 근거: [최신 2단계 안내](https://ipsi.dongguk.edu/upload/file/20261006095039VE3PSQ.PDF). 추가 세부 운영은 고사장 안내에서 확인.
