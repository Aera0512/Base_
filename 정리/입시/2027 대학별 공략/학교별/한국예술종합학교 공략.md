## 2. 학교가 공식적으로 말하는 배우상

### 공식 교육 방향

한예종 연극원은 연기전공의 목표를 다음 축으로 설명한다. **[A]**

- 자기 이해와 인간 이해
- 몸과 마음의 균형
- 상상력과 창조력
- 고유한 연기 세계
- 고전부터 현대 실험극까지 다양한 양식
- 연극·영화·뮤지컬 등 여러 장르에서 활동할 수 있는 전문성

교육과정도 1학년의 자기 이해·몸과 마음의 훈련에서 시작해 2학년의 작품 이해와 인물 창조, 3·4학년의 공연과 역할 탐구로 이어진다. 연기실습만이 아니라 즉흥연기, 움직임, 박과 사위, 호흡과 발성, 서양가창, 한국의 소리, 화술, 한국무용을 함께 다룬다. **[A]**

### 입시 전략으로 번역한 가설

> [!warning] 아래는 공식 합격 기준이 아니다
> 학과의 교육목표와 시험 형식을 연결한 **[H] 전략 가설**이다. “한예종은 반드시 이런 학생만 뽑는다”라고 단정하지 않는다.

| 공식 축 | 시험에서 검증할 수 있는 행동 가설 |
|---|---|
| 자기·인간 이해 | 인물을 성격 한 단어로 규정하지 않고 모순·관계·행동의 이유를 이해한다 |
| 몸과 마음의 균형 | 긴장 속에서도 호흡·시선·보행·정지가 서로 싸우지 않는다 |
| 상상력·창조력 | 기성품 같은 억양과 제스처가 아니라 작품 근거가 있는 자기 선택이 있다 |
| 고유한 연기 세계 | 남들과 다르게 보이려는 장식이 아니라 내가 실제로 믿는 관점이 보인다 |
| 다양한 양식 | 체홉의 희극성과 뮤지컬의 서사를 같은 톤으로 뭉개지 않고 각각 다룬다 |
| 전문 배우로의 확장성 | 지시를 듣고 바로 바꾸며, 중단·질문·실수 뒤에도 관계를 회복한다 |

### 이번 시험에서 피할 오해

- `자연스러움 = 작고 무기력함`이 아니다.
- `창의성 = 이상한 동작이나 튀는 해석`이 아니다.
- `지적인 배우 = 분석을 길게 설명하는 사람`이 아니다.
- `건강함 = 항상 밝게 웃는 이미지`가 아니다.
- `가능성 = 미완성 작품을 대충 보여주는 것`이 아니다.

## 3. 나와 한예종의 접점

### 이미 가진 자원 **[P]**

- 182cm의 크고 마른 체형, 차분함·진중함·부드러움·지적인 분위기, 자연스러운 소년미
- 작품·작가·인물의 객관적 사실을 길게 조사하고 자기 관점을 만드는 습관
- 연습 목표를 정하고 촬영한 뒤 관찰 가능한 사실로 수정하는 방식
- 상대에게 외부 초점을 두고, 목적 아래에서 실제로 행동하려는 훈련
- 말에 힘을 과하게 주기보다 툭툭 전달하고 눈에 사고를 담으려는 방향
- 보컬에서는 담백하고 말하는 듯한 전달, 정확한 발음과 음정·박자를 우선하는 방향

### 한예종에서 살릴 강점 **[H]**

1. **소년 같은 얼굴과 젊은 예술가의 지성**  
   꼬스챠의 어린 자존심·예술적 야심·사랑받고 싶은 마음이 체형과 기본 인상에 자연스럽게 연결된다.

2. **분석을 행동으로 바꾸려는 태도**  
   체홉의 희극성, 소린과의 관계, 공연 직전 상황을 실제 설득 행동으로 바꾸면 학과가 말하는 작품 이해와 인간 이해가 함께 보일 수 있다.

3. **연기와 노래의 확장성**  
   꼬스챠의 날카로운 논쟁 뒤 〈Who I’d Be〉의 꿈과 따뜻함을 보여주면 하나의 고정 이미지보다 넓은 스펙트럼이 생긴다.

### 가장 큰 위험 **[P/H]**

| 위험 | 영상에서 나타나는 신호 | 반대 행동 |
|---|---|---|
| 내부 초점 | 내 감정과 다음 대사를 확인하느라 상대가 사라짐 | 매 문장을 소린에게 일으킬 변화로 시작 |
| 생각 과잉 | 머리가 먼저 돌고 반응과 말이 느려짐 | 분석은 연습실에 두고 실전에서는 보고 듣고 행동 |
| 어두운 이미지 중복 | 꼬스챠와 슈렉이 모두 상처받은 외부자의 한탄으로 보임 | 꼬스챠는 재치·공격·신념, 슈렉은 꿈·열림·희망을 전면에 둠 |
| 미리 만든 감정 | 시작부터 고통을 깔고 변화가 사라짐 | 꽃잎 놀이의 가벼움에서 실제로 출발 |
| 힘으로 증명 | 가슴·목·턱이 굳고 목소리만 커짐 | 이완된 중심과 분명한 자음, 상대에게 가는 생각으로 에너지 생성 |

### 2025년 실제 한예종 응시에서 배운 것 **[P]**

지난해 같은 시험을 직접 치른 기록은 어떤 학원 후기보다 우선하는 개인 근거다.

| 직접 관찰 | 2027 교정 전략 |
|---|---|
| 고사장이 예상보다 넓고 밝았으며 조용하고 소리가 먹혔다 | 작은 연습실만 쓰지 말고 넓고 흡음되는 공간에서도 말·노래 전달을 점검한다 |
| 심사위원이 표정을 읽기 어려울 만큼 멀었다 | 반응을 확인하려 얼굴을 해석하지 말고, 구체적인 상대와 행동을 끝까지 유지한다 |
| 첫 시작의 집중이 약했다 | 입장 뒤 감정을 만들지 말고 첫 자극·첫 행동을 2–3초 안에 실행한다 |
| 질답이 단답형 흐름으로 끝나 매력을 거의 못 보였다고 느꼈다 | 직접 답한 뒤 실제 경험 한 문장을 덧붙이는 `한 호흡 확장`을 훈련한다 |
| 당시 스스로를 `유치하고 성실하면서 진중한 사람`이라고 설명했다 | `유치함`을 숨길 결점이 아니라 순수함·놀이성·상상력으로 더 정확히 설명한다 |

## 4. 1차 시험 구성과 준비물

### 확인된 구성 **[A]**

- 준비한 독백: 1~2분
- 무반주 노래 또는 움직임: 1분 이내. 노래는 뮤지컬·가곡·판소리 등 8마디 이상
- 질의응답
- 의상: 무채색·무늬 없는 티셔츠와 바지
- 화장 금지
- 신발: 맨발 또는 굽 없는 무용화류만 가능, 일반 신발 금지
- 대기실 입실 뒤 외출·환복 불가, 별도 연습시간 없음
- 액세서리·미용렌즈 금지, 전자기기와 위해·오염·조립·의상교체가 필요한 소품 등 반입 제한

### 개인 확정안 **[P]**

| 항목 | 선택 |
|---|---|
| 독백 | 안톤 체홉 《갈매기》의 뜨레쁠레프(꼬스챠) |
| 특기 | 뮤지컬 《슈렉》의 〈Who I’d Be〉, 무반주 1분 |
| 질답 | 완성 원고 암기 없이 핵심 키워드 + 실제 경험 + 즉흥 말하기 |
| 복장 | 무채색 무지 티셔츠·검정 무지 바지·굽 없는 무용화 또는 맨발 |
| 헤어·얼굴 | 얼굴과 눈썹을 가리지 않는 자연스러운 정돈, 맨얼굴, 장신구·컬러렌즈 제거 |

> [!important] 대기실에 들어가기 전에 끝낼 것
> 최신 2027 공식 유의사항상 입실 뒤 환복·외출이 불가능하고 별도 연습시간도 없다. 복장·신발·화장·장신구 확인, 신체·목소리 워밍업, 꼬스챠의 첫 자극과 〈Who I’d Be〉의 시작음을 **캠퍼스 입장 전에** 준비한다. 현장에서는 감독관 지시에 따르고 임의로 연습하지 않는다.

## 5. 문 밖에서 퇴장까지

### 핵심 원칙

입장 자체를 별도의 연기로 만들지 않는다. **준비된 몸으로 들어와, 정확히 듣고, 지시받은 일을 하고, 깨끗하게 나가는 것**이 목표다. 걸음걸이는 학교가 좋아할 것 같은 캐릭터를 흉내 내는 장치가 아니라 몸과 마음의 균형을 보여주는 첫 증거다. **[H]**

### 행동 순서

1. **문 밖** — 발바닥 감각, 길게 내쉬기, 턱·손·어깨의 불필요한 힘만 확인한다. 감정을 만들지 않는다.
2. **호명** — 짧고 분명하게 응답하고 지시를 끝까지 듣는다.
3. **문 열기** — 급히 몸부터 넣지 않고 문과 공간을 실제로 본다.
4. **입장** — 평소보다 아주 조금만 또렷한 보폭. 가슴을 내밀거나 발끝을 과장하지 않는다.
5. **위치 찾기** — 표시와 지시가 있으면 그대로 따른다. 임의로 중앙을 연출하지 않는다.
6. **정지** — 양발의 무게를 느끼고 손·옷·머리를 다시 만지지 않는다.
7. **인사·소개** — 지시된 방식만 사용한다. 과하게 밝은 톤이나 낮은 목소리를 만들지 않는다.
8. **독백 준비** — 상대 위치와 직전 자극을 한 번 확인하고 시작한다. 감정이 차오르기를 기다리지 않는다.
9. **중단 지시** — 실패로 해석하지 않고 즉시 멈춘 뒤 눈과 몸을 열어 다음 지시를 듣는다. 후기에서는 실기가 중간에 끊기는 사례가 있으므로, 끝까지 보여주지 못해도 작품의 첫 구간에서 핵심 인상과 관계가 보여야 한다. **[C/D]**
10. **노래 전환** — 꼬스챠의 몸과 시선을 풀고 중립으로 돌아온다. 제목 소개는 요청받은 만큼만 한다.
11. **질답** — 질문을 끝까지 듣고 1–2초 생각한다. 모르면 꾸미지 말고 아는 범위와 더 확인할 부분을 나눈다.
12. **퇴장** — 마지막 지시를 확인하고 짧게 인사한 뒤 같은 속도로 나간다. 결과를 읽으려 교수 표정을 훑지 않는다.

### 5m 보행 훈련

정면·측면 카메라를 두고 `문 열기 → 5m 걷기 → 표시에서 정지 → 인사 → 지시 듣기`를 촬영한다.

| 합격 기준 | 실패 신호 |
|---|---|
| 첫 걸음 전에 공간을 실제로 봄 | 문을 열자마자 외운 동선으로 돌진 |
| 보폭과 팔이 자연스럽고 속도가 일정 | 군대식 팔, 모델 워킹, 지나친 느림 |
| 머리·가슴·골반이 서로 끌어당기지 않음 | 가슴만 내밀거나 상체가 앞으로 쏠림 |
| 정지 뒤 바로 들을 수 있음 | 발을 다시 맞추고 옷·머리를 만짐 |
| 얼굴이 열려 있으나 미소를 고정하지 않음 | 평가자를 의식한 웃음·무표정 연출 |

훈련 변형: 호명 속도 바꾸기, 위치를 옆으로 바꾸기, 입장 직후 질문하기, 독백 전에 노래를 먼저 시키기. 순서가 달라져도 몸의 중립을 회복하는 것이 성공이다.

> [!note] 사실과 전략의 경계
> 공식 자료에는 특정 보폭·시선·인사·퇴장 멘트가 없다. 여러 대기실을 거치거나 관리번호로 호명된 경험담은 있지만 연도·시험장에 따라 달라질 수 있다. `한예종식 걸음걸이`를 만들지 말고 당일 진행요원의 지시를 우선한다.

## 6. 준비 독백 — 꼬스챠

관련 분석: [[연기/작품과 인물 분석/뜨레쁠레프 - 갈매기|뜨레쁠레프 작품·인물 분석]] · [[연기/작품과 인물 분석/뜨레쁠레프 자유연기 디자인|자유연기 디자인]]

### 이 장면의 한 문장

> 공연을 앞둔 꼬스챠가 소린에게 **어머니가 자신을 사랑하지 않는다는 논리를 인정시키고, 자신이 믿는 새로운 연극의 편에 세우려 한다.**

`상처받은 아들이 슬픔을 토로한다`보다 행동 가능하고, 현재 준비 중인 공연과도 연결된다.

### 보여줄 이야기

| 구간 | 상대에게 할 일 | 살아 있어야 할 색 |
|---|---|---|
| 꽃잎 놀이 | 운명을 시험하고 소린의 주의를 끈다 | 가벼움·장난·불안 |
| 엄마의 나이 논리 | 내가 틀린 게 아니라는 증거를 납득시킨다 | 영리함·재치·약간의 잔인함 |
| 요즘 연극 비판 | 소린을 내 예술의 편으로 끌어온다 | 흥분·쾌감·신념 |
| 모파상 비유 | 이 세계에서 달아나고 싶은 압박을 이해시킨다 | 진짜 호소·열림 |

### 한예종에서 살릴 지점 **[H]**

- 체홉이 희곡을 코미디로 부른 이유를 몸으로 보여준다. 심각한 고통만이 아니라 꼬스챠가 자기 논리에 취하고, 기성 연극을 재치 있게 조롱하는 재미를 살린다.
- 소린이 매번 바로 설득되지 않기 때문에 수단을 바꾼다. 혼자 만든 감정의 파도보다 관계 안의 변화가 먼저다.
- `새로운 형식`을 외치는 인물을 상투적인 비장함으로 연기하는 모순을 피한다.
- 약함을 숨기지 않되 약함을 보여주려 하지 않는다. 끝까지 상대를 바꾸려는 적극성이 약함을 드러내게 둔다.

### 구체적 연습 과제

1. **소린 반응 카드**  
   파트너가 `안 믿음 / 걱정함 / 웃음 / 딴짓 / 동의함` 중 하나를 무작위로 선택한다. 같은 억양을 유지하지 말고 설득 수단을 바꾼다.

2. **희극성 테스트**  
   감정을 줄이는 것이 아니라, 엄마의 나이를 계산하는 논리와 기성 연극을 비판하는 과장에 실제 재미를 발견한다. 영상에서 관객이 웃을 틈이 생기되 웃기려는 표정은 없어야 한다.

3. **첫 30초 완성**  
   중단될 가능성을 대비해 꽃잎 놀이, 소린과의 관계, 꼬스챠의 영리함과 결핍이 첫 30초 안에 이미 보이게 한다.

4. **60·90·120초 버전**  
   내용과 행동의 중심이 무너지지 않는 세 버전을 만든다. 학교가 중간에 멈추더라도 실패로 느끼지 않게 한다.

5. **침묵 뒤 시작**  
   감정을 끌어올리는 긴 준비 없이 신호 후 2–3초 안에 꽃잎과 상대를 실제로 보고 시작한다.

### 금지 목록

- 시작부터 우울하고 죽을 것 같은 얼굴
- 소린을 잊고 관객에게 예술론을 연설하기
- 모든 문장을 같은 분노와 큰 소리로 밀기
- `지적인 인물`을 보여주려 발음과 제스처를 과장하기
- 대사마다 미리 정한 감정 이름을 재생하기
- 손에 든 가상의 꽃보다 손 모양을 예쁘게 보이게 하기

## 7. 무반주 노래 — 〈Who I’d Be〉

### 원작 장면

이 곡은 슈렉이 동키에게 처음으로 마음을 열고, 오거가 아니라면 어떤 사람이 되고 싶은지 상상하는 장면이다. 피오나는 멀리서 이 고백을 들으며 자신의 고립과 슈렉의 마음을 겹쳐 본다. **[공식 라이선스 페이지·공연 시놉시스]**

### 이 곡을 선택한 이유 **[H]**

- 꼬스챠와 슈렉 모두 타인의 시선에 상처받고, 다른 모습으로 인정받고 싶어 한다.
- 꼬스챠가 바깥으로 공격하며 자기 가치를 증명한다면, 슈렉은 믿을 수 있는 상대 앞에서 숨겨 둔 꿈을 처음 꺼낸다.
- 같은 결핍을 다른 행동으로 보여주면 개인의 일관성과 연기 폭을 동시에 만들 수 있다.

### 가장 큰 위험

두 작품을 모두 `상처받은 남자의 비애`로 처리하면 이미지가 한 가지로 좁아진다. 이 노래에서는 외로움보다 **상상하는 즐거움, 마음이 열리는 속도, 더 큰 사람이 되고 싶은 생명력**을 앞에 둔다.

### 1분 구성 원칙

1. **출발:** 동키라는 구체적인 상대에게 조심스럽게 처음 말한다.
2. **확장:** 말하던 사람이 자기 상상에 설득되어 공간과 꿈이 넓어진다.
3. **고백:** 영웅의 겉모습보다 왜 그런 존재가 되고 싶은지가 들린다.
4. **도착:** 마지막 음이 아니라 상대에게 전한 생각으로 끝낸다.

> 원곡은 슈렉·동키·피오나의 관계와 하모니가 포함된 장면이다. 1분 컷은 **슈렉의 솔로만으로도 문장이 완결되고 침묵 구멍이 없는 55~58초, 8마디 이상 구간**을 사용한다. 정확한 마디와 시작음은 보컬 선생님과 악보를 기준으로 확정한다.

### 표현 원칙

- 오거 목소리·외국식 억양을 흉내 내지 않는다. 내 편한 말소리와 노래 소리를 사용한다.
- 콘서트처럼 정면에 감정을 뿌리지 않고 동키 한 사람에게 말한다.
- 손동작으로 판타지 장면을 모두 묘사하지 않는다. 상상으로 공간이 커지면 시선과 호흡의 범위가 자연스럽게 달라지게 둔다.
- 꼬스챠에서 쓴 날카로운 텐션을 그대로 가져오지 않는다. 몸을 중립으로 돌리고 따뜻한 호흡에서 시작한다.

### 내 보컬 기록에서 유지할 것 **[P]**

- 우선순위는 음정·박자
- 들숨에서 코어와 발음을 준비하고, 소리를 먼저 진행하기
- 중고음에서 인위적으로 톤을 바꾸지 않기
- 첫 자음·모음과 발음의 선명도 유지
- 발성 기관을 통제하려는 생각보다 상대에게 가사를 전달하기
- 담백하고 말하듯 부르되 에너지가 필요한 도약은 작게 만들지 않기

### 목을 소모하지 않는 80분 세션

| 시간 | 내용 |
|---:|---|
| 15분 | 몸·호흡·말소리·가벼운 발성 |
| 15분 | 리듬 말하기, 자음·모음과 영어 문장 전달 |
| 15분 | 어려운 도약·시작음·끝음 부분 연습 |
| 10분 | 1차 풀런과 즉시 감각 기록 |
| 10분 | 녹음 확인 후 한 가지만 수정 |
| 10분 | 2차 풀런 |
| 5분 | 낮은 강도의 정리와 다음 과제 기록 |

목이 거칠어지거나 통증이 생기면 풀런을 늘리지 않는다. 보컬 선생님의 현재 지시와 컨디션을 우선한다.

## 9. 질의응답 — 키워드와 즉흥

### 답변 구조

`결론 한 문장 → 내 실제 경험·관찰 → 지금도 탐구 중인 질문`

- 보통 20~40초 안에 핵심을 끝낸다. 길이를 채우려고 부연하지 않는다.
- 학교의 명성보다 **내가 이 교육과정에서 무엇을 훈련하고 싶은지**를 말한다.
- 멋진 가치어보다 실제 작품·수업·실패·연습 방식 한 가지를 든다.
- 꼬리질문은 공격이 아니라 생각을 더 보려는 기회로 받아들인다.

### 개인 키워드 은행 **[P]**

| 주제 | 사용할 수 있는 실제 키워드 |

| 최근 작품 | 《갈매기》, 《햄릿》, 《세 자매》, 《테베랜드》 |

## 10. D-15 훈련 계획

연습실 7시간을 전부 고강도로 채우지 않는다. 집중 세션·촬영·회복을 포함한 7시간으로 운영하고, 집의 방음부스에서는 낮은 강도의 분석·리듬·발음 연습을 이어간다.

## 12. 시험 전날·당일 체크

### 전날

- [ ] 수험표에서 날짜·대기실·입실 마감·캠퍼스 재확인
- [ ] 최신 2027 유의사항에서 맨발/굽 없는 무용화, 장신구·미용렌즈·전자기기·소품 규정 확인
- [ ] 이동 경로와 예비 경로, 목표 도착 시각 확정
- [ ] 의상 세탁·얼룩·로고·무늬·여벌 확인
- [ ] 신분증·수험표·물·필요 물품 한곳에 준비
- [ ] 독백·노래 풀런은 한 번 이내, 새 피드백과 새 선택 금지
- [ ] 수면과 식사 시간을 시험 시각에 맞춤

### 당일

- [ ] 목표 도착은 입실 마감보다 충분히 앞당김
- [ ] 캠퍼스 입장 전에 환복·몸·목소리 워밍업·시작음 확인을 완료
- [ ] 대기실 입실 뒤에는 연습하지 않고 감독관 지시에 따름
- [ ] 다른 수험생의 소리·후기에 내 선택을 바꾸지 않음
- [ ] 문 밖에서는 `잘 보여야 한다`가 아니라 `보고 듣고 행동한다`
- [ ] 중단은 평가 결과가 아니라 다음 지시
