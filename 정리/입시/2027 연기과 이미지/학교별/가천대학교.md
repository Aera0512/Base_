# 가천대학교 연기예술학과

[[의상 및 헤어 등 이미지|← 총괄 대시보드]]

## 전형과 일정

- 전형: 실기우수자 전형 연기예술학과 연기, 24명
- 1단계: 자유연기 또는 특기 중 택1, 2분 이내 / 10배수
- 2단계: 즉흥상황연기 2분 + 지정연기 2분, 특기를 실시할 수 있음
- 일정: 1단계 2026-09-17~09-22, 2단계 2026-10-09~10-10
- 고사장 확인: 2026-09-14

## 공식 이미지 규정

| 단계 | 항목 | 판정 | 공식 내용 |
|---|---|---|---|
| 1·2단계 | 의상 | 공식 확정 | 의상 제한 없음. 과도한 노출 의상은 가급적 피함 |
| 1·2단계 | 신발 | 공식 확정 | 구두·하이힐·장화 등은 가급적 피함 |
| 1·2단계 | 헤어 | 공식 확정 | 용모를 단정하게 하라는 수준만 명시 |
| 1·2단계 | 메이크업 | 공식 확정 | 신원 파악이 힘들 정도의 분장 금지 |
| 1·2단계 | 액세서리 | 공식 언급 없음 | 별도 규정 미기재 |

## 기본 룩에서 변경할 것

- 기본 흰색 또는 검정 무지 상의 + 검정 팬츠 유지
- 작품상 의상이 꼭 필요해도 과한 노출과 신원 식별 방해 요소 제외
- 구두·부츠 대신 저상 무용화 또는 안정적인 연습화
- 얼굴 윤곽을 가리지 않는 단정한 헤어
- 자연스러운 잡티 보정 이상은 하지 않기
