# 국민대학교 공연예술학부 연극전공

[[의상 및 헤어 등 이미지|← 총괄 대시보드]]

## 전형과 일정

- 전형: 실기우수자 전형, 20명
- 1단계: 지정연기 + 자유연기, 총 2분
- 2단계: 자유연기 1분 30초 + 즉흥연기 2분 + 지정작품 연기 1분 30초
- 일정: 1단계 2026-10-01~10-04, 2단계 2026-10-24~10-25
- 고사장 안내: 09-22 / 2단계 안내: 10-20

## 공식 이미지 규정

| 단계 | 항목 | 판정 | 공식 내용 |
|---|---|---|---|
| 1·2단계 | 의상 | 공식 확정 | 검정 상·하의 또는 흰색 상의+검정 하의만. 조금이라도 다른 색 불가. 움직임이 편한 복장 |
| 1·2단계 | 신발 | 공식 언급 없음 | 별도 규정 미기재 |
| 1·2단계 | 헤어 | 공식 확정 | 단정하게 정리하되 세팅·스타일링 금지 |
| 1·2단계 | 메이크업 | 공식 확정 | 최소 화장 가능하나 권장하지 않음 |
| 1·2단계 | 액세서리 | 공식 언급 없음 | 별도 규정 미기재 |

### 추가 의상 규정

- 풀스커트는 검정 또는 흰색만 가능
- 과도한 노출은 감점될 수 있음
- 배경음악·반주 사용 불가
- 위험·대형·설치가 느린 소품 금지
- 학교 의자 사용 가능, 개인 의자 금지

## 기본 룩에서 변경할 것

- 흰색 무지 크루넥 + 검정 팬츠를 1안, 올블랙을 2안으로 촬영 비교
- 헤어 왁스·스프레이·고데기 스타일링 없이 빗질과 커트로만 단정하게
- 가능하면 맨얼굴, 필요한 경우에도 작은 잡티 보정만
- 신발은 후속 공지 전까지 검정 저상 재즈화로 연습

## 고사 직전 체크리스트

- [ ] 옷·양말·끈에 다른 색 포인트 없음
- [ ] 헤어 스타일링 제품 사용하지 않음
- [ ] 메이크업 최소 또는 맨얼굴
- [ ] 소품 크기·안전·설치시간 확인
- [ ] MR·반주 없이 수행
- [ ] 09-22/10-20 최신 공지 확인
