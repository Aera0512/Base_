# 동국대학교 연극학부

[[의상 및 헤어 등 이미지|← 총괄 대시보드]]

## 전형과 일정

- 전형: 실기/실적 연극학부 실기형
- 1단계: 연극 또는 뮤지컬 장면 중 택1, 2분 이내
- 2단계: 지정작품 + 종합실기
- 1단계: 2026-09-18~09-22
- 2단계: 2026-10-21~10-24 (10/6 최신 공지)
- 고사 안내: 1단계 09-16, 2단계 10-19 예정

## 공식 이미지 규정 — 2단계

2026-10-06 공지 기준. 이전 ‘공식 언급 없음’ 및 흰 상의·연습화 임시안을 대체한다. 이 규정을 1단계에 소급 적용하지 않는다.

| 항목 | 최신 규정 |
|---|---|
| 실기복 | 검정 라운드넥 반팔·긴팔 연습복과 긴바지. 레깅스·레오타드 가능 |
| 금지 의상 | 흰색·민소매·터틀넥·셔츠·정장·무대의상·7부·치마·슬랙스(앞 지퍼·단추·버클 바지), 큰 레터링·프린트·레이스·시스루·유색 패턴·신체 강조 패드 |
| 발 | 맨발 필수. 양말 및 모든 신발 불가 |
| 화장 | BB·틴트·립글로스·반영구 포함 일체 금지 |
| 헤어 | 눈·코·입·이마·귀 노출. 단발 이상 묶기, 묶이지 않으면 핀 고정. 검정 머리끈·고정핀만 허용 |
| 기타 | 액세서리·유색 네일/페디·노출 타투·미용렌즈·가발·피스·모자 불가 |
| 소품 | 개인 소품 불가. 의자·큐빅 미제공. 특기 악기 연주용 악기는 가능하나 소품용 악기는 금지 |

## 내 준비안 — 소지품 선택은 미정

- 검정 무지 라운드넥 연습복 + 검정 긴 연습바지 한 벌을 골라 맨발로 리허설.
- 연기·특기 전체를 해보며 움직임 방해, 옷의 흘러내림, 얼굴 가림 여부 확인.
- 헤어 고정과 화장·액세서리 제거를 포함해 당일 준비 순서 점검.

## 고사 직전 체크리스트

- [ ] 실기복·맨발 조건으로 전체 리허설
- [ ] 머리·화장·네일·액세서리 등 개인 해당 항목 점검
- [ ] 최종 고사장 안내, 출력 수험표·인정되는 실물 신분증, 반주 사용 시 USB 점검

고사 시작 1시간 전 입실 완료. 모바일 신분증·촬영본은 불인정.
