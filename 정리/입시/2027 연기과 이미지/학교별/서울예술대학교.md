### 소품·음악

- 소품은 입실 전 검사 후 허용된 것만 사용
- 흉기·총포·화기·날카로운 물건·인화성 물질·음식물 등 위험 소품 금지
- 특기 음악은 mp3 파일을 USB에 저장
- 피아노·큐브·의자는 학교에 비치

## 기본 룩에서 변경할 것

- 기본 흰색 무지 상의 + 검정 팬츠 유지
- 얼굴 전면이 확실히 보이도록 앞머리를 정리
- 컬러·서클렌즈 대신 무색 시력교정 렌즈 또는 안경 여부를 공식 문의 후 결정
- 자율 선택이어도 강한 분장·장신구는 개인 전략상 배제

## 고사 직전 체크리스트

- [ ] 얼굴 전면이 머리카락에 가리지 않음
- [ ] 서클·컬러렌즈 착용하지 않음
- [ ] 소품 사전 검사 가능, 위험물·음식물 없음
- [ ] mp3 USB에 입시용 음악만 저장
- [ ] 10-12 이후 개인 시험일 확인
- [ ] 2차 원서접수·전형료 납부 별도 확인
