# 세종대학교 영화예술학과 연기예술

## 전형과 일정

- 전형: 실기/실적 실기우수자 전형
- 모집: 영화예술학과 연기예술 22명
- 1단계: 자유연기 3분 + 특기 / 실기 100%, 8배수
- 2단계: 즉흥연기 + 지정연기, 총 5분 / 실기 70% + 학생부 30%
- 일정: 1단계 2026-09-29부터, 2단계 2026-10-30~10-31
- 1단계 안내 09-22, 2단계 안내 10-21

## 기본 룩에서 변경할 것

- 기본 흰색 또는 검정 무지 상의 + 검정 팬츠
- 입실 전 최종 의상 착용 완료
- 맨발 상태로 모든 장면과 특기 리허설
