# 인천대학교 공연예술학과

[[의상 및 헤어 등 이미지|← 총괄 대시보드]]

## 전형과 일정

- 전형: 실기우수자, 20명
- 1단계: 자유연기 2분 + 질의응답·특기, 7배수
- 2단계: 당일 지정연기 2분 + 지정목록 작품 자유연기 2분 + 질의응답·특기
- 일정: 1단계 2026-10-20~10-24, 2단계 2026-11-13~11-14
- 고사 안내: 1단계 10-07, 2단계 11-11

## 공식 이미지 규정

| 단계 | 항목 | 판정 | 공식 내용 |
|---|---|---|---|
| 1·2단계 | 의상 | 공식 확정 | 검정·흰색·회색 계열의 단순한 연습용 티셔츠와 바지 |
| 1·2단계 | 신발 | 공식 언급 없음 | 별도 규정 미기재 |
| 1·2단계 | 헤어 | 공식 언급 없음 | 별도 규정 미기재 |
| 1·2단계 | 메이크업 | 공식 확정 | 화장 금지 |
| 1·2단계 | 액세서리 | 공식 언급 없음 | 별도 규정 미기재 |

### 소품

- 위험하거나 다른 수험생의 실기를 방해하는 소품 금지

## 기본 룩에서 변경할 것

- 회색 또는 흰색 무지 티셔츠 + 검정 팬츠
- 맨얼굴
- 후속 공지 전까지 검정 저상 재즈화 준비
- 장신구는 개인 기본안에 따라 모두 제거

## 고사 직전 체크리스트

- [ ] 의상이 검정·흰색·회색 범위 안
- [ ] 티셔츠와 바지가 단순한 연습복
- [ ] 화장하지 않음
- [ ] 소품 안전성과 다른 수험생 방해 여부 확인
- [ ] 10-07/11-11 최신 공지에서 신발·헤어·액세서리 확인
