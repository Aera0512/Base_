## 새 노트 진행 현황

```dataview
TABLE WITHOUT ID
  link(file.path, work) AS "작품",
  author AS "작가",
  status AS "진행 상태"
FROM "연기/작품과 인물 분석/세종대학교 2027 지정희곡"
SORT work ASC
```

> [!tip] 상태값
> 각 노트의 `status`를 `미시작 → 진행 중 → 완료`로 바꾸면 위 표에 바로 반영된다.
