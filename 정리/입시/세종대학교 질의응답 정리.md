# 세종대학교 질의응답 정리

> [!abstract] 자료 범위
> 사용자가 제공한 두 묶음의 면접 후기 질문과 2026-10-01에 확인한 세종대학교 공식 자료를 통합했다. 후기 질문은 학교의 공식 출제 목록이 아니며, 답변 예시는 개인 경험에 맞게 수정하는 연습용 문장이다.

## 1. 먼저 준비할 질문과 빈도

## 2. 세종대학교 영화예술학과 핵심 정보

### 특징과 공식 교육목표

학부는 **연출·제작 / 연기예술** 두 세부전공으로 구성된다. 전공 간 통합 교육, 인문학·공학·타 예술과의 연결, 이론과 실기 및 산학협력을 강조한다. 무대·영상·온라인 플랫폼 등 여러 매체에서 창작하고 활동하는 **Multi-Performer·Multi-Creator** 양성이 핵심 방향이다.

| 공식 교육목표 | 이해할 내용 |
|---|---|
| Innovation | 혁신·도전·창의성 |
| Convergence | 예술·인문학·공학 등 학문 간 융합 |
| Professionalism | 통합 교육과 산학협력을 통한 전문성 |
| Versatility | 여러 매체에서 표현하고 창작하는 역량 |

K-Culture와 세계 콘텐츠 환경을 고려한 창작도 강조한다. 이는 학과의 교육 방향이며, 다른 학교에는 없는 독점적 특징이나 공식 입시 평가표라는 뜻은 아니다. [공식 학과 소개](https://dept.sejong.ac.kr/moviedpt/intro/department-introduction.do)

## 3. 학교 관련 질의응답 예시

> [!tip] 사용 방법
> 답변은 ‘학교에 대해 확인한 사실 하나 + 내 관심이나 목표 하나’로 연결한다. 아래 문장을 자신의 실제 생각에 맞게 고친다.

### Q. 세종대학교 영화예술학과의 특징은?

**답변 예시:** 연출·제작과 연기예술을 연결해서 배우고, 여러 매체에서 활동할 수 있는 배우를 기른다는 점이 특징이라고 생각합니다.

### Q. 세종대를 한 키워드로 표현하면?

**답변 예시:** 융합입니다. 연기를 연출·제작과 함께 이해하며 작품 전체를 보는 배우로 성장하고 싶기 때문입니다.

**꼬리질문:** 그럼 본인은 어떤 키워드인가요?

**내 답변:** [키워드]입니다. [그 성격이 드러난 실제 경험]이 있기 때문입니다.

### Q. 세종대학교 로고의 의미를 아나요?

**답변 예시:** 해시계의 영침과 아가페 책자, 승리를 상징하는 월계관으로 구성되어 있습니다. 창의적 봉사라는 뜻의 문구와 함께 덕성·창의·봉사·실천의 교육정신을 담고 있다고 알고 있습니다.

### Q. 세종대를 색으로 표현하면?

**답변 예시:** 크림슨 레드입니다. 공식 색상이 상징하는 에너지와 창의성이 제가 세종대에서 키우고 싶은 모습과 연결되기 때문입니다.

**꼬리질문:** 본인은 무슨 색인가요?

**내 답변:** [색]입니다. [실제 성격이나 경험에 근거한 이유].

색에 관한 개인적 비유를 묻는 질문에는 다른 색으로 답해도 된다. 공식 색상과 개인 해석은 구분한다.

### Q. 가장 듣고 싶은 수업은?

| 선택할 과목 | 연습용 답변 |
|---|---|
| 호흡과발성1 | 긴장한 상황에서도 말끝까지 안정적으로 전달하는 힘을 기르고 싶습니다. |
| 텍스트와연기실습1 | 대본에서 발견한 인물의 특징을 실제 행동으로 구체화하는 과정을 배우고 싶습니다. |
| 매체연기실습1 | 매체의 특성에 따라 제 표현을 어떻게 조절해야 하는지 실습하며 알아가고 싶습니다. |
| 공연제작Project1 | 동료들과 작품을 완성하면서 제 연기가 공연 전체에 어떻게 기여하는지 배우고 싶습니다. |

공식 설명에서 텍스트와연기실습1은 역할 창조 과정을, 매체연기실습1은 대중예술매체에서 연기를 연구하고 활용하는 방법을 다룬다. 위의 개인 목표는 답변 예시다. [과목별 설명](https://dept.sejong.ac.kr/moviedpt/intro/curriculum.do)

### Q. 세종대를 선택한 특별한 이유는?

**답변 틀:** [학교에서 확인한 교육 방향·수업]에 관심이 있습니다. 저는 [실제 경험에서 발견한 배움의 필요]가 있어서, [해당 수업·활동]을 통해 [구체적인 목표]를 이루고 싶습니다.

### Q. 우리 학교에 와서 무엇을 하고 싶어요?

**답변 틀:** [관심 있는 수업·창작 활동]에 참여하고 싶습니다. 특히 [배우고 싶은 점]을 경험해서 [성장 목표]로 이어가고 싶습니다.

### Q. 세종대 공연을 봤어요?

**답변 틀:** [실제로 본 작품명]을 [공연장]에서 봤습니다. [구체적 장면과 배우의 행동]이 기억에 남았고, [그 이유] 때문에 [배역]을 맡아보고 싶었습니다.

직접 관람하지 않은 작품을 관람했다고 작성하지 않는다. 학교 제작 공연인지, 공연명·연도·공연장이 맞는지 확인한다.

## 4. 후기 질문 모음 — 중복 통합, 꼬리질문 유지

### 연기 경력·입시 이력

- 연기를 배운 지 얼마나 됐어요? / 입시 준비는 얼마나 했어요?
- 입시는 처음인가요? 몇 번째 도전인가요? / 재수·삼수인가요?
- 그동안 활동도 했어요? / 이전에 결과가 없었나요, 다시 도전하는 건가요?
- 고3인가요? 몇 살인가요?
- 연기를 시작하기 전에는 무엇을 했어요? / 춤은 얼마나 췄어요?
- 촬영을 전공하다 연기에 도전하는 건가요?
- 연기를 시작한 계기는? / 왜 배우가 되려고 해요?
- 연기를 해보니 어때요? / 시작하면서 무엇이 달라졌어요?
- 부모님이 반대하지 않으세요?
- 공부는 열심히 했어요?

### 준비 과정·피드백·당일 평가

- 연기를 준비하면서 가장 스트레스받았던 것은?
- 이번 입시에서 무엇을 가장 보완했어요?
- 연기하면서 정말 고치기 힘들었던 점은?
- 가장 많이 받은 코멘트는? → 극복하기 위해 어떤 노력을 했어요?
- 선생님 피드백을 잘 받아들이나요, 자신의 생각을 우선하나요?
- 납득해야만 피드백을 반영하나요? → 납득하지 못하면 반영하지 않나요?
- 입시 준비가 행복했어요, 힘들었어요? → 왜 행복했어요? → 가장 힘들었던 때는?
- 오늘 실기에 만족하나요? / 준비한 것을 잘 보여줬나요? / 잘 본 것 같아요?

### 자기소개·매력·배우의 자질

- 자기소개 해보세요.
- 본인의 매력은? → 한 단어로 표현하면? → 사람을 홀린다고요?
- 배우로서 본인의 장점과 단점은?
- 본인만의 장점은? / 남들보다 훨씬 잘하는 것은?
- 성격적 장점을 짧게 말해보세요. / 솔직하게 성격적 단점은?
- 배우에게 창의성이 필요한 이유는?
- 배우라는 직업의 특성은?
- 배우가 움직임을 배우는 이유는?

### 세종대 관심·지원 동기

- 세종대를 어떻게 알게 됐어요? / 고른 특별한 이유는?
- 학교에 대한 관심도는? / 어떤 관심이 있나요? / 아는 것을 말해보세요.
- 세종대의 특성·장점은? → 짧게 말해보세요.
- 우리 학교의 연기 특징은?
- 우리 학교는 어떤 것 같아요? / 본인에게 세종대학교란?
- 세종대를 키워드로 표현하면? → 본인은?
- 세종대를 색으로 표현하면? → 본인은 무슨 색?
- 커리큘럼·교과목을 찾아봤어요? → 어땠어요? → 구체적으로 듣고 싶은 수업은?
- 세종대가 1지망인가요?
- 어떤 각오로 세종대 입시에 임했어요?
- 입학하면 무엇을 하고 싶어요? / 어떤 공연을 해보고 싶어요? / 캠퍼스 생활의 로망은?
- 세종대학교 로고의 의미는? — 지원자가 로고를 안다고 말한 뒤 이어진 질문.

### 공연 관람 경험

- 연극 보는 것을 좋아해요? / 평소 많이 봐요? → 올해 몇 편 봤어요?
- 최근 본 공연은? → 또 어떤 공연을 봤어요?
- 가장 기억에 남는 연극은?
- 어느 공연장에서 했어요? → 연출가는 누구예요?
- 어떤 역할을 해보고 싶어요?
- 세종대학교 공연을 봤어요? → 어떤 공연? → 어땠어요? → 무엇이 가장 재미있었어요?
- 가장 인상 깊은 장면은? → 그 장면이 제일 인상 깊었어요?
- 그 공연에서 맡아보고 싶은 배역은?
- 커튼콜은 어떻게 진행됐어요? → 극장은 어디였어요? → 다른 공연도 같은 극장에서 봤어요?
- 정말 우리 학교 공연이 맞아요?
- 올해는 왜 우리 학교 공연을 보지 않았어요? → 관심이 없는 건가요?

### 준비한 독백·인물

- 이 독백을 고른 이유는?
- 연기한 인물의 직업은?
- 이 인물을 연기하기 위해 특별히 노력한 것은?
- 무반주를 선택한 특별한 이유는?
- 질량 보존의 법칙을 알아요? → 설명해보세요.
- 흥미롭게 생각하는 물리 법칙 하나를 말해보세요. → 설명해보세요.

물리 질문은 후기의 대화 흐름상 인물의 직업이나 지원자의 답변에서 이어졌을 가능성이 있다. 모든 지원자에게 공통으로 물었다는 근거는 없다.

### 롤모델·미래·가치관

- 롤모델 / 존경하거나 닮고 싶은 배우는? → 이름만! → 이유는?
- 만나고 싶은 배우는? → 특별히 만나고 싶은 이유는?
- 인생에서 꼭 해보고 싶은 로망의 배역은?
- 10년 후에는 어떤 모습일까요? / 20년 후에는 무엇을 하고 있을까요?
- 인생의 최종 목표는?
- 좌우명은?
- 가장 소중한 세 가지는? → 왜요?

### 성격·관계·경험·관심사

- 친구가 많아요? / 친구들에게 보통 어떤 사람인가요?
- 고집이 있는 편인가요? / 솔직히 까불까불한 편이죠?
- 가장 재미있었던 일탈은? → 친구들과 했어요? → 재미있었어요?
- 가장 크게 해본 반항은?
- 집안일을 자주 도와드려요? → 어떤 일을 맡아요?
- 최근 가장 행복했던 순간은? → 가장 화났던 순간은?
- 요즘 가장 기억에 남는 순간은? → 어떤 친구예요? → 그때 무엇을 느꼈어요?
- 요즘 본인을 가장 설레게 하는 것은?
- 요즘 최대 관심사는? → 러닝을 자주 해요? → 러닝과 연기의 비슷한 점은?

러닝 관련 질문은 지원자의 관심사 답변에서 이어진 사례다.

### 독서·상식·시대에 대한 생각

- 최근 읽은 책은? → 소개해주세요. / 희곡 외에 읽은 책은?
- 헨리크 입센은 누구인가요? / 소포클레스는 누구인가요?
- 사자성어 두 개를 말해보세요.
- 우이독경의 뜻은? / 아비규환의 사전적 의미는?
- AI 시대에 배우가 할 수 있는 기능은?
- 챗GPT나 AI에게 무엇을 가장 많이 물어봐요?

### 현장 요청·진행 멘트

- 숨을 고르세요. / 크게 심호흡하세요. / 가운데 또는 T자로 서세요.
- 담백하고 또박또박하게 할 수 있는 것이 있어요? → 더 또박또박 해보세요.
- 가운데에서 턴을 돌아보세요.
- 카메라를 보고 활짝 웃어보세요.
- 다른 연기를 보여줄 수 있어요?
- 입을 벌려보세요. / 이마가 보이도록 머리를 올려보세요.
- 지금 교정 중인가요? / 발음이 불편한가요? / 머리가 반짝거리는데 무엇인가요?

현장 요청은 후기 사례이며 공식 필수 시험 항목을 뜻하지 않는다. 교수의 웃음·말 끊기 등에 대한 응시자의 해석은 평가 사실로 옮기지 않았다.

## 6. 면접 전 확인

- [ ] 연기 시작 시점과 입시 횟수를 혼동 없이 말할 수 있다.
- [ ] 학교 특징 하나와 듣고 싶은 과목 하나를 이유와 함께 설명한다.
- [ ] 관람한 학교 공연과 일반 공연의 제목·연출·공연장을 확인했다.
- [ ] 롤모델 이름만 묻는 경우 짧게 답하고, 이유를 물으면 이어서 답한다.
- [ ] 장점·단점·피드백을 실제 경험으로 설명한다.
- [ ] 답변에 쓴 단어를 “그게 무슨 뜻인가요?”라고 다시 물어도 설명할 수 있다.
- [ ] 독백 인물의 직업과 선택 이유를 말할 수 있다.
- [ ] 개인 답변의 빈칸을 실제 경험으로 채웠다.
