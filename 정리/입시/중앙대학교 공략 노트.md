## 1. 전형과 일정

### 연극(연기) 전형

- **실기/실적(실기형), 서울캠퍼스 24명.** 별도 자격을 요구하는 특기형 2명과 구분.
- **1단계 실기 100%, 5배수 → 2단계 실기 80% + 교과 15% + 출결 5%. 수능최저 없음.**

| 단계 | 실기 |
|---|---|
| 1단계 | 자유연기 **2분 이내**, MR 불가 |
| 2단계 | 당일 지정대사·즉석연기·인터뷰 + **1단계와 다른 작품** 자유연기. 총 **5분 이내**, MR 불가 |

지정대사는 1~2분 내외 분량이며, 당일 받은 대본을 연습해 발표한다.

## 2. 의상 규정

**연극(연기)·뮤지컬연기:** 확인한 최신 모집요강의 실기과제 안내와 8/12 일정 공지에는 의상·신발·헤어·메이크업·장신구 세부규정이 없다. **9/22·10/13 수험생 유의사항에서 각각 확인 필요.**

**TV방송연예:** 비대면 영상 촬영 안내가 별도로 있으므로, 대면 연기시험의 규정을 그대로 적용하지 않는다. 이번 확인에서는 영상 촬영 관련 의상 원문까지 검증하지 못했다.

미기재를 자유복장·맨발·화장 허용/금지로 해석하지 않는다. 다른 전공인 무용의 지정의상도 연극에 적용하지 않는다.

## 3. 학교에서 직접 언급한 추구하는 학생과 방향성

아래는 **연극전공**의 공식 교육목표와 연기 교육 설명을 요약한 내용이다. 이를 TV방송연예의 별도 인재상이나 입시 외모 기준으로 확대하지 않는다.

| 공식 교육 방향 | 구체적 내용 |
|---|---|
| 창의적 공연예술인 | 작품을 창의적으로 이해하고 표현할 예술인 양성 |
| 다양한 매체의 전문인 | 공연과 영상 등 여러 매체에서 역량을 발휘 |
| 이론과 실기의 결합 | 융복합 장르에서 활동할 실천적인 예술가 |
| 교양과 국제적 역량 | 예술교양을 갖추고 국제무대에서 활동하는 문화예술인 |
| 연기자의 정체성과 전문성 | 발성·움직임의 기초부터 비사실주의 연기까지 체계적으로 교육 |
| 제작과정 경험 | 작품 선정에서 공연까지 직접 경험하는 실습교육 |

학교의 설명은 연기 기본기뿐 아니라 작품을 만들고 공연하는 전체 과정, 이론과 교양, 배우로서의 전문성을 함께 강조한다.
