## 분석 진행 현황

```dataview
TABLE WITHOUT ID
  link(file.path, work) AS "작품",
  author AS "작가",
  exam_scope AS "시험 범위",
  status AS "진행 상태"
FROM "연기/작품과 인물 분석/한예종 2027 지정희곡"
SORT work ASC
```

> [!tip] 상태값
> 각 노트의 `status`를 `미시작 → 진행 중 → 완료`로 바꾸면 위 표에 바로 반영된다.

## 사용 순서

1. 희곡을 읽고 `작가 소개 → 줄거리 → 사건의 흐름`을 정리한다.
2. `등장인물과 특징 → 인물 관계도 → 작품의 특징과 의미`를 작성한다.
3. 추가 희곡은 독백 후보를 수집하고, 모든 희곡은 구술 답변을 준비한다.
4. 새 작품은 Templater에서 `한예종 2차 지정희곡 분석`을 실행해 생성한다.
